<Definition>
A **junction tree** for a factorised distribution is a tree whose nodes are clusters of variables, such that every
factor's variables lie inside some cluster, and every variable shared by two clusters lies in every cluster on the path
between them (the **running intersection property**). The junction tree algorithm builds such a tree from the maximal
cliques of a triangulated graph, then runs <NoteLink to="belief-propagation">belief propagation</NoteLink> between
clusters. After one inward and one outward sweep, each cluster holds the exact marginal of its variables
<Cite id="lauritzen1988" />.
</Definition>

## Problem

Belief propagation is exact on trees and approximate on graphs with cycles.
<NoteLink to="variable-elimination">Variable elimination</NoteLink> is exact on any graph but answers one query per run.
The junction tree algorithm gives both: exact results on any graph and every marginal from two sweeps. It groups
variables into clusters until the cluster graph is a tree, and passes messages between clusters, each message a table
over the variables that two neighbouring clusters share.

## Mechanism

**1. Moralise.** For a <NoteLink to="bayesian-network">Bayesian network</NoteLink>, join every pair of parents of a
common child and drop the directions. Every conditional $p(x_i \mid \xvec_{\mathrm{pa}(i)})$ then lies in a clique. A
<NoteLink to="markov-random-field">Markov random field</NoteLink> needs no change.

**2. Triangulate.** Add edges until every cycle of four or more nodes has a chord, an edge between two non-consecutive
nodes of the cycle. The result is a **chordal** graph. One way to triangulate is to run variable elimination
symbolically: the fill edges of any elimination order triangulate the graph, and the cliques created are those of the
chordal graph.

**3. Build the tree.** Find the maximal cliques $C_1, \dots, C_m$ of the chordal graph. Join them into a tree by a
maximum-weight spanning tree, where the weight of the edge between $C_i$ and $C_j$ is the size of their intersection.
The intersection on a tree edge is its **separator** $S_{ij} = C_i \cap C_j$. For a chordal graph, every maximum-weight
spanning tree has the running intersection property <Cite id="koller2009" />.

**4. Assign factors.** Put each factor into one cluster that contains all its variables, and let the **clique
potential** $\psi_C$ be the product of the factors assigned to $C$ (or 1 if none).

**5. Pass messages.** Treat each cluster as a node of a tree and each separator as the variable set on an edge. The
message from $C_i$ to a neighbour $C_j$ is

$$
m_{i \to j}(\xvec_{S_{ij}}) = \sum_{\xvec_{C_i \setminus S_{ij}}} \psi_{C_i}(\xvec_{C_i}) \prod_{k \in N(i) \setminus j} m_{k \to i}(\xvec_{S_{ki}}),
$$

where $N(i)$ is the set of neighbouring clusters. Send messages from the leaves to a root and back. The **belief** of
each cluster is then

$$
\beta_i(\xvec_{C_i}) = \psi_{C_i}(\xvec_{C_i}) \prod_{k \in N(i)} m_{k \to i}(\xvec_{S_{ki}}) \propto p(\xvec_{C_i}).
$$

This is the Shafer–Shenoy form <Cite id="shafer1990" />. The Hugin form stores beliefs on clusters and separators and
updates by division, which saves repeated products when clusters have many neighbours <Cite id="lauritzen1988" />. The
marginal of a single variable comes from summing the belief of any cluster that contains it.

## Why the conditions are needed

**Running intersection.** A message carries information only about separator variables. If $x$ lay in clusters $C_i$
and $C_j$ but not in some cluster between them, no message on the path would mention $x$. The two clusters could then
hold beliefs that disagree about $x$. With the running intersection property, every cluster on the path holds $x$, and
the messages force agreement.

**Triangulation.** A graph has a junction tree over its maximal cliques exactly when it is chordal
<Cite id="koller2009" />. The four-cycle $a - b - c - d - a$ has maximal cliques $\set{a, b}$, $\set{b, c}$,
$\set{c, d}$ and $\set{d, a}$. Each variable lies in exactly two of them, so the running intersection property requires
those two clusters to be adjacent in the tree. That requires four distinct edges, one per variable, but a tree on four
nodes has only three. For example, the path $\set{a, b} - \set{b, c} - \set{c, d} - \set{d, a}$ separates the two
clusters that contain $a$ by clusters that do not.

**Exactness.** Once the tree has the running intersection property, the derivation of belief propagation on trees
applies with clusters in place of variables. The subtrees behind each separator share only separator variables, so the
sum distributes over them.

## Worked example

Take binary variables on the four-cycle $a - b - c - d - a$, with the same potential on every edge,
$\psi(u, v) = 2$ if $u = v$ and $1$ otherwise.

- **Triangulate.** Add the chord $a - c$. The maximal cliques are $C_1 = \set{a, b, c}$ and $C_2 = \set{a, c, d}$, with
  separator $\set{a, c}$. Assign $\psi(a, b)\,\psi(b, c)$ to $C_1$ and $\psi(c, d)\,\psi(d, a)$ to $C_2$.
- **Message from $C_1$ to $C_2$.** Sum out $b$: $m_{1 \to 2}(a, c) = \sum_b \psi(a, b)\,\psi(b, c)$. When $a = c$ this is
  $2 \times 2 + 1 \times 1 = 5$; when $a \ne c$ it is $2 \times 1 + 1 \times 2 = 4$.
- **Belief of $C_2$.** $\beta_2(a, c, d) = \psi(c, d)\,\psi(d, a)\, m_{1 \to 2}(a, c)$. Summing out $d$ gives the same
  table of 5s and 4s, times $m_{1 \to 2}$: the unnormalised marginal of $(a, c)$ is 25 when $a = c$ and 16 otherwise.
- **Result.** $Z = 2 \times 25 + 2 \times 16 = 82$ and $p(a = c) = 50/82 = 0.610$. Summing the joint over all 16
  configurations gives the same value.

The largest table has $2^3 = 8$ entries, against $2^4 = 16$ for the full joint. The saving grows exponentially for
larger graphs with small cliques.

## Cost

Each message and belief is a table over a cluster, with $k^{\abs{C}}$ entries for variables of $k$ states. The cost is
$O(m\, k^{c})$ for $m$ clusters of at most $c$ variables. The smallest achievable $c$ over all triangulations is the
treewidth plus one, the same exponent as the best elimination order for
<NoteLink to="variable-elimination">variable elimination</NoteLink>. The junction tree reuses its messages, so it answers
every single-cluster query for about twice the cost of one elimination run.

## Trade-offs

- **Triangulation is the hard part.** Finding a triangulation with the smallest largest clique is NP-hard. Greedy
  elimination heuristics, such as min-fill, are used in practice.
- **Large cliques are unavoidable for some graphs.** An $L \times L$ grid has treewidth $L$, so its clusters have at
  least $L + 1$ variables. When clusters are too large to tabulate, approximate methods such as
  <NoteLink to="loopy-belief-propagation">loopy belief propagation</NoteLink> are used instead.
- **Queries outside a cluster.** The marginal of variables that share no cluster needs extra work, for example variable
  elimination over the path of clusters between them.
- **Evidence is cheap to add.** Observing a variable multiplies an indicator into one cluster potential. A new round of
  messages then gives every posterior marginal.
