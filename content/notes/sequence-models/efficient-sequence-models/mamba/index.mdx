<Definition>
A **selective state-space layer** (S6) runs, independently for each of $D$ channels, the recurrence

$$
\hvec_t = \bar{\Amat}_t\hvec_{t-1} + \bar{\Bmat}_t x_t, \qquad y_t = \Cmat_t\hvec_t, \qquad
\bar{\Amat}_t = e^{\Delta_t\Amat}, \quad \bar{\Bmat}_t = \Delta_t\Bmat_t,
$$

with a diagonal $\Amat \in \reals^{N \times N}$ that is a fixed learned parameter, and a step $\Delta_t > 0$ and vectors
$\Bmat_t, \Cmat_t \in \reals^N$ that are computed from the input at position $t$. **Mamba** is a deep network of blocks
built around this layer, with no attention and no separate MLP blocks <Cite id="gu2023mamba" />.
</Definition>

## Why time invariance fails

A <NoteLink to="structured-state-space-models">structured state-space layer</NoteLink> such as S4 applies the same
transition at every step. Its output is a convolution $y = \bar K * x$ with a kernel that does not depend on the input.
That property gives S4 its fast convolutional training, and it is also its limit. A fixed kernel weights a token by its
position relative to the query, never by what the token is.

Two synthetic tasks show the problem <Cite id="gu2023mamba" />:

- **Selective copying.** A few content tokens are scattered among noise tokens at random positions, and the model must
  output the content tokens in order. The gap between them varies, so no fixed kernel can pick them out. S4 solves
  about 18% of cases; the selective layer solves about 97%.
- **Induction heads.** After seeing "… Harry Potter …" once, the model must predict "Potter" the next time "Harry"
  appears. The answer depends on matching content, not on distance.

Attention handles both, because its weights are computed from the tokens. Mamba gives the recurrence the same
ability while keeping a fixed-size state.

## Selection

Mamba computes, for each position $t$ with input vector $\xvec_t \in \reals^D$ over all channels,

$$
\Bmat_t = \Wmat_B\xvec_t \in \reals^N, \qquad \Cmat_t = \Wmat_C\xvec_t \in \reals^N, \qquad
\Delta_t = \operatorname{softplus}\paren{\text{bias} + \text{broadcast}_D(\wvec_\Delta^\tr\xvec_t)} \in \reals^D.
$$

$\Bmat_t$ and $\Cmat_t$ are shared by all $D$ channels. $\Delta_t$ has one entry per channel. $\Amat$ is diagonal and
real, initialised as $A_n = -(n+1)$ (S4D-Real) with state size $N = 16$ <Cite id="gu2023mamba" /> <Cite id="gu2022s4d" />.
The state transition is discretised with the zero-order hold, and the input matrix with the simpler Euler rule
$\bar{\Bmat}_t = \Delta_t\Bmat_t$.

### The step size is a gate

The role of $\Delta_t$ becomes clear with one state per channel. Take $N = 1$, $A = -1$, $B = 1$, and discretise both
$A$ and $B$ with the zero-order hold. Then $\bar A_t = e^{-\Delta_t}$ and $\bar B_t = (e^{-\Delta_t} - 1)/(-1) =
1 - e^{-\Delta_t}$, so

$$
h_t = e^{-\Delta_t}h_{t-1} + \paren{1 - e^{-\Delta_t}}x_t.
$$

Let $\Delta_t = \operatorname{softplus}(z_t) = \log(1 + e^{z_t})$ with $z_t$ a linear function of $x_t$. Then
$e^{-\Delta_t} = 1/(1 + e^{z_t}) = 1 - \sigma(z_t)$, where $\sigma$ is the logistic sigmoid. Writing
$g_t = \sigma(z_t)$,

$$
h_t = (1 - g_t)\,h_{t-1} + g_t\,x_t.
$$

This is the gated update of a <NoteLink to="gru">GRU</NoteLink> without the nonlinearity inside the recurrence
<Cite id="gu2023mamba" />. A large $\Delta_t$ ($g_t \to 1$) resets the state and stores the current token. A small
$\Delta_t$ ($g_t \to 0$) keeps the state and ignores the token. With $N > 1$, input-dependent $\Bmat_t$ controls which
state dimensions a token writes to, and $\Cmat_t$ controls which dimensions the output reads.

### Worked example

Take the scalar gated layer above with inputs $x = (2, 9, 9, -4)$. Suppose the input projection marks tokens 1 and 4 as
relevant, $\Delta = (5, 0.01, 0.01, 5)$. The gates are $g_t = 1 - e^{-\Delta_t} = (0.99326, 0.00995, 0.00995, 0.99326)$.

- $h_1 = 0.99326 \times 2 = 1.9865$.
- $h_2 = 0.99005 \times 1.9865 + 0.00995 \times 9 = 2.0563$.
- $h_3 = 0.99005 \times 2.0563 + 0.00995 \times 9 = 2.1254$.
- $h_4 = 0.00674 \times 2.1254 + 0.99326 \times (-4) = -3.9587$.

The state holds the value 2 through the two ignored tokens and then replaces it. A time-invariant layer with the fixed
gate $g = 0.5$ gives $h = (1, 5, 7, 1.5)$: the ignored tokens dominate the state.

## Computing a selective layer

Input-dependent parameters make the layer time-varying. The output is no longer a convolution with one kernel, so the
FFT route of S4 is gone. The recurrence is still linear in $\hvec$, and $\bar{\Amat}_t$ is diagonal, so each state
dimension is a scalar recurrence $h_t = \bar a_t h_{t-1} + \bar b_t x_t$. A
<NoteLink to="parallel-scan">parallel scan</NoteLink> computes all $L$ states in $O(\log L)$ depth and $O(L)$ work.

The obstacle is memory. The states form a tensor of shape (batch, $L$, $D$, $N$), $N$ times larger than the input. Writing
it to the GPU's main memory (HBM) would make the layer memory-bound. Mamba's kernel avoids this in the same way as
<NoteLink to="flash-attention">FlashAttention</NoteLink> <Cite id="gu2023mamba" />:

- **Kernel fusion.** It reads $\Delta$, $\Amat$, $\Bmat$, $\Cmat$ and $x$ from HBM into on-chip SRAM, discretises and runs
  the scan there, and writes back only the output $y$ of shape (batch, $L$, $D$).
- **Recomputation.** The backward pass recomputes the states from the inputs instead of storing them.

The fused scan is up to 3 times faster than earlier convolution-based SSMs on an A100, 20 to 40 times faster than a plain
PyTorch scan, and faster than FlashAttention-2 beyond sequence length 2K, and its memory use matches an optimised transformer layer with FlashAttention <Cite id="gu2023mamba" />.

At generation time the layer keeps only $\hvec_t$, $DN$ numbers per layer, and each token costs $O(DN)$ whatever its
position. There is no <NoteLink to="kv-cache">KV cache</NoteLink>.

## The Mamba block

A Mamba block expands the model width $D$ by a factor $E = 2$ with a linear projection into two branches. One branch
applies a short causal convolution, a SiLU nonlinearity and the selective SSM. The other applies SiLU and acts as a
multiplicative gate on the first. A linear projection returns to width $D$. Blocks are stacked with residual connections
and normalisation, and no attention or MLP layers are added <Cite id="gu2023mamba" />.

<MambaBlockDiagram />

Mamba generates with 5 times the throughput of a transformer of similar size, scales linearly with sequence length,
and improves on real data up to sequences of a million tokens. Mamba-3B outperforms transformers of the same size and
matches transformers twice its size on language modelling <Cite id="gu2023mamba" />. On induction heads it extrapolates
from training length 256 to sequences of $2^{20} \approx 10^6$ tokens, while no other method tested generalises beyond
twice its training length.

## Mamba-2 and state space duality

Mamba-2 restricts the transition further, from diagonal to a scalar times the identity: $\bar{\Amat}_t = a_t\eye$
<Cite id="dao2024" />. Unrolling the recurrence as for S4 gives

$$
y_j = \sum_{i \le j} \Cmat_j^\tr\,(a_j a_{j-1} \cdots a_{i+1})\,\Bmat_i\,x_i,
$$

because the input at step $i$ is multiplied by every transition between $i$ and $j$. In matrix form $\yvec = \Mmat\xvec$
with

$$
\Mmat = \Lmat \circ (\Cmat\Bmat^\tr), \qquad
L_{ji} = \begin{cases} a_j a_{j-1}\cdots a_{i+1} & j \ge i, \\ 0 & j < i, \end{cases}
$$

where the rows of $\Cmat$ and $\Bmat$ are the $\Cmat_t^\tr$ and $\Bmat_t^\tr$, and $\circ$ is the elementwise product. This
is causal <NoteLink to="linear-attention">linear attention</NoteLink> with queries $\Cmat$, keys $\Bmat$, values $x$ and a
decay mask $\Lmat$ in place of the causal mask. The same layer has two algorithms: the recurrence, linear in $L$, and
the masked matrix product, quadratic in $L$ but made of matrix multiplications. Dao and Gu call this **structured state
space duality** (SSD) <Cite id="dao2024" />.

Mamba-2 computes SSD in chunks: the quadratic form inside each chunk, which uses the GPU's matrix-multiply units, and the
recurrence between chunks. The SSD layer is 2 to 8 times faster than Mamba's selective scan, and the faster layer lets
Mamba-2 use a larger state <Cite id="dao2024" />. It also adds heads, analogous to multi-head attention.

## Assumptions

- **Linearity in the state.** Selection makes the coefficients depend on the input, not on the state. The recurrence
  stays linear in $\hvec$, which is what makes the scan possible.
- **Diagonal transition.** A dense input-dependent $\bar{\Amat}_t$ would make each scan combination an $N \times N$
  matrix product.

## Pitfalls

- **Fixed-size memory.** The state has $DN$ numbers whatever the context length. Tasks that need exact recall of many
  earlier tokens, such as copying a long string or retrieving one fact from a long document, are harder for Mamba than
  for attention, which keeps every token. <NoteLink to="hybrid-sequence-models">Hybrid models</NoteLink> add a few
  attention layers for this reason.
- **No convolutional mode.** Code written for S4 that precomputes a kernel does not apply. Training needs the scan.
- **Short convolution.** The causal convolution before the SSM supplies local context. Removing it hurts, because the
  SSM alone sees each token only through the state.
