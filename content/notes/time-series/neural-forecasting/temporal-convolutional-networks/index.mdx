<Definition>
A **temporal convolutional network** (TCN) maps an input sequence $x_0, \dots, x_T$ to an output sequence
$\hat y_0, \dots, \hat y_T$ of the same length with a stack of one-dimensional convolutions that are **causal**: each
output $\hat y_t$ depends only on $x_0, \dots, x_t$ <Cite id="bai2018" />. Layer $l$ applies a **dilated** convolution
with kernel size $k$ and dilation $d_l$,

$$
F(s) = \sum_{i=0}^{k-1} f(i)\, x_{s - d_l i},
$$

so its taps are $d_l$ steps apart. With $d_l = 2^{l-1}$ the number of past steps an output can see, its **receptive
field**, grows exponentially with the number of layers. Residual connections keep deep stacks trainable.

</Definition>

## Causal convolution

A standard one-dimensional convolution of width $k$ centred on $t$ reads inputs on both sides of $t$. A forecaster
cannot read the future, so a TCN uses only taps at $t, t-1, \dots, t-k+1$. In practice the sequence is padded on the
left with $k - 1$ zeros and convolved normally, which keeps every layer as long as the input

<Cite id="bai2018" />. This is a finite impulse response filter with learnt taps, as in a
<NoteLink to="finite-impulse-response-filters">causal FIR filter</NoteLink>, followed by a nonlinearity.

With dilation $1$, each layer adds $k - 1$ steps of history. Seeing $1024$ past steps with $k = 2$ would take $1023$
layers. Dilation removes that linear growth.

## Dilated convolution

A dilated convolution with dilation $d$ applies a $k$-tap filter to inputs spaced $d$ apart:
$x_s, x_{s-d}, \dots, x_{s-(k-1)d}$. It is the same as a convolution with a filter of length $(k-1)d + 1$ whose
entries between the taps are zero, computed without the zeros <Cite id="oord2016c" />. At $d = 1$ it is an ordinary
convolution. The output keeps the input's length, unlike pooling or strided convolution, which shorten it. In image
segmentation, stacks of dilated convolutions with exponentially growing dilation give exponentially growing receptive
fields without loss of resolution <Cite id="yu2016" />.

## Deriving the receptive field

Stack $L$ causal layers with kernel size $k$ and dilations $d_1, \dots, d_L$. Consider one unit at the top layer at
time $s$. Layer $L$ reads layer $L - 1$ at times $s - i_L d_L$ for $i_L \in \{0, \dots, k-1\}$. Each of those reads
layer $L - 2$ at a further offset $i_{L-1} d_{L-1}$, and so on down to the input. The output at $s$ therefore depends
on inputs at

$$
s - \sum_{l=1}^{L} i_l\, d_l, \qquad i_l \in \{0, 1, \dots, k-1\}.
$$

The largest offset takes every $i_l = k - 1$ and equals $(k-1)\sum_l d_l$. The smallest is $0$. The **receptive
field**, the number of time steps from the earliest input reached to the latest, is

$$
R = 1 + (k - 1)\sum_{l=1}^{L} d_l.
$$

With no dilation, $d_l = 1$ and $R = 1 + L(k-1)$: linear in depth. With doubling dilations $d_l = 2^{l-1}$ the sum is a
geometric series, $\sum_{l=1}^{L} 2^{l-1} = 2^L - 1$, so

$$
R = 1 + (k - 1)(2^L - 1).
$$

The receptive field doubles with each layer, while the number of parameters grows only linearly in $L$.

**No input is skipped.** $R$ measures the span. A schedule could reach both ends of the span but miss inputs in
between. For $k = 2$ and $d_l = 2^{l-1}$ this cannot happen: the offsets are $\sum_l i_l 2^{l-1}$ with each
$i_l \in \{0, 1\}$, which are exactly the binary representations of $0, 1, \dots, 2^L - 1$. Every input in the span is
reached, and by exactly one path. Dilations that grow faster, such as $d_l = 4^{l-1}$ with $k = 2$, leave holes.

<Derivation title="When a dilation schedule has no holes">
Let $S_l = (k-1)\sum_{j \le l} d_j$ be the largest offset after $l$ layers, and suppose the offsets reachable after
$l - 1$ layers are all of $\{0, 1, \dots, S_{l-1}\}$. Layer $l$ adds $i\,d_l$ for $i = 0, \dots, k-1$, so the
reachable set after $l$ layers is the union of the intervals $[i\,d_l,\ i\,d_l + S_{l-1}]$. Consecutive intervals
overlap or touch when $d_l \le S_{l-1} + 1$. Then the union is the whole interval $\{0, \dots, S_l\}$. The first layer
reaches $\{0, \dots, (k-1)d_1\}$ without holes when $d_1 = 1$. By induction, a schedule with $d_1 = 1$ and
$d_l \le 1 + (k-1)\sum_{j<l} d_j$ for every $l$ has no holes. Doubling satisfies this for every $k \ge 2$, because
$2^{l-1} \le 1 + (k-1)(2^{l-1} - 1)$. Quadrupling with $k = 2$ violates it at $l = 2$: $4 > 1 + 1$.
</Derivation>

## WaveNet

WaveNet is a generative model of raw audio built from dilated causal convolutions <Cite id="oord2016c" />. It models a
waveform $x_1, \dots, x_T$ autoregressively, $p(\xvec) = \prod_t p(x_t \mid x_1, \dots, x_{t-1})$, with a softmax
over 256 quantised amplitude values at each step. Because the convolutions are causal, all $T$ conditionals are
computed in one parallel pass at training time. Generation is sequential: each sampled value is fed back as input.

WaveNet uses $k = 2$ and dilations that double up to a limit and then repeat:
$1, 2, 4, \dots, 512, 1, 2, 4, \dots, 512, \dots$. One block of ten layers has

$$
R = 1 + (2 - 1)(1 + 2 + \dots + 512) = 1 + 1023 = 1024,
$$

the same span as a single $1024$-tap convolution, with $10$ two-tap filters in place of one long one and a
nonlinearity after each. Three stacked blocks give $R = 1 + 3 \times 1023 = 3070$. Each layer uses a gated activation,
$\zvec = \tanh(\Wmat_f * \xvec) \odot \sigma(\Wmat_g * \xvec)$, where $*$ is the dilated convolution, $\odot$ the
elementwise product and $\sigma$ the logistic sigmoid. Residual and parameterised skip connections run through the
stack. See <NoteLink to="autoregressive-generative-models">autoregressive generative models</NoteLink> for WaveNet as a
density model.

## The generic TCN

Bai, Kolter and Koltun distilled these ideas into a plain architecture and compared it with recurrent networks on the
tasks those networks were usually benchmarked on <Cite id="bai2018" />. It has no gating, no skip connections across
layers and no conditioning.

- **Residual block.** Two dilated causal convolutions with the same dilation, each followed by weight normalisation,
  a ReLU and spatial dropout, which zeroes whole channels. The block's input is added to its output,
  $\ovec = \operatorname{ReLU}(\xvec + \mathcal{F}(\xvec))$, as in a
  <NoteLink to="residual-network">residual network</NoteLink> <Cite id="he2016" />. A $1 \times 1$ convolution matches
  the channel counts when they differ.
- **Dilation schedule.** Block $i$ uses $d = 2^{i}$ for $i = 0, 1, \dots, n-1$.

Each block holds two convolutions at dilation $2^i$, so a stack of $n$ blocks has

$$
R = 1 + 2(k-1)\sum_{i=0}^{n-1} 2^{i} = 1 + 2(k-1)(2^n - 1).
$$

The paper's main tuning rule is to choose $k$ and $n$ so that $R$ covers the history the task needs. Across its tasks
the generic TCN outperformed LSTM and GRU networks of similar size and retained information over longer spans.

## Worked example

Sequential MNIST presents a $28 \times 28$ image one pixel at a time, a sequence of $784$ steps, and asks for the digit
at the end. The TCN for this task used $k = 7$ and $n = 8$ residual blocks <Cite id="bai2018" />. Its receptive field is

$$
R = 1 + 2 \times 6 \times (2^8 - 1) = 1 + 12 \times 255 = 3061,
$$

which covers all $784$ pixels from the last step. Seven blocks would give $1 + 12 \times 127 = 1525$, still enough; six
would give $757$, which is not. An undilated stack with $k = 7$ and two convolutions per block would need
$\lceil 783 / 12 \rceil = 66$ blocks to cover the image.

## In forecasting

A TCN computes an output at every time step with weights shared across time, so it can replace a recurrent encoder in
a forecaster. MQ-CNN is <NoteLink to="multi-horizon-quantile-recurrent-network">MQ-RNN</NoteLink> with a WaveNet-style dilated convolutional encoder. On
Amazon demand data it was the most accurate encoder the authors tried <Cite id="wen2017" />.

## Trade-offs against recurrent networks

- **Parallel training.** Every output of a layer is computed at once. An RNN must finish step $t - 1$ before step $t$.
- **Stable gradients.** The backpropagation path has length equal to the depth, not the sequence length, which avoids
  the exploding and vanishing gradients of long recurrences.
- **Fixed memory span.** A TCN sees exactly $R$ steps and nothing earlier. An RNN's hidden state can in principle carry
  information from any distance. A TCN moved to a task that needs longer history must be rebuilt with a larger $R$.
- **Inference memory.** An RNN keeps only its hidden state between steps. A TCN must keep the last $R$ inputs, or the
  intermediate activations each layer needs, to produce the next output.

## Pitfalls

- A convolution library's default padding is symmetric. Without left-only padding the network reads the future and
  its training loss is misleadingly low.
- The receptive field bounds what the network can see, not what it uses. Distant inputs reached by a single path can
  still receive little weight.
