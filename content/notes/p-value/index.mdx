<Definition>
Let $T$ be a test statistic whose large values count as evidence against a null hypothesis $H_0$, and let $t$ be its
observed value. The p-value is

$$
p = P_{H_0}(T \ge t).
$$

For a two-sided test, "at least as extreme" means $\abs{T} \ge \abs{t}$. The null is rejected at significance level
$\alpha$ when $p \le \alpha$ <Cite id="wasserman2004" />.
</Definition>

## Reading a p-value

A p-value answers one question: if $H_0$ were true, how often would data this extreme occur? A small p-value means
the data would be unusual under $H_0$. Either $H_0$ is false, or an unusual event occurred.

The significance level $\alpha$ is chosen before seeing the data. It fixes the long-run rate of false rejections when
$H_0$ is true. Reporting the p-value itself carries more information than reporting only whether it crossed $\alpha$.

## Uniform under the null

If $H_0$ is true and $T$ is continuous, the p-value has a $\Unif(0, 1)$ distribution. So
$P_{H_0}(p \le \alpha) = \alpha$ for every $\alpha$: the rule "reject when $p \le \alpha$" makes false rejections at
exactly rate $\alpha$.

<PValueHistogram />

<Derivation title="Why p is uniform under the null">
Let $F$ be the cdf of $T$ under $H_0$, assumed continuous. The one-sided p-value is $p = 1 - F(T)$. Because $F$ is
continuous, $F(T) \sim \Unif(0, 1)$ by the probability integral transform, and so is $1 - F(T)$. For a discrete $T$,
$P_{H_0}(p \le \alpha) \le \alpha$ instead: the p-value is conservative.
</Derivation>

## What a p-value is not

The American Statistical Association lists these misreadings <Cite id="wasserstein2016" />:

- **Not the probability that $H_0$ is true.** $p$ is computed assuming $H_0$. The probability of $H_0$ given the data
  requires a prior and Bayes' theorem.
- **Not the probability that the result is due to chance.** Chance is always involved. $p$ measures how unusual the
  data are under one specific chance model.
- **Not a measure of effect size.** A tiny effect gives a small $p$ when $n$ is large. A large effect can give a large
  $p$ when $n$ is small. Report the effect size and a confidence interval alongside $p$.
- **Not a replication probability.** Suppose a z-test gives $p = 0.04$, so $\abs{z} \approx 2.05$. Even if the true
  effect equals the observed one, an identical replication reaches $p < 0.05$ only about 54% of the time.

## Pitfalls

- **Multiple testing.** Testing 20 true nulls at $\alpha = 0.05$ yields about one false rejection. Correct for the
  number of tests or control the false discovery rate.
- **Optional stopping.** Checking the p-value repeatedly and stopping when it drops below $\alpha$ raises the false
  rejection rate well above $\alpha$.
- **Choosing the side afterwards.** A one-sided test must be specified before seeing the data. Choosing the
  direction that looks favourable halves the p-value dishonestly.
