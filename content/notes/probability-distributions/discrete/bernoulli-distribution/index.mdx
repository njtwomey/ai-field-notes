<Definition>
A <NoteLink to="random-variable">random variable</NoteLink> $X$ has a Bernoulli distribution with success probability $p \in [0, 1]$, written $X \sim \Bern(p)$,
if

$$
P(X = 1) = p, \qquad P(X = 0) = 1 - p.
$$

Equivalently, $P(X = x) = p^x (1 - p)^{1 - x}$ for $x \in \{0, 1\}$.
</Definition>

## At a glance

| | |
| --- | --- |
| Parameter | Success probability $p \in [0, 1]$ |
| Support | $x \in \{0, 1\}$ |
| pmf | $p^x (1 - p)^{1 - x}$ |
| Mean | $p$ |
| Variance | $p(1 - p)$ |
| Mode | 1 if $p > 1/2$, 0 if $p < 1/2$, both if $p = 1/2$ |
| <NoteLink to="entropy">Entropy</NoteLink> | $-p \log p - (1 - p) \log (1 - p)$ |

## Where it comes from

Any event $A$ defines an indicator variable $X = \indicator\{A\}$, which is 1 when $A$ occurs and 0 otherwise. $X$ is
Bernoulli with $p = P(A)$. Coin flips, pass or fail tests, clicks and binary class labels are all Bernoulli trials.

The expectation of an indicator is the probability of its event: $\expect[\indicator\{A\}] = P(A)$. This identity turns
questions about probabilities into questions about expectations. For example, the fraction of successes in $n$
independent trials estimates $p$, because it is a sample mean of Bernoulli variables <Cite id="wasserman2004" />.

## Properties

**Mean and variance.** The mean is $\expect[X] = 0 \cdot (1 - p) + 1 \cdot p = p$. Because $X$ is 0 or 1, $X^2 = X$,
so $\expect[X^2] = p$ and every higher moment is also $\expect[X^k] = p$ for $k \ge 1$. The variance is

$$
\var(X) = \expect[X^2] - \expect[X]^2 = p - p^2 = p(1 - p).
$$

**Maximal variance at 1/2.** <NoteLink to="completing-the-square">Completing the square</NoteLink> gives $p(1 - p) = \tfrac14 - (p - \tfrac12)^2$, so the variance
is at most $1/4$, reached at $p = 1/2$. The entropy $H(p) = -p \log p - (1 - p)\log(1 - p)$ has <NoteLink to="derivative">derivative</NoteLink>
$H'(p) = \log\frac{1 - p}{p}$, which is zero only at $p = 1/2$, where $H = \log 2$. A fair coin is the least predictable
binary outcome. As $p$ moves towards 0 or 1 the outcome becomes nearly certain and both quantities fall to 0.

**Maximum likelihood.** For $n$ independent observations $x_1, \dots, x_n$ with $s = \sum_i x_i$ ones, the
log-likelihood is

$$
\ell(p) = \sum_{i=1}^n \brack{x_i \log p + (1 - x_i) \log(1 - p)} = s \log p + (n - s) \log(1 - p).
$$

Its derivative is $\ell'(p) = s/p - (n - s)/(1 - p)$. Setting it to zero gives $s(1 - p) = (n - s)p$, so
$\hat p = s/n$, the fraction of ones. The second derivative, $-s/p^2 - (n - s)/(1 - p)^2$, is negative, so this is a
maximum.

**Log-odds form.** Write $\eta = \log \frac{p}{1 - p}$, the log-odds. Solving for $p$ gives
$p = e^{\eta}/(1 + e^{\eta}) = \sigma(\eta) = 1/(1 + e^{-\eta})$, and so $1 - p = 1/(1 + e^{\eta})$. Taking the log of
the pmf,

$$
\log P(X = x) = x \log p + (1 - x) \log(1 - p) = x \log \frac{p}{1 - p} + \log(1 - p) = x\eta - \log(1 + e^{\eta}),
$$

so

$$
P(X = x) = \exp\paren{x \eta - \log(1 + e^{\eta})}.
$$

This is the exponential-family form of the Bernoulli, with <NoteLink to="exponential-family">natural parameter</NoteLink> $\eta$. The logistic function
$\sigma$ maps any real score to a valid success probability.

## Relations to other distributions

- **Binomial.** The sum of $n$ independent $\Bern(p)$ variables is $\Binom(n, p)$. A Bernoulli is a binomial with
  $n = 1$.
- **Categorical.** A Bernoulli is a <NoteLink to="categorical-distribution">categorical distribution</NoteLink> with
  $K = 2$ categories.
- **Geometric.** The number of independent $\Bern(p)$ trials up to and including the first 1 is
  <NoteLink to="geometric-distribution">geometric</NoteLink> with parameter $p$.
- **Beta.** The <NoteLink to="beta-distribution">beta distribution</NoteLink> is the <NoteLink to="conjugate-priors">conjugate prior</NoteLink> for $p$. A
  $\Beta(a, b)$ prior and $s$ ones in $n$ trials give a $\Beta(a + s, b + n - s)$ posterior.

## In machine learning

- **Binary classification.** <NoteLink to="logistic-regression">Logistic regression</NoteLink> models a label as
  $y \sim \Bern(\sigma(\wvec^\top \xvec + b))$. Its negative log-likelihood per example is the <NoteLink to="cross-entropy-and-perplexity">binary cross-entropy</NoteLink>,
  $-\brack{y \log \hat p + (1 - y) \log (1 - \hat p)}$ <Cite id="bishop2006" />.
- **Dropout.** Dropout multiplies each unit by an independent Bernoulli mask during training, keeping a unit with
  probability $p$ <Cite id="srivastava2014" />.
- **Evaluation.** Whether a model classifies one test example correctly is a Bernoulli trial. Accuracy on a test set is
  a mean of such trials.

## Pitfalls

- **Estimates of 0 or 1.** With few observations, $\hat p = s/n$ is often exactly 0 or 1. The model then assigns
  probability 0 to an outcome that can occur, and the log-likelihood of a future observation is $-\infty$. A prior
  avoids this: the posterior mean under a uniform prior is $(s + 1)/(n + 2)$.
- **Cross-entropy on probabilities.** Computing $\log \hat p$ after rounding $\hat p$ to 0 gives $-\infty$. Compute the
  loss from the log-odds $\eta$ directly, as $\log(1 + e^{\eta}) - y\eta$, which libraries implement stably.
