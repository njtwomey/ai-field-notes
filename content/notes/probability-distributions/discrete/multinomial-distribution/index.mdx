<Definition>
A random vector of counts $\xvec = (x_1, \dots, x_K)$ has a multinomial distribution with $n$ draws and
probabilities $\pivec \in \Delta^{K-1}$, written $\xvec \sim \Mult(n, \pivec)$, if

$$
P(\xvec) = \frac{n!}{x_1! \cdots x_K!} \prod_{k=1}^K \pi_k^{x_k}
$$

for non-negative integers $x_1, \dots, x_K$ with $\sum_k x_k = n$. The count $x_k$ is the number of the $n$ draws that
land in category $k$.
</Definition>

## At a glance

| | |
| --- | --- |
| Parameters | Draws $n \in \{1, 2, \dots\}$, probabilities $\pivec \in \Delta^{K-1}$ |
| Support | Count vectors $\xvec \in \{0, \dots, n\}^K$ with $\sum_k x_k = n$ |
| pmf | $\frac{n!}{x_1! \cdots x_K!} \prod_k \pi_k^{x_k}$ |
| Mean | $n \pivec$ |
| Covariance | $n\paren{\diag(\pivec) - \pivec\pivec^\top}$ |
| Marginals | $x_k \sim \Binom(n, \pi_k)$ |

## Where it comes from

Make $n$ independent draws from $\Cat(\pivec)$ and count how many fall in each category. A particular sequence with
counts $\xvec$ has probability $\prod_k \pi_k^{x_k}$. The multinomial coefficient $n!/(x_1! \cdots x_K!)$ is the number
of sequences with those counts <Cite id="wasserman2004" />: it counts the ways to choose which $x_1$ of the $n$
positions hold category 1, which $x_2$ of the rest hold category 2, and so on,
$\binom{n}{x_1}\binom{n - x_1}{x_2}\cdots = n!/(x_1! \cdots x_K!)$. The probabilities sum to 1 by the multinomial
theorem, $\sum_{\xvec} \frac{n!}{x_1! \cdots x_K!} \prod_k \pi_k^{x_k} = (\pi_1 + \dots + \pi_K)^n = 1$.

## Properties

**Sum of one-hot vectors.** $\xvec = \sum_{i=1}^n \evec_i$, where the $\evec_i$ are independent one-hot categorical
draws. The moments follow from those of a single draw.

**Mean and covariance.** A single one-hot draw has mean $\pivec$ and covariance $\diag(\pivec) - \pivec\pivec^\top$ (see
<NoteLink to="categorical-distribution">categorical distribution</NoteLink>). The $n$ draws are independent, so their
means and covariances add: $\expect[\xvec] = n\pivec$ and $\cov(\xvec) = n\paren{\diag(\pivec) - \pivec\pivec^\top}$. In
particular $\var(x_k) = n\pi_k(1 - \pi_k)$ and $\cov(x_j, x_k) = -n\pi_j\pi_k$ for $j \ne k$.

**Negative correlation.** The counts sum to $n$, so a draw in one category is a draw missing from the others. Dividing
the covariance by the two standard deviations, the factors of $n$ cancel:

$$
\corr(x_j, x_k) = \frac{-n\pi_j\pi_k}{\sqrt{n\pi_j(1 - \pi_j)\, n\pi_k(1 - \pi_k)}}
= -\sqrt{\frac{\pi_j \pi_k}{(1 - \pi_j)(1 - \pi_k)}},
$$

whatever the value of $n$.

**Marginals and merging.** Each count on its own is $\Binom(n, \pi_k)$: a draw either lands in category $k$ or it does
not. Merging categories adds their probabilities. Merging all but one category gives the binomial marginal.

**Conditioning.** Given the first count $x_1$, the other counts are
$\Mult\paren{n - x_1, (\pi_2, \dots, \pi_K)/(1 - \pi_1)}$.
The remaining draws are shared among the remaining categories in proportion to their probabilities.

<Derivation title="Conditioning on one count">
$x_1 \sim \Binom(n, \pi_1)$. Divide the joint pmf by this marginal. Writing $m = n - x_1$,

$$
\frac{P(\xvec)}{P(x_1)}
= \frac{\frac{n!}{x_1! \cdots x_K!}\prod_{k} \pi_k^{x_k}}{\frac{n!}{x_1!\, m!}\,\pi_1^{x_1}(1 - \pi_1)^{m}}
= \frac{m!}{x_2! \cdots x_K!}\prod_{k=2}^K \paren{\frac{\pi_k}{1 - \pi_1}}^{x_k},
$$

using $\sum_{k \ge 2} x_k = m$. This is the $\Mult\paren{m, (\pi_2, \dots, \pi_K)/(1 - \pi_1)}$ pmf.
</Derivation>

**Poisson counts conditioned on their total.** Let $x_k \sim \Poisson(\lambda_k)$ be independent and
$N = \sum_k x_k$. Given $N = n$, the vector $\xvec$ is $\Mult(n, \lambdavec / \sum_k \lambda_k)$.

<Derivation title="Poisson counts conditioned on their total">
$N \sim \Poisson(\Lambda)$ with $\Lambda = \sum_k \lambda_k$, by closure of the Poisson under sums. For counts with
$\sum_k x_k = n$,

$$
P(\xvec \mid N = n) = \frac{\prod_k e^{-\lambda_k}\lambda_k^{x_k}/x_k!}{e^{-\Lambda}\Lambda^n/n!}
= \frac{n!}{x_1! \cdots x_K!}\prod_k \paren{\frac{\lambda_k}{\Lambda}}^{x_k}.
$$
</Derivation>

**Maximum likelihood.** The log-likelihood of one observed count vector is $\sum_k x_k \log \pi_k$ plus a constant.
This is the categorical log-likelihood with counts $x_k$, so the same Lagrange argument gives $\hat\pivec = \xvec / n$.

## Relations to other distributions

- **Binomial.** With $K = 2$, $\Mult(n, (1 - p, p))$ is equivalent to
  <NoteLink to="binomial-distribution">$\Binom(n, p)$</NoteLink> for the second count.
- **Categorical.** $\Mult(1, \pivec)$ is a single <NoteLink to="categorical-distribution">categorical</NoteLink> draw in
  one-hot form.
- **Poisson.** Independent <NoteLink to="poisson-distribution">Poisson</NoteLink> counts conditioned on their total are
  multinomial.
- **Dirichlet.** The <NoteLink to="dirichlet-distribution">Dirichlet</NoteLink> is the <NoteLink to="conjugate-priors">conjugate prior</NoteLink> for $\pivec$.
  Integrating $\pivec$ out of a $\Dir(\alphavec)$–multinomial model gives the Dirichlet-multinomial, which allows more
  spread than the multinomial.

## In machine learning

- **Bag of words.** A document represented by its word counts over a vocabulary of size $K$ is modelled as a
  multinomial draw. <NoteLink to="naive-bayes">Multinomial naive Bayes</NoteLink> classifies documents with one $\pivec$ per class and usually outperforms the
  Bernoulli event model, which records only presence or absence <Cite id="mccallum1998" />.
- **Histograms.** The counts in the bins of a histogram of $n$ independent samples are multinomial, with $\pi_k$ the
  probability of bin $k$. Goodness-of-fit tests compare observed counts with $n\pivec$.

## Pitfalls

- **Treating counts as independent.** With $n$ fixed, the counts are negatively correlated. <NoteLink to="standard-error">Standard errors</NoteLink> that treat
  each $x_k$ as an independent binomial or Poisson ignore this, which matters when a few categories dominate.
- **Burstiness.** Words recur within a document far more than a multinomial predicts: once a rare word appears, it
  tends to appear again. The Dirichlet-multinomial models this extra variance <Cite id="madsen2005" />.
- **Zero estimates.** $\hat\pi_k = 0$ for any category not observed. Smooth the estimate before using it as a model.
