<Definition>
k-means assigns each of $n$ points to one of $k$ clusters. It chooses the assignment and the cluster centres
$\muvec_1, \dots, \muvec_k$ to minimise the inertia
$J = \sum_{i=1}^{n} \norm{\xvec_i - \muvec_{c(i)}}^2$, where $c(i)$ is the cluster of point $i$.
</Definition>

## Lloyd's algorithm

Minimising $J$ exactly is NP-hard. Lloyd's algorithm alternates two steps that each reduce $J$ <Cite id="lloyd1982" />:

1. **Assign.** Put each point in the cluster whose centre is nearest.
2. **Update.** Move each centre to the mean of its assigned points.

The algorithm stops when no assignment changes. It always terminates, because $J$ decreases at every step and there
are finitely many assignments.

## Initialisation

Lloyd's algorithm finds a local minimum. The result depends on the starting centres. Random initialisation can
place two centres in one true cluster and none in another.

k-means++ picks the first centre uniformly at random. It picks each further centre with probability proportional to
its squared distance from the nearest centre already chosen. The expected inertia is then within $O(\log k)$ of the
optimum <Cite id="arthur2007" />. Running several initialisations and keeping the best is standard practice.

## Choosing k

Inertia always falls as $k$ grows. It reaches zero when $k = n$. It cannot select $k$ on its own. The elbow method
plots inertia against $k$ and picks the point where the decrease slows. The Outputs tab shows this curve. A
<NoteLink to="gaussian-mixture-model">Gaussian mixture model</NoteLink> turns the same choice into a minimisation, using
AIC or BIC.

## Assumptions

- Clusters are roughly spherical and of similar size. The Euclidean distance encodes this.
- Features are on comparable scales. Standardise features first, or large-scale features dominate the distance.
- Every point belongs to exactly one cluster. Outliers pull centres toward them.

<Callout variant="tip">
k-means is a special case of a <NoteLink to="gaussian-mixture-model">Gaussian mixture model</NoteLink>. It is the limit where every component has the same
isotropic covariance and the variance tends to zero <Cite id="bishop2006" />.
</Callout>
