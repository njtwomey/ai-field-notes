<Definition>
**Visual recognition** assigns semantic labels to images at increasing levels of detail: one class for the whole image,
a box and class for each object, a class for each pixel, or a class and an instance identity for each pixel. The
tasks share a learned backbone, a convolutional network or a vision transformer, and differ in the output head and
the loss.
</Definition>

## What it is for

Recognition is the part of <NoteLink to="computer-vision">computer vision</NoteLink> that most applications need:
tagging photos, reading medical scans, detecting pedestrians for driver assistance, counting products on shelves, and
segmenting roads and buildings in satellite images. Each application chooses the finest level of detail it needs, since
finer labels cost more to annotate and to compute. Benchmarks such as PASCAL VOC, <Gloss name="imagenet" /> and
<Gloss name="coco" /> define the tasks in practice <Cite id="everingham2010" />.

## Main ideas

**One label per image.** <NoteLink to="image-classification" /> maps pixels to class logits, applies a softmax and
trains by cross-entropy. Hand-crafted features gave way to convolutional networks in 2012 and later to transformers.
The classifier's backbone is reused by every other task.

**Boxes around objects.** <NoteLink to="object-detection" /> outputs a box, class and score for every object. Two-stage
detectors such as Faster R-CNN classify region proposals; one-stage detectors such as YOLO and SSD predict densely
from anchor boxes; both remove duplicate boxes by non-maximum suppression. DETR predicts the set of objects directly
with a transformer.

**A class for every pixel.** <NoteLink to="semantic-segmentation" /> maps an image to a class score map of the same
size. Encoder–decoder networks such as U-Net restore resolution with upsampling and skip connections; dilated
convolutions avoid losing it. <NoteLink to="instance-and-panoptic-segmentation" /> separates individual objects of the
same class: Mask R-CNN adds a mask head to a detector, and panoptic segmentation labels every pixel with a class and,
for countable objects, an instance.

**Images as sequences of patches.** The <NoteLink to="vision-transformer" /> (ViT) cuts an image into patches, embeds
each patch as a token and runs a transformer encoder. It lacks the locality bias of convolution and so needs large
pretraining sets, but then matches or exceeds convolutional networks <Cite id="dosovitskiy2021" />.

## How the notes fit together

Start with <NoteLink to="image-classification" />. Object detection and semantic segmentation each extend it in one
direction, boxes or pixels, and can be read in either order. Instance and panoptic segmentation combine the two and
come after both. The vision transformer note changes the backbone rather than the task and can be read at any point
after classification.
