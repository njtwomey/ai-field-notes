<Definition>
**State-space control** designs feedback for a linear system written as $\dot{\xvec} = \Amat\xvec + \Bmat\uvec$,
$\yvec = \Cmat\xvec$, with state $\xvec \in \reals^n$, input $\uvec \in \reals^m$ and output $\yvec \in \reals^p$. The
controller feeds back the state, or an estimate of it, through a gain matrix. The approach handles several inputs and
outputs in one framework and rests on two structural properties, controllability and observability, introduced by
Kalman <Cite id="kalman1960c" />.
</Definition>

## What it is for

Classical design works one loop at a time on a <NoteLink to="transfer-function-and-block-diagrams">transfer
function</NoteLink>. A plant with coupled inputs and outputs, such as an aircraft, a robot arm or an inverted pendulum
on a cart, needs a method that treats the whole state at once. State feedback $\uvec = -\Kmat\xvec$ changes the dynamics
matrix to $\Amat - \Bmat\Kmat$, so the designer chooses the closed-loop eigenvalues directly <Cite id="astrom2021" />.
When some states are not measured, an observer reconstructs them from the outputs.

The same structure appears in machine learning. A Kalman filter is an observer whose gain is chosen for noise, not for
pole locations. Observability is the condition under which the hidden state of a linear-Gaussian
<NoteLink to="kalman-filter">state-space model</NoteLink> can be recovered from its outputs.

## Main ideas

**Not every state can be steered or seen.** A system is controllable if some input moves any state to any other, and
observable if the outputs determine the initial state.
<NoteLink to="controllability-and-observability" /> gives Kalman's rank tests on the matrices
$[\Bmat\; \Amat\Bmat\; \cdots\; \Amat^{n-1}\Bmat]$ and $[\Cmat; \Cmat\Amat; \dots; \Cmat\Amat^{n-1}]$, the mode-by-mode
PBH test, and the Kalman decomposition into controllable, observable and hidden parts.

**Controllability means the poles can go anywhere.** If $(\Amat, \Bmat)$ is controllable, state feedback can place the
closed-loop eigenvalues at any set closed under complex conjugation. <NoteLink to="pole-placement" /> derives the gain,
including Ackermann's formula for one input, and balances an inverted pendulum. The choice of pole locations trades
speed against input size and noise sensitivity.

**Observability means the estimate can converge at any rate.** A Luenberger
<NoteLink to="state-observer" /> runs a copy of the model and corrects it with the output error through a gain
$\Lmat$. Its error obeys $\dot{\evec} = (\Amat - \Lmat\Cmat)\evec$, and observability lets $\Lmat$ place these
eigenvalues anywhere. Observer design is the dual of state-feedback design, with $\Amat^\top$ and $\Cmat^\top$ in
place of $\Amat$ and $\Bmat$.

**Estimation and control separate.** Feeding back the estimate in place of the true state gives a closed loop whose
eigenvalues are those of $\Amat - \Bmat\Kmat$ together with those of $\Amat - \Lmat\Cmat$. The two gains can be
designed independently. <NoteLink to="state-observer" /> proves this separation principle.

## How the notes fit together

Read the three notes in order: <NoteLink to="controllability-and-observability" />, then
<NoteLink to="pole-placement" />, then <NoteLink to="state-observer" />. Each depends on the one before.

Pole placement answers where the poles can go but not where they should go. <NoteLink to="optimal-control" /> answers
the second question: the <NoteLink to="linear-quadratic-regulator" /> chooses $\Kmat$ by minimising a quadratic cost,
and <NoteLink to="linear-quadratic-gaussian-control" /> pairs it with a Kalman-filter observer, a stochastic version of
the separation principle. <NoteLink to="subspace-identification" /> uses the observability matrix to estimate a
<Gloss name="state-space-model">state-space model</Gloss> from data.
