<Definition>
Sort the calibration cases by classifier score, $s_1 \le s_2 \le \dots \le s_n$, with labels $y_i \in \set{0, 1}$.
**<NoteLink to="isotonic-regression">Isotonic regression</NoteLink>** finds values $\mu_1, \dots, \mu_n$ that solve

$$
\min_{\mu} \sum_{i=1}^n (\mu_i - y_i)^2 \quad \text{subject to} \quad \mu_1 \le \mu_2 \le \dots \le \mu_n.
$$

**Isotonic calibration** maps a new score to the fitted value of the calibration case with the nearest score below it,
giving a non-decreasing step function from score to probability <Cite id="zadrozny2002" />.
</Definition>

## Problem

A parametric <NoteLink to="classifier-calibration">calibration map</NoteLink> assumes a shape: a sigmoid for
<NoteLink to="platt-scaling">Platt scaling</NoteLink>, a beta-derived curve for <NoteLink to="beta-calibration">beta
calibration</NoteLink>. A model whose distortion has another shape stays miscalibrated. The only assumption that holds
for nearly every scoring classifier is that a higher score should never mean a lower probability. Isotonic calibration
assumes that and nothing else.

## Mechanism

**Pool adjacent violators (PAV).** Process the sorted cases from left to right, keeping a stack of blocks, each with a
value and a weight (its number of cases). Push each new case as a block of weight 1 with value $y_i$. While the top
block has a lower value than the block below it, pop both and push one block with their weighted mean. At the end every
case takes its block's value <Cite id="ayer1955" />. Each case is pushed once and popped at most once, so after sorting
the algorithm takes $O(n)$ time.

**Adjacent violators share a value at the optimum.** Suppose adjacent cases have $y_i > y_{i+1}$, and suppose an optimal
solution had $\mu_i < \mu_{i+1}$. Raise $\mu_i$ and lower $\mu_{i+1}$ by a small $\varepsilon$. The order constraints
still hold, and the objective changes by

$$
2\varepsilon\brack{(\mu_i - y_i) - (\mu_{i+1} - y_{i+1})} + O(\varepsilon^2) = 2\varepsilon\brack{(\mu_i - \mu_{i+1}) - (y_i -
y_{i+1})} + O(\varepsilon^2),
$$

which is negative because $\mu_i - \mu_{i+1} < 0$ and $y_i - y_{i+1} > 0$. That contradicts optimality, so
$\mu_i = \mu_{i+1}$. Two cases forced to share a value $\mu$ contribute
$(\mu - y_i)^2 + (\mu - y_{i+1})^2 = 2(\mu - \bar y)^2 + \text{const}$, with $\bar y$ their mean, so they act as one
case of weight 2 at $\bar y$. The same argument applies to adjacent blocks with weights, and repeating it until no
violation remains gives the PAV solution.

<PavSteps />

**Optimal for every proper score.** The PAV solution minimises squared error by construction. Brümmer and du Preez
proved more: among all non-decreasing maps, it simultaneously minimises every binary proper
<NoteLink to="proper-scoring-rule">scoring rule</NoteLink> on the calibration data, including
<NoteLink to="cross-entropy-and-perplexity">log loss</NoteLink> <Cite id="brummer2013" />. The same step function is the
best monotone calibration however the probabilities will be scored.

**Equivalence with the ROC convex hull.** Each block of the PAV solution corresponds to a segment of the convex hull of
the empirical ROC curve, and each hull segment to a block <Cite id="fawcett2007" />. A block with $n_+$ positives and
$n_-$ negatives has value $n_+/(n_+ + n_-)$. The matching hull segment has slope $r = (n_+/N_+)/(n_-/N_-)$, with
$N_+$ and $N_-$ the class totals, and with $\pi = N_+/(N_+ + N_-)$,

$$
\frac{\pi r}{\pi r + (1 - \pi)} = \frac{n_+ N_- / n_-}{n_+ N_-/n_- + N_-} = \frac{n_+}{n_+ + n_-},
$$

the block value. The concavities of the ROC curve are exactly the violations that PAV pools (see
<NoteLink to="receiver-operating-characteristic-convex-hull">ROC convex hull</NoteLink>).

## Cost

Sorting takes $O(n \log n)$ and PAV $O(n)$. Prediction is a binary search over the block boundaries. The map has as many
free values as it has blocks, up to one per distinct score, so it needs far more calibration data than a two- or
three-parameter map. With small calibration sets it overfits: blocks at the ends contain few cases and take values 0
or 1. Niculescu-Mizil and Caruana found Platt scaling better than isotonic regression for every learner they tested when
the calibration set was below roughly 200 to 1000 cases, and isotonic regression as good or better with more data
<Cite id="niculescumizil2005" />.

## Trade-offs

- **Ties.** The step function gives every case in a block the same probability. Cases that the model ranked apart
  become tied, so AUC on the calibrated scores can be slightly lower than on the raw scores.
- **Probabilities of 0 and 1.** End blocks that contain only one class get values exactly 0 or 1. Under log loss one
  wrong prediction there costs infinity. Clip the map to $[\varepsilon, 1 - \varepsilon]$ or use Laplace-smoothed block
  values.
- **Monotone only.** A model whose <NoteLink to="reliability-diagrams-and-consistency-bars">calibration curve</NoteLink>
  genuinely decreases somewhere, which is rare, cannot be fitted.
- **Multiclass.** Isotonic regression has no direct multiclass form, because the ordering it relies on is between two
  classes. The usual approach calibrates each class against the rest and renormalises <Cite id="zadrozny2002" />.

## Worked example

Eight calibration cases, sorted by score, have labels $0, 1, 0, 0, 1, 1, 0, 1$. PAV proceeds:

1. Push $0$. Push $1$: no violation.
2. Push $0$: $1 > 0$, pool to $\set{1, 0}$ with value $0.5$. Now $0 \le 0.5$: stop.
3. Push $0$: $0.5 > 0$, pool to $\set{1, 0, 0}$ with value $1/3$. Now $0 \le 1/3$: stop.
4. Push $1$, push $1$: no violations.
5. Push $0$: $1 > 0$, pool to value $0.5$. Then $1 > 0.5$, pool to $\set{1, 1, 0}$ with value $2/3$. Now $1/3 \le 2/3$:
   stop.
6. Push $1$: no violation.

The fitted values are $0, \tfrac13, \tfrac13, \tfrac13, \tfrac23, \tfrac23, \tfrac23, 1$, with squared error $4/3$ and
mean log loss $0.477$. Every block value is the fraction of positives in the block, so the fit is calibrated on these
eight cases by construction.
