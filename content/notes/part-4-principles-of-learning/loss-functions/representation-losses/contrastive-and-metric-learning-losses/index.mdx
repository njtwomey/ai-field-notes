<Definition>
**Contrastive and metric-learning losses** train a map $f$ from inputs to an embedding space so that a fixed distance in
that space, usually Euclidean or cosine, reflects similarity in the task. Matching items, such as two photographs of one
face, should land close together, and non-matching items far apart. The losses differ in what each example is compared
with: other examples, learned class representatives or a set of candidates.
</Definition>

## What it is for

Face verification, person re-identification, image and text retrieval, recommendation and few-shot classification all
compare new items with each other rather than assigning them to a fixed set of classes. A classifier trained on known
classes cannot score a face it has never seen. An embedding trained with these losses can, because comparison needs only
a distance. The same embeddings feed <NoteLink to="k-nearest-neighbours" /> and <Gloss name="ann-search">approximate
nearest-neighbour search</Gloss> at scale.

## Main ideas

**A learned distance is a fixed distance after a learned map.** <NoteLink to="metric-learning" /> starts from a
Mahalanobis distance $d_{\Mmat}(\xvec, \xvec') = \sqrt{(\xvec - \xvec')^\top \Mmat (\xvec - \xvec')}$ with $\Mmat =
\Lmat^\top \Lmat$, which is Euclidean distance after the linear map $\Lmat$. Neighbourhood components analysis and large
margin nearest neighbour learn $\Lmat$ from labelled data <Cite id="weinberger2009b" />. Deep metric learning replaces
$\Lmat$ by a neural network.

**Margins prevent collapse.** A loss that only pulls matching pairs together is minimised by mapping everything to one
point. <NoteLink to="triplet-and-margin-losses" /> covers the pair loss, which also pushes non-matching pairs beyond a
margin, and the triplet loss, which asks an anchor to be closer to a positive than to a negative by a margin. Most
triplets satisfy the margin early in training, so the choice of hard or semi-hard negatives decides how fast the loss
learns.

**Compare with class representatives.** Sampling informative pairs and triplets is costly.
<NoteLink to="proxy-and-classification-based-metric-losses" /> compares each example with one learned vector per class.
A softmax classifier with normalised weights and features is such a loss, and CosFace and ArcFace add an angular margin
to the true class. Under a common training setup, a benchmark found the 2006 pair loss, the triplet loss and ArcFace
within a few points of each other, so many reported gains between these losses reflect differences in training setup
<Cite id="musgrave2020" />.

**Pick the match out of a set.** The InfoNCE loss treats each matching pair as the correct class in a softmax over one
positive and many negatives, with similarities divided by a temperature. It is the loss of
<NoteLink to="contrastive-learning" />, where the two items are augmented views of one input, and of two-tower retrieval
models, covered in <NoteLink to="contrastive-losses-for-retrieval" />.
