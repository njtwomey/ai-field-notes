<Definition>
**Classification metrics** score a classifier's hard predictions against true labels. Every metric in this topic is a
function of the counts in the <NoteLink to="confusion-matrix" />: how often each true class received each predicted
class. The metrics differ in which cells they use, how they weight the classes and whether they correct for agreement
by chance.
</Definition>

## What it is for

A classifier deployed at a fixed threshold makes decisions, and the confusion matrix records the outcome of those
decisions on a test set. The metrics here turn that matrix into one number for model comparison, monitoring or
reporting. The choice of number changes conclusions. On a test set with 1% positives, a classifier that always
predicts the negative class has 99% accuracy, a balanced accuracy of 50%, a recall of 0 and a Matthews correlation of
0. Medical screening, fraud detection, information retrieval and annotation studies each favour different metrics for
this reason <Cite id="sokolova2009" />.

## Main ideas

**Rates within a true class and rates within a predicted class.** Dividing a cell by its row total gives a rate within
a true class, such as sensitivity or specificity. Dividing by its column total gives a rate within a predicted class,
such as precision or the negative predictive value. Rates of the first kind are properties of the classifier. Rates of
the second kind also depend on the prevalence of each class, through Bayes' theorem. The note
<NoteLink to="sensitivity-specificity-and-predictive-values" /> develops both, with likelihood ratios.

**Imbalance and the trivial classifier.** <NoteLink to="accuracy-and-balanced-accuracy" /> shows that accuracy is a
prevalence-weighted average of per-class recalls, so the majority class dominates it. Balanced accuracy weights the
classes equally. <NoteLink to="precision-recall-and-f-score" /> covers metrics that ignore <Gloss name="tn">true
negatives</Gloss> altogether and combine precision and recall by a harmonic mean, the $F_\beta$ score.

**Correlation and chance correction.** The <NoteLink to="matthews-correlation-coefficient" /> is the
<NoteLink to="pearson-correlation">Pearson correlation</NoteLink> between predicted and true labels, so it uses all four
cells and is 0 for a classifier no better than chance. <NoteLink to="cohens-kappa" /> compares observed agreement with
the agreement expected by chance from the marginal totals, and its weighted form gives partial credit for near misses.
Informedness and markedness, defined in the sensitivity note, are the chance-corrected versions of the row and column
rates <Cite id="powers2011" />.

**More than two classes.** A binary metric extends to $K$ classes by scoring each class against the rest. The
<NoteLink to="averaging-multiclass-metrics" /> note shows that micro, macro and weighted averages of the same per-class
scores can differ widely on imbalanced data. Multi-label predictions, where each example has a set of labels, are scored
by <NoteLink to="hamming-jaccard-and-exact-match" />. Ordered classes need metrics that charge an error by its size,
covered in <NoteLink to="ordinal-classification-metrics" />.

## How the notes fit together

Start with the <NoteLink to="confusion-matrix" />, which every other note requires. Sensitivity, specificity and the
predictive values come next, because they define the rates the later notes combine. Accuracy, the F-score, the
Matthews correlation and kappa are four ways to reduce the matrix to one number. The averaging, multi-label and ordinal
notes extend the binary metrics to other label structures.
