<Definition>
Logistic regression predicts $P(y = 1 \mid \xvec) = \sigma(\wvec^\top\xvec + b)$ for a binary label
$y \in \{0, 1\}$. The logistic function is $\sigma(z) = 1 / (1 + e^{-z})$. It maps any real score to $(0, 1)$
<Cite id="cox1958" />.
</Definition>

## Model

The score $z = \wvec^\top\xvec + b$ is the log-odds of the positive class:
$z = \log \frac{p}{1 - p}$. Each weight is the change in log-odds per unit change of its feature.

<SigmoidExplorer />

## Decision boundary

The model predicts class 1 when $p \geq 0.5$, which is when $z \geq 0$. The boundary $\wvec^\top\xvec + b = 0$
is a hyperplane. Logistic regression is therefore a linear classifier.

## Objective

Fitting maximises the likelihood of the labels. This is the same as minimising the mean cross-entropy:

$$
L(\wvec, b) = -\frac{1}{n}\sum_{i=1}^{n} \big[y_i \log p_i + (1 - y_i)\log(1 - p_i)\big]
$$

The loss is convex in $(\wvec, b)$. Any local minimum is the global minimum <Cite id="bishop2006" />. There is
no closed-form solution. <NoteLink to="gradient-descent">Gradient descent</NoteLink> or <NoteLink to="newtons-method">Newton's method</NoteLink> finds it.

<LossSurfaceExplorer />

<Derivation title="Gradient of the cross-entropy">
With $p_i = \sigma(z_i)$ and $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, the <NoteLink to="derivative">derivative</NoteLink> of one term with respect to
$z_i$ simplifies to $p_i - y_i$. By the chain rule, $\nabla_\wvec L = \frac{1}{n} X^\top(\pvec - \yvec)$.

This has the same form as the <NoteLink to="linear-regression">linear-regression</NoteLink> <NoteLink to="gradient">gradient</NoteLink>, with predictions passed through $\sigma$.
</Derivation>

## Separable data

If a hyperplane separates the classes perfectly, the likelihood has no maximum. The weights grow without bound as
the fit sharpens. An L2 penalty $\tfrac{\lambda}{2}\norm{\wvec}^2$ keeps the weights finite.

<Callout variant="warning">
Predicted probabilities are only calibrated when the model is well specified. A strong penalty or a missing
feature shifts them, even when accuracy is unchanged.
</Callout>
