<Definition>
A covariance function is a symmetric function $k : \Xcal \times \Xcal \to \reals$ such that the <NoteLink to="kernel-trick">Gram matrix</NoteLink>
$\Kmat_{ij} = k(\xvec_i, \xvec_j)$ is <Gloss name="positive-semi-definite">positive semi-definite</Gloss> for every finite set of inputs
<Cite id="rasmussen2006" />. It is the covariance $k(\xvec, \xvec') = \cov[f(\xvec), f(\xvec')]$ of a
<NoteLink to="gaussian-process">Gaussian process</NoteLink>. A covariance function is stationary when it depends only on
$\xvec - \xvec'$, and isotropic when it depends only on the distance $r = \norm{\xvec - \xvec'}$.
</Definition>

## Intuition

The covariance function is the whole prior of a zero-mean Gaussian process. Its value at $r = 0$ is the variance of
$f$ at one input. Its decay with $r$ sets how far information from one observation reaches. Its behaviour near
$r = 0$ sets how rough the sample functions are.

## Common covariance functions

Each kernel below has a signal variance $\sigma_f^2$, the variance of $f(\xvec)$, and a length-scale $\ell > 0$, the
distance over which correlation decays. The table writes $r = \norm{\xvec - \xvec'}$.

| Kernel | $k(\xvec, \xvec')$ | Sample paths |
| --- | --- | --- |
| Squared exponential | $\sigma_f^2 \exp\paren{-\dfrac{r^2}{2\ell^2}}$ | infinitely differentiable |
| Matérn, $\nu = 1/2$ | $\sigma_f^2 \exp\paren{-\dfrac{r}{\ell}}$ | continuous, not differentiable |
| Matérn, $\nu = 3/2$ | $\sigma_f^2 \paren{1 + \dfrac{\sqrt 3 r}{\ell}} \exp\paren{-\dfrac{\sqrt 3 r}{\ell}}$ | once differentiable |
| Matérn, $\nu = 5/2$ | $\sigma_f^2 \paren{1 + \dfrac{\sqrt 5 r}{\ell} + \dfrac{5r^2}{3\ell^2}} \exp\paren{-\dfrac{\sqrt 5 r}{\ell}}$ | twice differentiable |
| Rational quadratic | $\sigma_f^2 \paren{1 + \dfrac{r^2}{2\alpha\ell^2}}^{-\alpha}$ | infinitely differentiable, many scales |
| Periodic | $\sigma_f^2 \exp\paren{-\dfrac{2\sin^2(\pi r / p)}{\ell^2}}$ | smooth, period $p$ |
| Linear | $\sigma_b^2 + \sigma_v^2\, \xvec^\top\xvec'$ | straight lines (planes) |

### Squared exponential

The squared exponential kernel, also called the Gaussian or RBF kernel, is the default in many libraries. Its
correlation at distance $r = \ell$ is $e^{-1/2} = 0.607$, and at $r = 3\ell$ it is $e^{-4.5} = 0.011$. Its sample
functions have <NoteLink to="derivative">derivatives</NoteLink> of every order. That smoothness is often too strong for physical data, and it makes the
Gram matrix badly conditioned when inputs are dense relative to $\ell$.

### The Matérn family

The Matérn class adds a smoothness parameter $\nu > 0$ <Cite id="stein1999" />:

$$
k_\nu(r) = \sigma_f^2\, \frac{2^{1-\nu}}{\Gamma(\nu)} \paren{\frac{\sqrt{2\nu}\, r}{\ell}}^{\nu} K_\nu\paren{\frac{\sqrt{2\nu}\, r}{\ell}},
$$

where $\Gamma$ is the <NoteLink to="gamma-function">gamma function</NoteLink> and $K_\nu$ is the modified Bessel function of the second kind. Sample paths are
$k$ times mean-square differentiable exactly when $\nu > k$. For half-integer $\nu = p + 1/2$ the Bessel function
reduces to an exponential times a polynomial of degree $p$ in $r$, which gives the closed forms in the table. The case
$\nu = 1/2$ is the covariance of the <NoteLink to="ornstein-uhlenbeck-process">Ornstein–Uhlenbeck process</NoteLink>. As $\nu \to \infty$ the Matérn kernel converges to the
squared exponential. At $r = \ell$ the correlations are $0.368$ for $\nu = 1/2$, $0.483$ for $\nu = 3/2$ and $0.524$
for $\nu = 5/2$, rising toward the squared exponential's $0.607$. Rasmussen and Williams recommend $\nu = 3/2$ or
$5/2$ for most regression problems, since larger values are hard to distinguish from the squared exponential with
finite noisy data <Cite id="rasmussen2006" />.

### Rational quadratic

The rational quadratic kernel is a scale mixture of squared exponential kernels. Let the inverse squared length-scale
$\tau = 1/\ell'^2$ follow a <NoteLink to="gamma-distribution">gamma distribution</NoteLink> with shape $\alpha$ and rate $\beta = \alpha\ell^2$, so that
$\expect[\tau] = 1/\ell^2$. Averaging the squared exponential over $\tau$ gives

$$
\int_0^\infty e^{-\tau r^2/2}\, \frac{\beta^\alpha \tau^{\alpha - 1} e^{-\beta\tau}}{\Gamma(\alpha)}\, d\tau
= \frac{\beta^\alpha}{(\beta + r^2/2)^\alpha} = \paren{1 + \frac{r^2}{2\alpha\ell^2}}^{-\alpha},
$$

using $\int_0^\infty \tau^{\alpha-1} e^{-c\tau}\, d\tau = \Gamma(\alpha)/c^\alpha$ with $c = \beta + r^2/2$. Small
$\alpha$ gives a wide spread of length-scales. As $\alpha \to \infty$ the gamma distribution concentrates at $1/\ell^2$
and the kernel becomes the squared exponential. For $\alpha = 2$, $\ell = 1$ and $r = 1$ the kernel equals
$(1 + 1/4)^{-2} = 0.64$.

### Periodic

MacKay's periodic kernel maps a scalar input onto a circle and applies a squared exponential kernel there
<Cite id="mackay1998" />. Let $\uvec(x) = (\cos(2\pi x / p), \sin(2\pi x / p))$ for period $p$. Then

$$
\norm{\uvec(x) - \uvec(x')}^2 = 2 - 2\cos\paren{\frac{2\pi (x - x')}{p}} = 4\sin^2\paren{\frac{\pi (x - x')}{p}},
$$

using $\cos a\cos b + \sin a\sin b = \cos(a - b)$ and $1 - \cos 2\theta = 2\sin^2\theta$. Substituting into
$\exp(-\norm{\uvec - \uvec'}^2 / 2\ell^2)$ gives the periodic kernel in the table. The kernel is valid because it is a
valid kernel applied to transformed inputs. Values exactly one period apart have correlation 1, so the prior contains
only exactly periodic functions.

### Linear

The linear kernel $k(\xvec, \xvec') = \sigma_b^2 + \sigma_v^2\,\xvec^\top\xvec'$ is the covariance of
$f(\xvec) = b + \wvec^\top\xvec$ with $b \sim \Gauss(0, \sigma_b^2)$ and $\wvec \sim \Gauss(\zeros, \sigma_v^2\eye)$
independent: $\cov[f(\xvec), f(\xvec')] = \var[b] + \xvec^\top\cov[\wvec]\xvec'$. A Gaussian process with this kernel
is <NoteLink to="bayesian-linear-regression">Bayesian linear regression</NoteLink>. The kernel is not stationary, since the variance $\sigma_b^2 + \sigma_v^2\norm{\xvec}^2$
grows with distance from the origin.

## Building new kernels

Sums and products of covariance functions are covariance functions. Let $f_1 \sim \GP(0, k_1)$ and
$f_2 \sim \GP(0, k_2)$ be independent.

- **Sum.** $g = f_1 + f_2$ has covariance
  $\cov[g(\xvec), g(\xvec')] = k_1(\xvec, \xvec') + k_2(\xvec, \xvec')$, because the cross terms vanish by
  <NoteLink to="independence">independence</NoteLink>. A sum models a function as the superposition of independent components, such as a trend plus
  short-scale variation.
- **Product.** $h = f_1 f_2$ has zero mean and covariance
  $\expect[f_1(\xvec)f_2(\xvec)f_1(\xvec')f_2(\xvec')] = \expect[f_1(\xvec)f_1(\xvec')]\,\expect[f_2(\xvec)f_2(\xvec')] = k_1 k_2$,
  again by independence. The product is a valid covariance even though $h$ is not Gaussian. A product acts like an
  "and": $k_1 k_2$ is large only where both factors are. A squared exponential times a periodic kernel gives a
  locally periodic function whose repeating shape drifts over a distance set by the squared exponential's
  length-scale.
- **Scaling and warping.** $a\,k$ for $a > 0$, and $k(\gvec(\xvec), \gvec(\xvec'))$ for any map $\gvec$, are
  covariance functions. The periodic kernel is an instance of warping.

Searching over sums and products of a few base kernels by <NoteLink to="law-of-total-probability">marginal likelihood</NoteLink> can recover interpretable structure,
such as trend plus yearly cycle plus noise, from a time series <Cite id="duvenaud2013" />.

## Stationarity and the spectrum

Bochner's theorem characterises stationary kernels on $\reals^D$: a continuous stationary function
$k(\xvec - \xvec')$ is positive semi-definite exactly when it is the <NoteLink to="fourier-transform">Fourier transform</NoteLink> of a finite non-negative measure,
its spectral density $S(\svec)$ <Cite id="rasmussen2006" />. The squared exponential kernel has a Gaussian spectral
density with standard deviation $1/(2\pi\ell)$ in frequency, so it has almost no power at high frequency, which is why
its samples are so smooth. The Matérn kernel has spectral density proportional to
$(2\nu/\ell^2 + 4\pi^2\norm{\svec}^2)^{-(\nu + D/2)}$, a power-law tail whose exponent grows with $\nu$. Sampling
frequencies from the spectral density gives <NoteLink to="random-fourier-features">random Fourier features</NoteLink>.

## Assumptions

- **Stationarity.** A stationary kernel assumes the same smoothness and variance everywhere. Data whose behaviour
  changes across the input space need a non-stationary kernel, an input warping, or a sum of kernels.
- **One length-scale per kernel.** An isotropic kernel treats all input dimensions alike. Separate length-scales per
  dimension relax this.

## Pitfalls

- **Invalid combinations.** Differences of kernels, and ad hoc similarity functions such as a truncated distance, are
  not positive semi-definite in general. The Gram matrix then has negative eigenvalues and the <NoteLink to="cholesky-decomposition">Cholesky factorisation</NoteLink>
  fails.
- **Oversmooth defaults.** The squared exponential prior rules out kinks. When the data have them, the fitted
  length-scale shrinks to accommodate them, and predictions elsewhere become noisy. A Matérn kernel usually fits
  better.
- **Strict periodicity.** The pure periodic kernel extrapolates the same cycle forever. Multiply it by a squared
  exponential when the pattern can change.
