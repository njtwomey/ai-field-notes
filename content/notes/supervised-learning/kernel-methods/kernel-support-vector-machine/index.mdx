<Definition>
A kernel support vector machine solves the dual of the soft-margin SVM with the inner products replaced by a positive
semi-definite kernel $k$ <Cite id="boser1992" />:

$$
\max_{\alphavec}\ \sum_{i=1}^{N}\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_j y_i y_j\, k(\xvec_i, \xvec_j)
\quad \text{subject to} \quad 0 \le \alpha_i \le C,\ \ \sum_i \alpha_i y_i = 0.
$$

It classifies a new input by the sign of $f(\xvec) = \sum_i \alpha_i y_i\, k(\xvec_i, \xvec) + b$. The sum runs over
the support vectors, the training points with $\alpha_i > 0$.
</Definition>

## Intuition

A linear <NoteLink to="support-vector-machine">support vector machine</NoteLink> draws a hyperplane. Mapping the inputs
through a feature map $\phivec$ first and drawing the hyperplane in feature space gives a curved boundary in the input
space. The SVM dual needs the data only through inner products $\phivec(\xvec_i)^\top\phivec(\xvec_j)$, so the
<NoteLink to="kernel-trick">kernel trick</NoteLink> applies: a kernel $k(\xvec_i, \xvec_j) = \phivec(\xvec_i)^\top\phivec(\xvec_j)$
computes them without ever forming $\phivec$. The feature space can be infinite-dimensional, as it is for the Gaussian
kernel.

With the Gaussian kernel $k(\xvec, \xvec') = \exp(-\norm{\xvec - \xvec'}^2/2\ell^2)$, the decision function is a sum of
Gaussian bumps centred on the support vectors, positive bumps for class $+1$ and negative for class $-1$. The
boundary is where the two kinds of bump balance.

## Details

### The problem in feature space

The primal problem in feature space is the linear SVM with $\xvec_i$ replaced by $\phivec(\xvec_i)$:
minimise $\frac12\norm{\wvec}^2 + C\sum_i\xi_i$ subject to $y_i(\wvec^\top\phivec(\xvec_i) + b) \ge 1 - \xi_i$ and
$\xi_i \ge 0$. The Lagrangian derivation of the linear SVM goes through unchanged. Stationarity gives
$\wvec = \sum_i \alpha_i y_i \phivec(\xvec_i)$, so

$$
f(\xvec) = \wvec^\top\phivec(\xvec) + b = \sum_i \alpha_i y_i\,\phivec(\xvec_i)^\top\phivec(\xvec) + b = \sum_i \alpha_i y_i\, k(\xvec_i, \xvec) + b,
$$

and the dual is the problem in the definition. The weight vector $\wvec$ may be infinite-dimensional and is never
formed. Its squared norm is available through the kernel as
$\norm{\wvec}^2 = \sum_{i,j}\alpha_i\alpha_j y_i y_j k(\xvec_i, \xvec_j)$, and the geometric margin in feature space is
$1/\norm{\wvec}$.

The kernel must be positive semi-definite. Then the matrix $\Qmat$ with entries $y_i y_j k(\xvec_i, \xvec_j)$ is
positive semi-definite, because $\cvec^\top\Qmat\cvec = \dvec^\top\Kmat\dvec \ge 0$ with $d_i = y_i c_i$. The dual is a
concave maximisation with a unique optimal value, and every local optimum is global. With an indefinite similarity
function the dual can be unbounded and solvers can fail.

### Separability with the Gaussian kernel

With the Gaussian kernel, any labelling of $N$ distinct points is separable in feature space. The Gaussian kernel's Gram
matrix $\Kmat$ on distinct points is strictly positive definite <Cite id="scholkopf2002" />, so the system
$\Kmat\cvec = \yvec$ has a solution. The function $f(\xvec) = \sum_j c_j k(\xvec_j, \xvec)$ then satisfies
$f(\xvec_i) = y_i$, so $y_i f(\xvec_i) = 1$ for every $i$, and the hard-margin constraints hold with $b = 0$. The
flexibility is a warning as well as a strength: with a short length-scale and a large $C$ the SVM can fit any labels,
including noise.

### Kernel and $C$ together

For the Gaussian kernel the two hyperparameters interact. A short length-scale $\ell$ makes each bump narrow, so the
boundary can follow individual points. A large $C$ makes violations expensive, so the boundary will follow them. Both
push toward overfitting, and the good settings lie along a diagonal ridge in the $(\ln\ell, \ln C)$ plane. The
standard practice is a grid search over both on logarithmic scales, scored by cross-validation, after standardising
the features. Libraries often write the kernel as $\exp(-\gamma\norm{\xvec - \xvec'}^2)$, with
$\gamma = 1/(2\ell^2)$.

### Worked example: XOR with a polynomial kernel

Take the four points $(\pm1, \pm1)$ with label $y = x_1x_2$: $(1, 1)$ and $(-1, -1)$ are class $+1$, and $(1, -1)$ and
$(-1, 1)$ are class $-1$. No line separates them. Use the polynomial kernel $k(\xvec, \xvec') = (\xvec^\top\xvec' + 1)^2$.
A point with itself gives $k = (2 + 1)^2 = 9$. Two points that differ in one coordinate have $\xvec^\top\xvec' = 0$ and
$k = 1$. Opposite points have $\xvec^\top\xvec' = -2$ and $k = 1$.

The problem is symmetric under the maps that permute the four points and preserve labels, so all $\alpha_i$ are equal,
say $\alpha$. The constraint $\sum_i \alpha_i y_i = 0$ holds automatically. In the matrix
$Q_{ij} = y_iy_j k(\xvec_i, \xvec_j)$, each row has $9$ on the diagonal, $-1$ for the two neighbours (opposite labels)
and $+1$ for the opposite point (same label), so each row sums to $8$. The dual objective is
$4\alpha - \frac12\cdot 32\alpha^2$, maximised at $\alpha = 1/8$. The decision function is

$$
f(\xvec) = \frac18\brack{(x_1 + x_2 + 1)^2 + (-x_1 - x_2 + 1)^2 - (x_1 - x_2 + 1)^2 - (-x_1 + x_2 + 1)^2} = x_1 x_2,
$$

with $b = 0$, since $f$ is already $\pm 1$ on every point. All four points are support vectors, on the margin. The
boundary is the pair of axes $x_1x_2 = 0$, and $\norm{\wvec}^2 = 32/64 = 1/2$, so the margin width in feature space is
$2/\norm{\wvec} = 2\sqrt 2$.

## Cost

Training with sequential minimal optimisation <Cite id="platt1998" /> needs kernel values on demand. Its cost grows
between quadratically and cubically in $N$ in practice, and caching the $N \times N$ kernel matrix needs $O(N^2)$
memory. Prediction costs one kernel evaluation per support vector. Beyond a few hundred thousand points, approximate
the kernel with <NoteLink to="random-fourier-features">random Fourier features</NoteLink> or a Nyström basis and train a
linear SVM on the explicit features.

The same kernelised dual without labels gives the <NoteLink to="one-class-support-vector-machine">one-class SVM</NoteLink>, which
separates unlabelled data from the origin of feature space to estimate the region where the data lie.

## Assumptions

- **A positive semi-definite kernel.** Mercer's condition guarantees a feature space and a concave dual.
- **A meaningful distance.** Stationary kernels such as the Gaussian compare inputs by Euclidean distance. Features on
  different scales, or irrelevant features, distort it.

## Pitfalls

- **Unscaled inputs.** One length-scale for all features makes the kernel ignore features with small ranges.
  Standardise first.
- **Tuning $\ell$ and $C$ separately.** Because the two interact, a one-dimensional search over each with the other
  fixed can miss the good region. Search the grid jointly.
- **Dense solutions on noisy data.** Every misclassified point is a support vector with $\alpha_i = C$. On noisy data
  most points become support vectors and prediction becomes as slow as a full kernel sum.
