<Definition>
Let $B_1, B_2, \dots$ be a partition of $\Omega$: disjoint events whose union is $\Omega$, each with $P(B_i) > 0$. For
every event $A$,

$$
P(A) = \sum_i P(A \mid B_i)\, P(B_i).
$$

For <NoteLink to="random-variable">random variables</NoteLink>, $p(x) = \sum_z p(x \mid z)\, p(z)$ when $Z$ is discrete and $p(x) = \int p(x \mid z)\, p(z)\,
dz$ when $Z$ is continuous <Cite id="wasserman2004" />.
</Definition>

## Meaning

The events $A \cap B_i$ split $A$ into disjoint pieces, one per case, because the $B_i$ are disjoint and cover
$\Omega$. Additivity sums the pieces, and the product rule writes each piece as $P(A \mid B_i)\, P(B_i)$:

$$
P(A) = P\paren{\bigcup_i (A \cap B_i)} = \sum_i P(A \cap B_i) = \sum_i P(A \mid B_i)\, P(B_i).
$$
 The result is a weighted average of the conditional probabilities, with
the case probabilities as weights. $P(A)$ therefore always lies between the smallest and largest $P(A \mid B_i)$.

**Example.** A factory has two machines. Machine 1 makes 60% of the parts and 2% of its parts are defective. Machine 2
makes 40% and 5% of its parts are defective. A random part is defective with probability

$$
P(D) = 0.02 \times 0.6 + 0.05 \times 0.4 = 0.032.
$$

The simplest partition is an event and its complement: $P(A) = P(A \mid B)\,P(B) + P(A \mid B^c)\,P(B^c)$. This is the
denominator of <NoteLink to="bayes-theorem">Bayes' theorem</NoteLink>.

## Marginalisation

For random variables the partition is the set of values of $Z$. Summing or integrating a joint distribution over one
variable gives the marginal of the other:

$$
p(x) = \int p(x, z)\, dz = \int p(x \mid z)\, p(z)\, dz.
$$

The same identity holds conditionally on any further variable: $p(x \mid y) = \int p(x \mid z, y)\, p(z \mid y)\,
dz$.

## Mixtures

A model that first draws a hidden case $z$ and then draws $x$ from a distribution that depends on $z$ has, by this law,
the marginal density

$$
p(x) = \sum_{k=1}^{K} \pi_k\, p(x \mid z = k), \qquad \pi_k = P(z = k).
$$

This is a mixture distribution. A <NoteLink to="gaussian-mixture-model">Gaussian mixture model</NoteLink> is the case
where each $p(x \mid z = k)$ is Gaussian. The <NoteLink to="student-t-distribution">Student $t$ distribution</NoteLink>
is a continuous mixture: a Gaussian whose precision is itself gamma-distributed, integrated out.

<Derivation title="The Student t as a mixture of Gaussians">
Let $\lambda \sim \GammaD(\nu/2, \nu/2)$ with shape $\nu/2$ and rate $\nu/2$, and $X \mid \lambda \sim \Gauss(0,
1/\lambda)$. Marginalising $\lambda$ and keeping only the factors that depend on $x$ or $\lambda$,

$$
p(x) \propto \int_0^\infty \lambda^{1/2} e^{-\lambda x^2 / 2}\, \lambda^{\nu/2 - 1} e^{-\nu\lambda/2}\, d\lambda =
\int_0^\infty \lambda^{(\nu + 1)/2 - 1} e^{-\lambda (\nu + x^2)/2}\, d\lambda.
$$

The gamma integral $\int_0^\infty \lambda^{a - 1} e^{-c\lambda}\, d\lambda = \Gamma(a)/c^a$ gives
$p(x) \propto \paren{(\nu + x^2)/2}^{-(\nu + 1)/2} \propto \paren{1 + x^2/\nu}^{-(\nu + 1)/2}$, the Student $t$
density with $\nu$ degrees of freedom.
</Derivation>

## In machine learning

- **Marginal likelihood.** In a latent-variable model, the likelihood of the data is
  $p(\xvec) = \int p(\xvec \mid \zvec)\, p(\zvec)\, d\zvec$. The integral is usually intractable, which is the problem
  that EM, <Gloss name="vi">variational inference</Gloss> and sampling methods address.
- **Bayesian prediction.** The <NoteLink to="bayesian-inference">posterior predictive distribution</NoteLink> averages the model's predictions over the posterior:
  $p(y \mid \xvec, \Dcal) = \int p(y \mid \xvec, \theta)\, p(\theta \mid \Dcal)\, d\theta$.
- **Classification under prior shift.** $p(\xvec) = \sum_y p(\xvec \mid y)\, p(y)$ changes when the class
  proportions $p(y)$ change, even if each class looks the same.

## Pitfalls

- **The cases must partition $\Omega$.** Overlapping cases count some outcomes twice; missing cases leave out
  probability.
- **Weights come from the same population.** The $P(B_i)$ must describe the population that $A$ is asked about. Using
  case weights from a different population is the same error as ignoring base rates.
- **<NoteLink to="simpsons-paradox">Simpson's paradox</NoteLink>.** Because $P(A)$ is a weighted average, $P(A \mid B_i, C) > P(A \mid B_i, C^c)$ can hold in
  every case $B_i$ while $P(A \mid C) < P(A \mid C^c)$ overall, if $C$ changes the case weights.
