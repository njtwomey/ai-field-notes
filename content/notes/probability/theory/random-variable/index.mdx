<Definition>
Given a <NoteLink to="probability-space">probability space</NoteLink> $(\Omega, \Fcal, P)$, a random variable is a
function $X : \Omega \to \reals$ such that $\set{\omega : X(\omega) \le t}$ is an event for every $t \in \reals$. Its
distribution, or law, is the probability measure $P_X$ on $\reals$ defined by

$$
P_X(B) = P\paren{\set{\omega \in \Omega : X(\omega) \in B}} = P\paren{X^{-1}(B)}
$$

for every Borel set $B$. $P_X$ is called the push-forward of $P$ through $X$ <Cite id="wasserman2004" />.
</Definition>

## A function, not a random number

A random variable is deterministic. All the randomness lives in the outcome $\omega$; $X$ only reads a number off it.
The notation $P(X \le 3)$ is shorthand for $P\paren{\set{\omega : X(\omega) \le 3}}$, the probability of the set of
outcomes that $X$ sends to values at most 3.

For two dice, $\Omega$ has 36 equally likely outcomes $(i, j)$. The sum $X(i, j) = i + j$ is a random variable. The
event $\set{X = 4}$ is the set $\set{(1, 3), (2, 2), (3, 1)}$, so $P(X = 4) = 3/36 = 1/12$. Many outcomes map to the
same value, and the probability of a value is the total probability of the outcomes that produce it.

## The induced distribution

$P_X$ is a probability measure on $\reals$, because preimages preserve the operations that the axioms use.
$X^{-1}(\reals) = \Omega$, so $P_X(\reals) = 1$. If $B_1, B_2, \dots$ are disjoint, their preimages are disjoint, since
no outcome can map into two disjoint sets, and $X^{-1}\paren{\bigcup_i B_i} = \bigcup_i X^{-1}(B_i)$. Countable
additivity of $P$ then gives $P_X\paren{\bigcup_i B_i} = \sum_i P_X(B_i)$.

Once $P_X$ is known, the sample space can be forgotten. Every probability, expectation and variance of $X$ depends only
on $P_X$. Two random variables on different sample spaces are **identically distributed** if their laws are equal. A
fair coin flip and the parity of a fair die roll are both $\Bern(1/2)$, although their sample spaces differ.

The law is described in one of three standard ways.

- **Cumulative distribution function (cdf).** $F_X(x) = P(X \le x)$. Every random variable has one. It is
  non-decreasing, right-continuous, tends to 0 as $x \to -\infty$ and to 1 as $x \to \infty$, and determines $P_X$
  completely.
- **Probability mass function (pmf).** For a discrete $X$, $p_X(x) = P(X = x)$, and $P(X \in B) = \sum_{x \in B}
  p_X(x)$. The cdf is a staircase that jumps by $p_X(x)$ at each $x$.
- **Probability density function (pdf).** For a continuous $X$, a function $f_X \ge 0$ with $P(X \in B) = \int_B
  f_X(x)\, dx$. Then $f_X = F_X'$ wherever the derivative exists. A density can exceed 1; only its integral is a
  probability.

<Derivation title="Why every cdf has these properties">
If $x < y$, then $\set{X \le x} \subseteq \set{X \le y}$, so $F_X(x) \le F_X(y)$ by monotonicity of $P$. The events
$\set{X \le x + 1/n}$ decrease to $\set{X \le x}$ as $n \to \infty$. Countable additivity implies that probabilities
of a decreasing sequence of events converge to the probability of their intersection, which gives right-continuity.
The same continuity applied to $\set{X \le -n}$, which decrease to the empty set, and to $\set{X \le n}$, which
increase to $\Omega$, gives the limits 0 and 1.
</Derivation>

A pmf and a pdf are the same idea with different reference measures: counting measure for the pmf, length for the pdf.
Some laws have neither. A spike-and-slab prior puts probability $\pi$ on exactly zero and spreads the rest as a
Gaussian, so it is a mixture of a discrete and a continuous part. The Cantor distribution has a continuous cdf but no
density.

## Functions of random variables

If $X$ is a random variable and $g$ is a reasonable (Borel measurable) function, then $Y = g(X)$ is a random variable
too, and its law is the push-forward of $P_X$ through $g$: $P(Y \in B) = P(X \in g^{-1}(B))$.

For example, let $X \sim \Unif(0, 1)$ and $Y = X^2$. For $0 \le y \le 1$,
$F_Y(y) = P(X^2 \le y) = P(X \le \sqrt y) = \sqrt y$, so $f_Y(y) = 1/(2\sqrt y)$. Squaring pushes mass towards 0.
For a smooth invertible $g$ the same calculation gives a general formula for the density of $g(X)$; see
<NoteLink to="change-of-variables">change of variables</NoteLink>.
<NoteLink to="inverse-transform-sampling">Inverse-transform sampling</NoteLink> uses the same mechanism in reverse: it
chooses $g$ so that a uniform $X$ is pushed forward to a target distribution.

## Random vectors

A random vector $\xvec = (X_1, \dots, X_d)$ is a function $\Omega \to \reals^d$ whose components are random variables.
Its law is a distribution on $\reals^d$, described by a joint cdf, pmf or pdf. The law of one component alone is its
**marginal**, obtained by summing or integrating the others out: $f_{X_1}(x_1) = \int f(x_1, x_2)\, dx_2$.

## In machine learning

- A data point, a label, a mini-batch gradient, a model's loss on a random test point and a sample from a generative
  model are all random variables.
- A generative model such as a variational autoencoder or a normalising flow defines its output distribution as a
  push-forward: draw simple noise $\zvec$, then return $g_\theta(\zvec)$.

## Pitfalls

- **$X$ versus $x$.** $X$ is the random variable; $x$ is a value it may take. $f_X(x)$ is the density of $X$ evaluated
  at the number $x$.
- **Density values are not probabilities.** For a continuous $X$, $P(X = x) = 0$ for every $x$, whatever $f_X(x)$ is.
- **Equal in distribution is not equal.** If $X \sim \Gauss(0, 1)$, then $-X$ has the same law, yet $X \ne -X$ except
  when $X = 0$.
