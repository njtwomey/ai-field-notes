<Definition>
A **readout** maps the <NoteLink to="node-embeddings">node embeddings</NoteLink> $\hvec_v \in \reals^d$ of a graph with
node set $\Vcal$ to one graph vector $\rvec \in \reals^{d'}$ that does not depend on how the nodes are numbered. The
global readouts are the sum $\sum_{v} \hvec_v$, the mean, the elementwise maximum and attention-weighted sums.
**Hierarchical pooling** instead coarsens the graph into a smaller graph between rounds of <Gloss name="gnn">message
passing</Gloss>, by a learned soft assignment of nodes to clusters (DiffPool) or by keeping the $k$ highest-scoring
nodes (top-$k$ pooling, SAGPool), and reads out the last, smallest graph.
</Definition>

## Intuition

A <NoteLink to="message-passing-neural-network">message passing network</NoteLink> produces one vector per node.
Graph-level tasks need one output per graph: the solubility of a molecule, the class of a protein, whether a program
graph contains a bug. The readout is the step between the two. Two molecules with the same atoms listed in different
orders are the same molecule, so the readout must give them the same vector. A function with that property is called
**permutation invariant**.

The readout also decides what the graph vector can still tell apart. A sum grows with the number of nodes, so it can
count. A mean reports the proportions of node types and forgets how many nodes there are. A maximum reports which node
types occur at all. A convolutional network for images makes the same choice when it ends in global average pooling or
global max pooling (<NoteLink to="pooling-and-strides">pooling and strides</NoteLink>); the difference on graphs is that
the number of nodes varies from one input to the next, so the choice changes what the network can learn.

Hierarchical pooling keeps a second idea from image networks: shrinking the input in stages, so that later layers see
larger regions. A graph has no grid to downsample, so the coarsening itself has to be computed or learned.

## Global readouts

Let node $v$ of a graph have the embedding $\hvec_v \in \reals^d$ after the last round of message passing. The four
standard readouts are

$$
\rvec_{\text{sum}} = \sum_{v \in \Vcal} \hvec_v, \qquad
\rvec_{\text{mean}} = \frac{1}{\abs{\Vcal}} \sum_{v \in \Vcal} \hvec_v, \qquad
\rvec_{\max} = \max_{v \in \Vcal} \hvec_v, \qquad
\rvec_{\text{att}} = \sum_{v \in \Vcal} \alpha_v \hvec_v,
$$

where the maximum is taken separately in each of the $d$ coordinates. The attention weights are
$\alpha_v = \exp(s_v) / \sum_{u \in \Vcal} \exp(s_u)$ with a gate score $s_v = \wvec^\tr \hvec_v$ and a learned
$\wvec \in \reals^d$. Each is invariant for the same reason: it depends on the multiset of node vectors, and a sum, a
maximum or a softmax over a multiset does not depend on the order in which its elements are listed. The graph vector
then passes to an ordinary classifier or regressor, usually a small <Gloss name="mlp" />.

**What each readout can distinguish.** Write the readout input as a multiset $\mset{\hvec_v}$. The sum separates
$\mset{\hvec, \hvec}$ from $\mset{\hvec}$; the mean and the maximum give both the same value. The mean separates
$\mset{\avec, \bvec}$ from $\mset{\avec, \avec, \bvec}$; the maximum does not, because both contain the same distinct
elements. Xu et al. show that the sum, composed with a suitable learned map of each element, is injective on multisets
of bounded size drawn from a countable set, and that the mean and maximum are not <Cite id="xu2019" />. Zaheer et al.
prove the matching statement for sets: every continuous permutation-invariant function of a set of fixed size can be
written $\rho(\sum_{v} \phi(\hvec_v))$ <Cite id="zaheer2017" />. The
<NoteLink to="deep-sets">deep sets</NoteLink> note develops that result. The attention readout is a weighted mean, since
its weights sum to 1, so it shares the mean's blindness to graph size.

**Readouts from every layer.** A readout of the last layer only sees structure at the depth of the network. The
<NoteLink to="graph-isomorphism-network">graph isomorphism network</NoteLink> concatenates a sum readout of every layer,
from the input features up, so the classifier sees neighbourhoods of every radius <Cite id="xu2019" />. Gilmer et al.
use a learned set function (set2set, an attention model that reads the node set several times with an
<Gloss name="lstm" /> <Cite id="vinyals2016ordermatters" />) and Li et al. a gated sum <Cite id="li2016gated" />; both
remain invariant.

## Hierarchical pooling

A global readout collapses the whole graph in one step. Hierarchical pooling alternates message passing with coarsening:
after a few rounds, the graph is replaced by a smaller graph whose nodes stand for groups of the old ones, and message
passing continues on it.

**DiffPool.** Ying et al. learn a soft assignment of the $n$ nodes to $c$ clusters <Cite id="ying2018diffpool" />. Two
networks run on the same graph, with adjacency $\Amat \in \reals^{n \times n}$ and node features
$\Xmat \in \reals^{n \times f}$. An embedding network gives $\Zmat \in \reals^{n \times d}$, and a pooling network gives
logits that a row softmax turns into the assignment $\Smat \in [0, 1]^{n \times c}$, each row summing to 1. The
coarsened graph is

$$
\Xmat' = \Smat^\tr \Zmat \in \reals^{c \times d}, \qquad \Amat' = \Smat^\tr \Amat \Smat \in \reals^{c \times c}.
$$

Entry $A'_{jk} = \sum_{u, v} S_{uj} A_{uv} S_{vk}$ is the edge weight between clusters $j$ and $k$, each edge counted
with the product of its two ends' memberships. Row $j$ of $\Xmat'$ is the membership-weighted sum of the embeddings
assigned to cluster $j$. Both are differentiable in $\Smat$, so the assignment is trained by the task loss. Gradients
from the task alone gave poor assignments in the paper's experiments, so DiffPool adds two auxiliary losses: the
link-prediction loss $\norm{\Amat - \Smat\Smat^\tr}_F$, small when linked nodes share clusters, and the mean entropy of
the rows of $\Smat$, small when each node commits to one cluster. Relabelling the nodes by a permutation matrix
$\Pmat$ maps $\Amat \mapsto \Pmat\Amat\Pmat^\tr$ and, because the pooling network is equivariant,
$\Smat \mapsto \Pmat\Smat$; then $\Amat' = \Smat^\tr\Pmat^\tr\Pmat\Amat\Pmat^\tr\Pmat\Smat = \Smat^\tr\Amat\Smat$ is
unchanged, because $\Pmat^\tr\Pmat = \Imat$. The coarsened graph is therefore invariant, and so is any readout of it.

DiffPool's cost is the price of its flexibility. $\Smat$ is dense, so the coarsened adjacency $\Amat'$ is dense and the
first pooling step costs $O(n^2 c)$ time and $O(nc)$ memory per graph, where message passing costs $O(\abs{\Ecal})$. The
<NoteLink to="choosing-the-number-of-clusters">number of clusters</NoteLink> $c$ is fixed in advance, for every graph in
the data. MinCutPool replaces the two auxiliary losses by a relaxed normalised-cut objective, which ties the assignment
to <NoteLink to="spectral-clustering">spectral clustering</NoteLink> <Cite id="bianchi2020mincut" />.

**Top-$k$ pooling.** Gao and Ji keep a subset of the nodes instead <Cite id="gao2019graphunet" />. A learned vector
$\pvec \in \reals^d$ scores every node by its projection $y_v = \hvec_v^\tr \pvec / \norm{\pvec}$. The $k$ nodes with
the largest scores survive, here $k = \lceil \rho n \rceil$ for a pooling ratio $\rho \in (0, 1]$. Their embeddings are
multiplied by $\tanh(y_v)$, which lets the gradient reach $\pvec$ through the kept values, and the coarsened graph is
the subgraph induced by the kept nodes. SAGPool computes the score with a one-layer
<NoteLink to="graph-convolutional-network">graph convolution</NoteLink> instead of a fixed projection, so a node's score
depends on its neighbours <Cite id="lee2019sagpool" />. Selection costs $O(\abs{\Ecal} + n \log n)$ and keeps the graph
sparse, but it discards the dropped nodes' features entirely, and the induced subgraph can fall apart into pieces.

## Worked example

Take the four-node graph of the <NoteLink to="message-passing-neural-network">message passing</NoteLink> note, a
triangle 1–2–3 with a tail 3–4, after one round of message passing. Its scalar node embeddings are
$h = (6, 6, 10, 7)$.

- **Sum:** $6 + 6 + 10 + 7 = 29$.
- **Mean:** $29 / 4 = 7.25$.
- **Max:** $10$.
- **Attention** with gate weight $w = 0.1$: the scores are $s = (0.6, 0.6, 1.0, 0.7)$, the exponentials are
  $(1.822, 1.822, 2.718, 2.014)$ with total $8.376$, and the weights are $\alpha = (0.218, 0.218, 0.325, 0.240)$. The
  readout is $0.218 \cdot 6 + 0.218 \cdot 6 + 0.325 \cdot 10 + 0.240 \cdot 7 = 7.54$, a mean tilted towards node 3.

Now feed in two disjoint copies of the same graph as one input. Every node has the same neighbourhood as before, so the
embeddings are $(6, 6, 10, 7, 6, 6, 10, 7)$. The sum doubles to $58$. The mean stays $7.25$, the maximum stays $10$, and
the attention readout stays $7.54$, because doubling every exponential leaves the weights' ratios unchanged. Only the
sum knows the input has eight nodes.

**One DiffPool step.** Assign nodes 1 and 2 to cluster $a$, node 4 to cluster $b$, and split node 3 evenly:

$$
\Smat = \begin{pmatrix} 1 & 0 \\ 1 & 0 \\ 0.5 & 0.5 \\ 0 & 1 \end{pmatrix}, \qquad
\Amat = \begin{pmatrix} 0 & 1 & 1 & 0 \\ 1 & 0 & 1 & 0 \\ 1 & 1 & 0 & 1 \\ 0 & 0 & 1 & 0 \end{pmatrix}.
$$

The coarsened features are $\Xmat' = \Smat^\tr \hvec = (6 + 6 + 0.5 \cdot 10,\ 0.5 \cdot 10 + 7) = (17, 12)$. The
coarsened adjacency is

$$
\Amat' = \Smat^\tr \Amat \Smat = \begin{pmatrix} 4 & 1.5 \\ 1.5 & 1 \end{pmatrix}.
$$

Each entry can be read off the edges. Inside cluster $a$, edge 1–2 has both ends fully in $a$ and contributes $1$, and
edges 1–3 and 2–3 contribute $0.5$ each; every undirected edge appears twice in the symmetric $\Amat$, so
$A'_{aa} = 2(1 + 0.5 + 0.5) = 4$. Inside cluster $b$, only edge 3–4 contributes, with weight $0.5 \cdot 1$, so
$A'_{bb} = 2 \cdot 0.5 = 1$. Between the clusters, edges 1–3 and 2–3 contribute $1 \cdot 0.5$ each and edge 3–4
contributes $0.5 \cdot 1$, so $A'_{ab} = 1.5$.

The link loss compares $\Amat$ with $\Smat\Smat^\tr$, whose entry $(u, v)$ is the probability that $u$ and $v$ share a
cluster. Here $\norm{\Amat - \Smat\Smat^\tr}_F^2 = 4.75$: the largest terms are the diagonal (a node always shares its
own cluster, but $\Amat$ has no self-loops) and the pair 3–4, which are linked but share a cluster with probability
$0.5$. The entropy loss is $\ln 2 / 4 = 0.173$ nats, all of it from node 3.

**Top-$k$ pooling.** Give the four nodes the scores $y = (0.2, -0.5, 0.9, 0.4)$ and keep $k = 2$. Nodes 3 and 4
survive, scaled by $\tanh(0.9) = 0.716$ and $\tanh(0.4) = 0.380$, and the coarsened graph is the single edge 3–4. The
triangle that nodes 1 and 2 belonged to has gone.

## Practice

Most graph-level models in use from 2020 to 2026 end in a global readout. Sum or mean pooling over the last layer, or
over every layer, followed by an MLP, is the default in molecular property prediction and in the graph-level tasks of
the <NoteLink to="graph-learning-benchmarks">Open Graph Benchmark</NoteLink> <Cite id="hu2020ogb" />. Sum suits targets
that add up over the graph, such as a molecule's energy or the number of a substructure; mean suits targets that are
intensive, such as a concentration. Graph transformers add a <NoteLink to="oversquashing-and-graph-rewiring">virtual
node</NoteLink> or a class token that attends to every node and is read out instead
(<NoteLink to="graph-transformer">graph transformer</NoteLink>).

Hierarchical pooling is used far less than its literature suggests. Errica et al. found that, under one evaluation
protocol with tuned baselines, DiffPool did not consistently beat simpler models on standard graph-classification
benchmarks <Cite id="errica2020fair" />. Mesquita et al. replaced the learned clusterings of several pooling methods by
random assignments, or by clusterings of the complement graph, and saw no drop in accuracy on those benchmarks
<Cite id="mesquita2020pooling" />. The <NoteLink to="convolutional-layer">convolutional layers</NoteLink>, not the
locality of the coarsening, carried the performance there. Hierarchical pooling remains in use where the coarse graph is
itself wanted, such as graph <Gloss name="u-net" plural /> for node-level prediction that pool and then unpool
<Cite id="gao2019graphunet" />.

## Assumptions

- The target depends on the graph as a whole and not on node order, which permutation invariance builds in.
- The readout matches how the target scales with size: sum for extensive targets that grow with the number of nodes,
  mean for intensive ones, max for "does any node have this property" targets.
- For DiffPool, a fixed number of clusters suits every graph in the data, and graphs are small enough for dense
  $n \times n$ products.

## Pitfalls

- **Mean or max readout on a counting task.** A target that depends on graph size, or on how many times a pattern
  occurs, cannot be learned from mean, max or attention readouts when node embeddings repeat, as in the cycles of the
  figure.
- **Sum readout across very different sizes.** Sum readouts grow with the number of nodes. A model trained on small
  graphs and tested on much larger ones sees graph vectors outside the training range. Normalising inputs, or combining
  sum and mean readouts, reduces the shift.
- **Readout cannot repair the encoder.** If message passing gives two different graphs the same multiset of node
  embeddings, every readout gives them the same vector. The bound comes from the
  <NoteLink to="weisfeiler-leman-test">Weisfeiler–Leman test</NoteLink>, not from the readout.
- **Disconnected pooled graphs.** Top-$k$ pooling can keep nodes with no edges between them, after which message
  passing on the pooled graph has nothing to pass.
- **Assignment collapse in DiffPool.** Without the entropy term, rows of $\Smat$ stay diffuse; with too large a weight
  on it, nodes commit early to arbitrary clusters. Clusters can also stay empty, which wastes capacity without an error.
