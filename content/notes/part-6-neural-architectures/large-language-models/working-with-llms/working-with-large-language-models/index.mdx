<Definition>
**Working with a large language model** means getting a task done by controlling what the model reads and what is
done with what it writes, while its weights stay fixed. The input is a prompt, possibly with demonstrations, retrieved
documents or the results of tool calls; the output is generated text or the most probable of a set of candidate
answers <Cite id="liu2023" />.
</Definition>

## What it is for

A pretrained model large enough can perform tasks it was never trained on, given a description and a few examples in its
prompt <Cite id="brown2020" />. This makes the prompt a programming interface: classification, extraction,
summarisation, <Gloss name="qa">question answering</Gloss> and code generation can all be set up without training. The
methods here improve on a bare prompt by eliciting reasoning, supplying knowledge the model lacks, letting it act
through tools, and checking whether its output can be trusted. They are cheaper and faster to change than fine-tuning,
and they are usually tried first.

## Main ideas

**The prompt specifies the task.** <NoteLink to="prompting" /> covers instructions, demonstrations and templates, and
how the prediction is read from the output. Results depend on wording, format and the order of examples, so prompts are
evaluated like any other model choice.

**Demonstrations teach without gradient steps.** <NoteLink to="in-context-learning" /> is a model performing a task from
examples in its prompt with fixed weights. One account treats it as <NoteLink to="bayesian-inference">Bayesian
inference</NoteLink> of a latent task; one mechanism is the induction head, which copies what followed an earlier
occurrence of a token.

**Writing the steps helps.** <NoteLink to="chain-of-thought" /> prompts the model to write intermediate reasoning
before its answer. Self-consistency samples several chains and returns the most common answer, an estimate of the
most probable answer marginalised over reasoning paths.

**Retrieval supplies knowledge.** <NoteLink to="retrieval-augmented-generation" /> conditions generation on passages
retrieved for the input, treating the passage as a latent variable. It grounds answers in sources the model can
quote and keeps knowledge current without retraining.

**Tools and loops let the model act.** In <NoteLink to="tool-use-and-agents" /> the model emits structured calls that
a runtime executes, and the results are appended to its context. An agent repeats this loop of reasoning, action and
observation until the task is done.

**Fluent output can be wrong.** <NoteLink to="hallucination-and-faithfulness" /> defines intrinsic and extrinsic
hallucinations and the ways to detect them: checking outputs against sources, measuring agreement between samples, and
using the model's calibrated confidence.
