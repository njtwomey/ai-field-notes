<Definition>
A **recurrent network** processes a sequence $\xvec_1, \dots, \xvec_T$ one element at a time, updating a hidden state
$\hvec_t = f(\hvec_{t-1}, \xvec_t)$ with the same weights at every step. The state summarises the prefix read so far,
so one network handles sequences of any length. Outputs are read from the states, at every step or only at the end
<Cite id="goodfellow2016" />.
</Definition>

## What it is for

Text, speech, sensor streams and time series are sequences of varying length in which order matters. A recurrent network
handles them with a fixed number of parameters and constant memory per step, and it generates sequences naturally by
feeding each output back as the next input. Recurrent networks were the standard model for language modelling,
<Gloss name="machine-translation">machine translation</Gloss> and speech recognition until transformers replaced them
from 2017. They remain in use for streaming and low-memory settings and for forecasting, as in <NoteLink to="deepar" />,
and recurrence has returned in the linear form of state-space models such as <NoteLink to="mamba" />.

## Main ideas

**One cell, applied at every step.** A <NoteLink to="recurrent-neural-network" /> computes
$\hvec_t = \phi(\Wmat\hvec_{t-1} + \Umat\xvec_t + \bvec)$. Unrolled over time it is a deep feedforward network with
shared weights, one layer per step. The same cell supports one-to-many, many-to-one and many-to-many input-output
patterns.

**Training unrolls the sequence, and gradients decay.** <NoteLink to="backpropagation-through-time" /> backpropagates
through the unrolled graph. The gradient from step $t$ to step $k$ is a product of $t - k$ Jacobians, so it vanishes or
explodes exponentially in the gap. Gradient clipping handles explosion; vanishing gradients mean a plain recurrent
network struggles to learn dependencies more than a few dozen steps long.

**Gates create a path for the gradient.** The <NoteLink to="long-short-term-memory" /> adds a cell state updated
additively, $\cvec_t = \fvec_t \odot \cvec_{t-1} + \ivec_t \odot \gvec_t$, with gates in $(0, 1)$ that decide what to
forget, write and read. Along the cell state the gradient is scaled only by the forget gates, so it survives hundreds
of steps <Cite id="hochreiter1997" />. The <NoteLink to="gated-recurrent-unit" /> achieves the same with two gates, no
separate cell and fewer parameters.

**Encoder and decoder for sequence transduction.** A
<NoteLink to="sequence-to-sequence">sequence-to-sequence model</NoteLink> reads an input sequence into a vector with an
encoder network and generates an output sequence of a different length with a decoder network, one token at a time.
Compressing a whole sentence into one fixed vector limits it on long inputs.

**Attention removes the bottleneck.** <NoteLink to="bahdanau-attention" /> gives the decoder a new context vector at
every step: a weighted average of all encoder states, with weights from a softmax of learned alignment scores. This is
the direct ancestor of the attention in transformers.
