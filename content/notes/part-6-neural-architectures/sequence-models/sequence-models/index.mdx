<Definition>
A **sequence model** maps a sequence $\xvec_1, \dots, \xvec_T$ of varying length to an output: a label, a value at each
step, or another sequence. Neural sequence models differ in how information moves between positions. A recurrent network
carries it forward in a hidden state, one step at a time; a transformer lets every position attend to every other; a
<Gloss name="structured-state-space-model">state-space model</Gloss> passes it through a linear recurrence that can be
computed in parallel <Cite id="goodfellow2016" />.
</Definition>

## What it is for

Language, speech, music, sensor streams, event logs and time series are sequences. Their length varies, their order
carries meaning, and dependencies can span long distances. A sequence model must share parameters across positions,
handle any length, and, when generating, produce one element at a time conditioned on what came before.

This topic holds the recurrent family, the first neural answer to these requirements and the standard one until 2017.
Recurrent <Gloss name="seq2seq">encoder-decoder</Gloss> models defined <NoteLink to="machine-translation">neural machine
translation</NoteLink> <Cite id="sutskever2014" />, and the attention mechanism added to them became the core of the
transformer.

## Main ideas

**A hidden state summarises the past.** A recurrent network applies one cell at every step and updates a state that
summarises the prefix read so far. Its memory per step is constant and its parameters do not depend on length.
<NoteLink to="recurrent-networks" /> develops the model and its training by <Gloss name="bptt">backpropagation through
time</Gloss>.

**Long dependencies need gated memory.** Gradients through a plain recurrence vanish over long gaps. The
<Gloss name="lstm" /> and <Gloss name="gru" /> add gates and an additively updated memory that carries the gradient
across hundreds of steps.

**Sequences in, sequences out.** An encoder-decoder model reads an input sequence and generates an output sequence of a
different length. Attention lets the decoder look back at every encoder state instead of one compressed vector.

**Parallelism decides what scales.** A recurrent network must process its steps in order, which limits how fast it
trains on parallel hardware. Transformers removed the recurrence and train on all positions at once at quadratic cost in
length. Linear recurrences, as in state-space models and <NoteLink to="linear-attention">linear attention</NoteLink>,
recover both parallel training and constant-cost generation.
