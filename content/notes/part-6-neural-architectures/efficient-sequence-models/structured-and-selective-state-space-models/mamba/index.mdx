<Definition>
A **selective state-space layer** (S6) runs, independently for each of $D$ channels, the recurrence

$$
\hvec_t = \bar{\Amat}_t\hvec_{t-1} + \bar{\Bmat}_t x_t, \qquad y_t = \Cmat_t\hvec_t, \qquad
\bar{\Amat}_t = e^{\Delta_t\Amat}, \quad \bar{\Bmat}_t = \Delta_t\Bmat_t,
$$

with a diagonal $\Amat \in \reals^{N \times N}$ that is a fixed learned parameter, and a step $\Delta_t > 0$ and vectors
$\Bmat_t, \Cmat_t \in \reals^N$ that are computed from the input at position $t$. The state matrix is discretised by
the zero-order hold, $\bar\Amat_t = e^{\Delta_t\Amat}$, and the input matrix by the Euler rule,
$\bar\Bmat_t = \Delta_t\Bmat_t$, as in the reference kernel <Cite id="gu2023mambacode" />. **Mamba** is a deep
network of blocks built around this layer, with no attention and no separate <Gloss name="mlp" /> blocks
<Cite id="gu2023mamba" />.
</Definition>

## Why time invariance fails

A <NoteLink to="structured-state-space-models">structured state-space layer</NoteLink> such as S4 applies the same
transition at every step. Its output is a convolution $y = \bar K * x$ with a kernel that does not depend on the input.
That property gives S4 its fast convolutional training, and it is also its limit. A fixed kernel weights a token by its
position relative to the query, never by what the token is.

Two synthetic tasks show the problem <Cite id="gu2023mamba" />:

- **<NoteLink to="long-range-and-recall-benchmarks">Selective copying</NoteLink>.** A few content tokens are scattered
  among noise tokens at random positions, and the model must output the content tokens in order. The gap between them
  varies, so no fixed kernel can pick them out. S4 solves about 18% of cases; the selective layer solves about 97%.
- **<NoteLink to="induction-heads-and-circuits">Induction heads</NoteLink>.** After seeing "… Harry Potter …" once, the
  model must predict "Potter" the next time "Harry" appears. The answer depends on matching content, not on distance.

Attention handles both, because its weights are computed from the tokens. Mamba gives the recurrence the same
ability while keeping a fixed-size state.

## Selection

Mamba computes, for each position $t$ with input vector $\xvec_t \in \reals^D$ over all channels,

$$
\Bmat_t = \Wmat_B\xvec_t \in \reals^N, \qquad \Cmat_t = \Wmat_C\xvec_t \in \reals^N, \qquad
\Delta_t = \operatorname{softplus}\paren{\text{bias} + \text{broadcast}_D(\wvec_\Delta^\tr\xvec_t)} \in \reals^D.
$$

$\Bmat_t$ and $\Cmat_t$ are shared by all $D$ channels. $\Delta_t$ has one entry per channel. $\Amat$ is diagonal and
real, initialised as $A_n = -(n+1)$ (S4D-Real) with state size $N = 16$ <Cite id="gu2023mamba" />
<Cite id="gu2022s4d" />. The real kernel discretises the state matrix by the zero-order hold and the input matrix by
the Euler rule: $\bar\Amat_t = e^{\Delta_t\Amat}$ and $\bar\Bmat_t = \Delta_t\Bmat_t$ <Cite id="gu2023mambacode" />.
The zero-order hold for $\Amat$ keeps every $\bar a_{t,n} = e^{\Delta_t A_n}$ in $(0, 1)$ for any step. The Euler rule
for $\Bmat$ saves an exponential per state and agrees with the zero-order hold to first order in $\Delta_t$, since
$(1 - e^{-\Delta_t|A_n|})/|A_n| = \Delta_t - \tfrac12\Delta_t^2|A_n| + \dots$.

### The step size is a gate

The role of $\Delta_t$ is clearest in a scalar simplification. Take $N = 1$, $A = -1$, $B = 1$, and discretise both
$A$ and $B$ with the zero-order hold. This departs from the real kernel, which uses the Euler rule for $B$; the
simplification is made because the gate form below needs it. Under the Euler rule the input weight is $\Delta_t$,
which is close to $1 - e^{-\Delta_t}$ only for small $\Delta_t$. With the zero-order hold for both,
$\bar A_t = e^{-\Delta_t}$ and $\bar B_t = (e^{-\Delta_t} - 1)/(-1) = 1 - e^{-\Delta_t}$, so

$$
h_t = e^{-\Delta_t}h_{t-1} + \paren{1 - e^{-\Delta_t}}x_t.
$$

Let $\Delta_t = \operatorname{softplus}(z_t) = \log(1 + e^{z_t})$ with $z_t$ a linear function of $x_t$. Then
$e^{-\Delta_t} = 1/(1 + e^{z_t}) = 1 - \sigma(z_t)$, where $\sigma$ is the logistic sigmoid. Writing
$g_t = \sigma(z_t)$,

$$
h_t = (1 - g_t)\,h_{t-1} + g_t\,x_t.
$$

This is the gated update of a <NoteLink to="gated-recurrent-unit">GRU</NoteLink> without the nonlinearity inside the
recurrence <Cite id="gu2023mamba" />. A large $\Delta_t$ ($g_t \to 1$) resets the state and stores the current token. A
small $\Delta_t$ ($g_t \to 0$) keeps the state and ignores the token. With $N > 1$, input-dependent $\Bmat_t$ controls
which state dimensions a token writes to, and $\Cmat_t$ controls which dimensions the output reads.

### Worked example

Take the scalar gated layer above, with the zero-order hold for both $A$ and $B$, and inputs $x = (2, 9, 9, -4)$.
Suppose the input projection marks tokens 1 and 4 as relevant, $\Delta = (5, 0.01, 0.01, 5)$. The gates are
$g_t = 1 - e^{-\Delta_t} = (0.99326, 0.00995, 0.00995, 0.99326)$.

- $h_1 = 0.99326 \times 2 = 1.9865$.
- $h_2 = 0.99005 \times 1.9865 + 0.00995 \times 9 = 2.0563$.
- $h_3 = 0.99005 \times 2.0563 + 0.00995 \times 9 = 2.1254$.
- $h_4 = 0.00674 \times 2.1254 + 0.99326 \times (-4) = -3.9587$.

The state holds the value 2 through the two ignored tokens and then replaces it. A time-invariant layer with the fixed
gate $g = 0.5$ gives $h = (1, 5, 7, 1.5)$: the ignored tokens dominate the state.

Under the real kernel's Euler rule for $B$ the same steps write each token with weight $\Delta_t$ instead of $g_t$:
$h = (10, 9.990, 9.981, -19.933)$. The state holds $5 \times 2$ through the ignored tokens and then $5 \times (-4)$,
plus a small leak. Selection works the same way, and the factor $\Delta_t$ on stored tokens is absorbed by the learned
maps $\Bmat_t$ and $\Cmat_t$.

The figure runs selective copying with this scalar layer: four marked tokens among noise, and a memory that should
hold the latest marked value. With a large step on marked tokens and a small one elsewhere, the selective state
follows the target, with a root-mean-square error of 0.16 on the default inputs. The time-invariant layer has one
step for all tokens and stays above an error of 1.7 for every step from 0.01 to 5: a small step averages marked and
noise tokens alike, and a large step lets the next noise token overwrite the stored value. Switching the rule for $B$
to Euler scales the selective curve by the step on marked tokens and leaves the decoded error almost unchanged. Raising
the step on the other tokens towards the step on marked ones turns the selective layer back into a time-invariant one,
and its error rises with it.

## Computing a selective layer

Input-dependent parameters make the layer time-varying. The output is no longer a convolution with one kernel, so the
<Gloss name="fft" /> route of S4 is gone. The recurrence is still linear in $\hvec$, and $\bar{\Amat}_t$ is diagonal, so
each state dimension is a scalar recurrence $h_t = \bar a_t h_{t-1} + \bar b_t x_t$. A
<NoteLink to="parallel-scan">parallel scan</NoteLink> computes all $L$ states in $O(\log L)$ depth and $O(L)$ work.

The obstacle is memory. The states form a tensor of shape (batch, $L$, $D$, $N$), $N$ times larger than the input.
Writing it to the <Gloss name="gpu" />'s main memory (HBM) would make the layer memory-bound. Mamba's kernel avoids this
in the same way as <NoteLink to="flash-attention">FlashAttention</NoteLink> <Cite id="gu2023mamba" />:

- **Kernel fusion.** It reads $\Delta$, $\Amat$, $\Bmat$, $\Cmat$ and $x$ from HBM into on-chip SRAM, discretises and
  runs the scan there, and writes back only the output $y$ of shape (batch, $L$, $D$).
- **Recomputation.** The backward pass recomputes the states from the inputs instead of storing them.

The fused scan is up to 3 times faster than earlier convolution-based <Gloss name="state-space-model">state-space
models</Gloss> on an A100, 20 to 40 times faster than a plain PyTorch scan, and faster than FlashAttention-2 beyond
sequence length 2K, and its memory use matches an optimised transformer layer with FlashAttention
<Cite id="gu2023mamba" />.

At generation time the layer keeps only $\hvec_t$, $DN$ numbers per layer, and each token costs $O(DN)$ whatever its
position. There is no <NoteLink to="key-value-cache">KV cache</NoteLink>.

## The Mamba block

A Mamba block expands the model width $D$ by a factor $E = 2$ with a linear projection into two branches. One branch
applies a short <NoteLink to="wavenet-and-causal-convolution">causal convolution</NoteLink>, a <Gloss name="silu" />
nonlinearity and the selective SSM. The other applies SiLU and acts as a multiplicative gate on the first. A linear
projection returns to width $D$. Blocks are stacked with <NoteLink to="residual-connections">residual
connections</NoteLink> and normalisation, and no attention or MLP layers are added <Cite id="gu2023mamba" />.

<MambaBlockDiagram />

Mamba generates with 5 times the throughput of a transformer of similar size, scales linearly with sequence length,
and improves on real data up to sequences of a million tokens. Mamba-3B outperforms transformers of the same size and
matches transformers twice its size on language modelling <Cite id="gu2023mamba" />. On induction heads it extrapolates
from training length 256 to sequences of $2^{20} \approx 10^6$ tokens, while no other method tested generalises beyond
twice its training length.

## Mamba-2

Mamba-2 restricts the transition further, from diagonal to a scalar times the identity, $\bar\Amat_t = a_t\eye$, and
uses state sizes of 64 or 128 instead of 16 <Cite id="dao2024" />. With that restriction the layer equals causal
<NoteLink to="linear-attention">linear attention</NoteLink> with queries $\Cmat_t$, keys $\Bmat_t$ and a decay mask of
cumulative products of the $a_t$, and it can be computed in chunks with <NoteLink to="matrix-multiplication">matrix
multiplications</NoteLink>. Its <Gloss name="structured-state-space-duality" /> layer is 2 to 8 times faster than
Mamba's selective scan <Cite id="dao2024" />. The equivalence, the chunked algorithm and the Mamba-2 block are in
<NoteLink to="mamba-2-and-state-space-duality" />.

## Assumptions

- **Linearity in the state.** Selection makes the coefficients depend on the input, not on the state. The recurrence
  stays linear in $\hvec$, which is what makes the scan possible.
- **Diagonal transition.** A dense input-dependent $\bar{\Amat}_t$ would make each scan combination an $N \times N$
  matrix product.

## Pitfalls

- **Fixed-size memory.** The state has $DN$ numbers whatever the context length. Tasks that need exact recall of many
  earlier tokens, such as copying a long string or retrieving one fact from a long document, are harder for Mamba than
  for attention, which keeps every token. <NoteLink to="hybrid-sequence-models">Hybrid models</NoteLink> add a few
  attention layers for this reason.
- **No convolutional mode.** Code written for S4 that precomputes a kernel does not apply. Training needs the scan.
- **Short convolution.** The causal convolution before the SSM supplies local context. Removing it hurts, because the
  SSM alone sees each token only through the state.
- **Mixing discretisation rules.** Weights trained with the Euler rule for $\Bmat$ write each token with weight
  $\Delta_t$. A reimplementation that uses the zero-order hold for $\Bmat$ writes it with $(1 - e^{\Delta_tA_n})/|A_n|$
  instead, which differs once $\Delta_t|A_n|$ is not small, so pretrained weights give different outputs.
