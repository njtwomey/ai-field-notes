<Definition>
**Linear attention** computes the output at position $i$ as

$$
\vvec_i' = \frac{\sum_j \phi(\qvec_i)^\tr\phi(\kvec_j)\,\vvec_j}{\sum_j \phi(\qvec_i)^\tr\phi(\kvec_j)}
= \frac{\phi(\qvec_i)^\tr\sum_j \phi(\kvec_j)\vvec_j^\tr}{\phi(\qvec_i)^\tr\sum_j \phi(\kvec_j)},
$$

where $\qvec_i, \kvec_j \in \reals^{d}$ are queries and keys, $\vvec_j \in \reals^{d_v}$ values, and
$\phi: \reals^d \to \reals^{m}$ a <NoteLink to="convolutional-layer">feature map</NoteLink> with non-negative outputs.
The sums over $j$ do not depend on $i$, so they are computed once and shared by all queries. Time and memory are linear
in the sequence length $n$ <Cite id="katharopoulos2020" />.
</Definition>

## Intuition

<NoteLink to="scaled-dot-product-attention">Softmax attention</NoteLink> compares every query with every key. It must
form the $n \times n$ matrix $\Qmat\Kmat^\tr$, apply the exponential elementwise and normalise each row, and only then
multiply by $\Vmat$. The exponential sits between the two <NoteLink to="matrix-multiplication">matrix
products</NoteLink>, so they cannot be regrouped.

If the similarity is instead a dot product of feature vectors, $\phi(\qvec)^\tr\phi(\kvec)$, the attention matrix is
$\phi(\Qmat)\phi(\Kmat)^\tr$ and the output is $\phi(\Qmat)\phi(\Kmat)^\tr\Vmat$. Matrix multiplication is associative,
so $\phi(\Kmat)^\tr\Vmat$, an $m \times d_v$ matrix, can be computed first. Its size does not depend on $n$. Each query
then reads from this fixed summary of all keys and values.

## Derivation

Write attention with a general non-negative similarity function:

$$
\vvec_i' = \frac{\sum_{j=1}^{n} \operatorname{sim}(\qvec_i, \kvec_j)\,\vvec_j}{\sum_{j=1}^{n} \operatorname{sim}(\qvec_i, \kvec_j)}.
$$

Softmax attention is the case $\operatorname{sim}(\qvec, \kvec) = \exp(\qvec^\tr\kvec/\sqrt{d})$. Any similarity that is
a <NoteLink to="kernel-trick">kernel</NoteLink> with a finite feature map, $\operatorname{sim}(\qvec, \kvec) =
\phi(\qvec)^\tr\phi(\kvec)$, gives

$$
\vvec_i'^\tr = \frac{\sum_j \phi(\qvec_i)^\tr\phi(\kvec_j)\,\vvec_j^\tr}{\sum_j \phi(\qvec_i)^\tr\phi(\kvec_j)}
= \frac{\phi(\qvec_i)^\tr\paren{\sum_j \phi(\kvec_j)\vvec_j^\tr}}{\phi(\qvec_i)^\tr\paren{\sum_j \phi(\kvec_j)}},
$$

because $\phi(\qvec_i)^\tr$ does not depend on $j$ and can be taken out of both sums. Define

$$
\Smat = \sum_{j=1}^{n} \phi(\kvec_j)\vvec_j^\tr \in \reals^{m \times d_v}, \qquad
\zvec = \sum_{j=1}^{n} \phi(\kvec_j) \in \reals^{m}.
$$

Then $\vvec_i'^\tr = \phi(\qvec_i)^\tr\Smat / \phi(\qvec_i)^\tr\zvec$. Computing $\Smat$ and $\zvec$ costs $O(nmd_v)$,
and each of the $n$ outputs costs $O(md_v)$. The total is $O(nmd_v)$ time, against $O(n^2 d)$ for softmax attention, and
no $n \times n$ matrix is stored <Cite id="katharopoulos2020" />.

Katharopoulos et al. use $\phi(\xvec) = \operatorname{elu}(\xvec) + 1$ elementwise, so $m = d$. The feature map must be
non-negative so that every weight is non-negative and the denominator cannot vanish or change sign.

### Causal linear attention is a recurrent network

With a <NoteLink to="causal-masking">causal mask</NoteLink>, query $i$ sums only over $j \le i$. The sums become prefix
sums:

$$
\Smat_i = \sum_{j \le i} \phi(\kvec_j)\vvec_j^\tr = \Smat_{i-1} + \phi(\kvec_i)\vvec_i^\tr, \qquad
\zvec_i = \zvec_{i-1} + \phi(\kvec_i), \qquad
\vvec_i'^\tr = \frac{\phi(\qvec_i)^\tr\Smat_i}{\phi(\qvec_i)^\tr\zvec_i},
$$

with $\Smat_0 = \zeros$ and $\zvec_0 = \zeros$. This is a <NoteLink to="recurrent-neural-network">recurrent
network</NoteLink> whose hidden state is the matrix $\Smat_i$ and the vector $\zvec_i$ <Cite id="katharopoulos2020" />.
Generation keeps $m(d_v + 1)$ numbers per head and layer and spends $O(md_v)$ per token, whatever the context length. A
softmax transformer instead keeps a <NoteLink to="key-value-cache">key-value cache</NoteLink> that grows by one key and
one value per token, and spends $O(i\,d)$ at position $i$. Katharopoulos et al. report autoregressive generation up to
4000 times faster than a softmax transformer on very long sequences.

For training, the same layer runs in parallel over the sequence. The state update is a linear recurrence, so all
$\Smat_i$ can be computed with a <NoteLink to="parallel-scan">parallel scan</NoteLink>, or in chunks: within a chunk of
$C$ positions, use the masked <NoteLink to="positive-definite-matrices">quadratic form</NoteLink>
$(\phi(\Qmat)\phi(\Kmat)^\tr \circ \Mmat)\Vmat$ with a causal mask $\Mmat$; between chunks, pass $\Smat$ forward.

### Worked example

Take three positions with feature vectors already applied, $m = d_v = 2$: $\phi(\kvec_1) = (1, 0)$,
$\phi(\kvec_2) = (1, 1)$, $\phi(\kvec_3) = (0, 2)$; values $\vvec_1 = (1, 0)$, $\vvec_2 = (0, 1)$, $\vvec_3 = (1, 1)$;
queries $\phi(\qvec_1) = (1, 1)$, $\phi(\qvec_2) = (1, 0)$, $\phi(\qvec_3) = (0, 1)$.

- $i = 1$: $\Smat_1 = \phi(\kvec_1)\vvec_1^\tr = \begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix}$, $\zvec_1 = (1, 0)$. The
  numerator is $\phi(\qvec_1)^\tr\Smat_1 = (1, 0)$, the denominator $1$, the output $(1, 0)$.
- $i = 2$:
  $\Smat_2 = \Smat_1 + \begin{pmatrix}0 & 1 \\ 0 & 1\end{pmatrix} = \begin{pmatrix}1 & 1 \\ 0 & 1\end{pmatrix}$,
  $\zvec_2 = (2, 1)$. The numerator is $(1, 1)$, the denominator $2$, the output $(0.5, 0.5)$.
- $i = 3$:
  $\Smat_3 = \Smat_2 + \begin{pmatrix}0 & 0 \\ 2 & 2\end{pmatrix} = \begin{pmatrix}1 & 1 \\ 2 & 3\end{pmatrix}$,
  $\zvec_3 = (2, 3)$. The numerator is $(2, 3)$, the denominator $3$, the output $(0.667, 1)$.

The quadratic form gives the same outputs. The masked similarity matrix has rows $(1, 0, 0)$, $(1, 1, 0)$ and
$(0, 1, 2)$. Row 3 weights the values by $(0, 1, 2)/3$, giving $(0 + 2, 1 + 2)/3 = (0.667, 1)$.

## Approximating softmax with random features

A fixed map such as $\operatorname{elu} + 1$ defines a different similarity from softmax. The Performer instead
approximates the softmax kernel itself with random features, FAVOR+ <Cite id="choromanski2021" />. For
$\omegavec_1, \dots, \omegavec_m$ drawn from $\Gauss(\zeros, \eye_d)$, define

$$
\phi(\xvec) = \frac{1}{\sqrt m}\,e^{-\norm{\xvec}^2/2}\paren{e^{\omegavec_1^\tr\xvec}, \dots, e^{\omegavec_m^\tr\xvec}}.
$$

Then $\expect[\phi(\qvec)^\tr\phi(\kvec)] = \exp(\qvec^\tr\kvec)$, so $\phi(\qvec)^\tr\phi(\kvec)$ is an unbiased
estimate of the softmax similarity; scaling $\qvec$ and $\kvec$ by $d^{-1/4}$ gives the $1/\sqrt d$ temperature. Every
feature is positive, so the estimated weights are positive. The trigonometric
<NoteLink to="random-fourier-features">random Fourier features</NoteLink> used for shift-invariant kernels can produce
negative estimates of small weights, which makes the normaliser unstable. Drawing the $\omegavec_i$ orthogonal to one
another lowers the variance further. In the figure, switching to positive random features moves the linear weights
toward softmax's as $m$ grows: the mean share of weight misplaced falls from 0.37 at $m = 4$ to 0.05 at $m = 1024$.
The Performer is one of several ways to approximate the softmax attention matrix;
<NoteLink to="low-rank-and-hashing-attention">low-rank and hashing attention</NoteLink> covers the projection and
hashing methods.

<Derivation title="Why positive random features are unbiased">
For $\omegavec \sim \Gauss(\zeros, \eye_d)$ and any fixed $\avec \in \reals^d$, the <Gloss name="mgf">moment-generating
function</Gloss> of a standard Gaussian gives $\expect[e^{\omegavec^\tr\avec}] = e^{\norm{\avec}^2/2}$. Each term of
$\phi(\qvec)^\tr\phi(\kvec)$ is $\frac1m e^{-(\norm{\qvec}^2 + \norm{\kvec}^2)/2}e^{\omegavec_i^\tr(\qvec + \kvec)}$, so

$$
\expect\brack{\phi(\qvec)^\tr\phi(\kvec)} = e^{-(\norm{\qvec}^2 + \norm{\kvec}^2)/2}\,e^{\norm{\qvec + \kvec}^2/2}.
$$

Expanding $\norm{\qvec + \kvec}^2 = \norm{\qvec}^2 + 2\qvec^\tr\kvec + \norm{\kvec}^2$ cancels the squared norms and
leaves $e^{\qvec^\tr\kvec}$.
</Derivation>

## Decay, gates and the delta rule

The plain recurrence $\Smat_i = \Smat_{i-1} + \phi(\kvec_i)\vvec_i^\tr$ never forgets. Every write stays in the state
with weight one, so after many tokens the state is a sum of many interfering outer products. Two changes to the update
rule address this, and both keep the update linear in $\Smat$, so training still runs as a scan or in chunks.

**Decay.** Multiplying the old state by a factor $\gamma_i \in (0, 1]$ before each write gives
$\Smat_i = \gamma_i\Smat_{i-1} + \phi(\kvec_i)\vvec_i^\tr$. Unrolled, the key at position $j$ enters the state read at
position $i$ with weight $\gamma_{j+1}\cdots\gamma_i$, so old tokens fade. In the parallel form the weight matrix
$\phi(\Qmat)\phi(\Kmat)^\tr$ is multiplied elementwise by this decay mask. RetNet uses a fixed $\gamma$ per head
<Cite id="sun2023retnet" />, covered in <NoteLink to="rwkv-and-retentive-networks">RWKV and retentive
networks</NoteLink>. Gated linear attention computes $\gamma_i$ from the current token, so the layer chooses when to
forget <Cite id="yang2024gla" />; <NoteLink to="gated-linear-recurrence">gated linear recurrences</NoteLink> develops
this family, and <NoteLink to="mamba-2-and-state-space-duality">Mamba-2</NoteLink> is the case of a scalar gate per
head.

**Delta rule.** The additive write adds $\phi(\kvec_i)\vvec_i^\tr$ even when the state already holds a value for a
similar key. The delta rule first reads the value the state stores for the key, $\Smat_{i-1}^\tr\phi(\kvec_i)$, and
writes only the correction:
$\Smat_i = \Smat_{i-1} + \beta_i\,\phi(\kvec_i)\paren{\vvec_i - \Smat_{i-1}^\tr\phi(\kvec_i)}^\tr$ with a write strength
$\beta_i \in (0, 1]$ <Cite id="schlag2021" />. For a unit-length feature vector and $\beta_i = 1$, the new value
replaces the old one for that key. The update is one step of <NoteLink to="gradient-descent">gradient descent</NoteLink>
on the squared error of predicting $\vvec_i$ from $\phi(\kvec_i)$, and DeltaNet trains it in parallel over the sequence
<Cite id="yang2024deltanet" />. <NoteLink to="delta-rule-and-test-time-training">Delta rule and test-time training
layers</NoteLink> covers it, writing the state transposed, as $\vvec\kvec^\tr$.

**Practice.** Large models built on linear attention since 2025 use gated or delta-rule updates and keep a minority of
softmax layers. MiniMax-01 places one softmax attention block after every seven lightning attention blocks, a linear
attention computed in chunks <Cite id="minimax2025" />. Qwen3-Next interleaves three Gated DeltaNet layers with one
gated attention layer <Cite id="qwen2025next" />, and Kimi Linear repeats three Kimi Delta Attention layers per
full-attention layer <Cite id="kimi2025linear" />. Kimi Linear reports up to 75% less KV cache and up to 6 times the
decoding throughput at a context of one million tokens <Cite id="kimi2025linear" />. The softmax layers supply the
exact recall that a fixed-size state lacks; <NoteLink to="hybrid-sequence-models">hybrid sequence models</NoteLink>
discusses the mix.

## Assumptions

- **Kernel similarity.** Linearity needs a similarity that factorises through a finite feature map. The exact softmax
  kernel needs infinitely many features, so it is approximated or replaced.
- **Fixed feature dimension.** The cost is linear in $n$ only while $m$ is fixed. Random-feature approximations need
  larger $m$ for lower variance.

## Pitfalls

- **Finite memory.** The causal state $\Smat_i$ has $m \times d_v$ entries. It is a sum of outer products, so once more
  than about $m$ key directions have been written, new associations interfere with old ones. Retrieval of one specific
  token from a long context is worse than with softmax attention.
- **Diffuse weights.** Softmax can put almost all weight on one key. A low-dimensional non-negative feature map rarely
  does, so attention is smoother and less selective. In the figure, with $\operatorname{elu} + 1$, the largest weight
  in the last row is 0.09, against 0.29 for softmax. Decay and the delta rule are the usual remedies.
- **Numerics of the normaliser.** Without the denominator the outputs grow with the sequence length; with it, a small
  denominator amplifies noise. Some variants drop the denominator and normalise the output with a
  <NoteLink to="layer-normalisation">layer normalisation</NoteLink> instead.
