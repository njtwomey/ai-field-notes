<Definition>
**Efficient sequence models** are token-mixing layers whose cost grows more slowly in the sequence length $n$ than the
$O(n^2)$ of softmax attention. One family keeps attention and scores fewer query–key pairs or approximates the attention
matrix <Cite id="tay2022" />. The other family compresses the past into a state of fixed size, updated by a map that is
linear in the state, $\hvec_t = \Amat_t\hvec_{t-1} + \bvec_t$, where $\Amat_t$ and $\bvec_t$ depend at most on token
$t$. Linear attention, linear recurrent models and <Gloss name="state-space-model">state-space models</Gloss> such as S4
and Mamba belong to the second family <Cite id="gu2023mamba" />.
</Definition>

## What it is for

A head of <NoteLink to="scaled-dot-product-attention">scaled dot-product attention</NoteLink> over $n$ tokens of width
$d$ costs $O(n^2 d)$ time. The standard algorithm also stores an $n \times n$ score matrix, and a decoder reads a
<NoteLink to="key-value-cache" /> that grows by one key and one value per generated token. These three costs limit how
long a document, conversation, codebase, audio clip or genome a transformer can process.
<NoteLink to="efficient-attention" /> compares the methods by which of the three costs each one cuts. Tiled exact
attention, <NoteLink to="flash-attention">FlashAttention</NoteLink>, removes the score memory but keeps the arithmetic
and the cache.

The layers in this topic cut the arithmetic to linear or $O(n \log n)$ in training. The fixed-state layers also
generate each token at constant time and memory. Current open <Gloss name="language-model">language models</Gloss> use
them as most of their layers: Jamba, Qwen3-Next and Nemotron-H interleave them with a few attention layers, and Gemma 3
uses sliding-window attention in five of every six layers.

## Main ideas

**Score fewer pairs.** <NoteLink to="sliding-window-and-sparse-attention" /> fixes each query's keys in advance: a local
window of width $w$, strided positions, global tokens or random keys, at cost $O(nw)$.
<NoteLink to="trainable-sparse-attention" /> lets each query select blocks of keys from cheap block scores.
<NoteLink to="low-rank-and-hashing-attention" /> replaces the attention matrix by thin factors (Linformer,
Nyströmformer) or restricts each query to a bucket of similar keys (Reformer).

**A fixed-size state, trained in parallel.** <NoteLink to="linear-attention" /> replaces the softmax similarity by a
kernel $\phi(\qvec)^\tr\phi(\kvec)$. Causal linear attention is then a recurrent network whose fixed-size matrix state
sums the outer products $\phi(\kvec_t)\vvec_t^\tr$. The update is affine in the state, so a
<NoteLink to="parallel-scan" /> computes all $n$ states in $O(\log n)$ parallel steps. Every fixed-state layer thus has
a parallel form for training and a recurrent form for generation. <NoteLink to="mamba-2-and-state-space-duality" />
shows that a selective state-space layer with a scalar transition is masked linear attention with a mask of cumulative
decays <Cite id="dao2024" />.

**From a fixed transition to a selective one.** The transition $\Amat_t$ sets what the state forgets.
<NoteLink to="hippo" /> derives a continuous-time transition whose state holds a polynomial approximation of the input
history. <NoteLink to="structured-state-space-models">S4</NoteLink> discretises it; a transition fixed across steps
makes the layer a long convolution, computed by the FFT. <NoteLink to="linear-recurrent-unit-and-s5">S5 and the linear
recurrent unit</NoteLink> run a diagonal recurrence as a scan instead, and <NoteLink to="long-convolution-models" />
generate long filters with a small network.
<NoteLink to="rwkv-and-retentive-networks">RetNet and RWKV</NoteLink> apply a fixed decay to a linear-attention state.
<NoteLink to="gated-linear-recurrence">Gated linear recurrences</NoteLink> and <NoteLink to="mamba" /> compute the
decay from each token, so the layer keeps or discards tokens by content.

**How the state is written.** Linear attention adds each new key–value pair to the state, so overlapping keys blur and
no stored value can be replaced. <NoteLink to="xlstm" /> scales the write by exponential input gates and divides by a
normaliser. The <NoteLink to="delta-rule-and-test-time-training">delta rule</NoteLink> writes only the difference
between the new value and what the state returns for its key, one gradient step of online regression. Gated DeltaNet
and RWKV-7 combine the delta rule with decay; test-time-training layers replace the matrix state by a small network
trained as the sequence is read.

**What a fixed state loses, and hybrids.** A state of fixed size cannot store every token, and a $d \times d$ linear
memory holds at most $d$ exact key–value associations. <NoteLink to="long-range-and-recall-benchmarks" /> show the
result: S4 solves 16,384-step Path-X, while fixed-state layers fall behind attention on associative recall as the
number of stored pairs grows. <NoteLink to="expressiveness-of-linear-recurrences" /> shows that diagonal transitions
with entries in $[0, 1]$ cannot track parity, and that negative eigenvalues or non-diagonal delta-rule transitions can.
<NoteLink to="hybrid-sequence-models" /> keep one attention layer per one to seven recurrent layers to restore exact
recall.

## How the notes fit together

The topic has four sub-chapters, read in order.

- <NoteLink to="sparse-linear-and-low-rank-attention" /> covers the methods that keep attention's form; its
  linear-attention note leads into the rest.
- <NoteLink to="linear-recurrent-models" /> starts with the parallel scan and develops matrix-state recurrences with
  decay, gates and the delta rule.
- <NoteLink to="structured-and-selective-state-space-models" /> derives the same kind of recurrence from continuous
  linear systems, from HiPPO and S4 to Mamba and Mamba-2, and uses the parallel scan of the previous sub-chapter.
- <NoteLink to="comparing-and-combining-sequence-models" /> compares the layer types on recall and state tracking,
  mixes them in hybrid stacks, and applies state-space layers to images, audio and DNA in
  <NoteLink to="state-space-models-beyond-text" />.
