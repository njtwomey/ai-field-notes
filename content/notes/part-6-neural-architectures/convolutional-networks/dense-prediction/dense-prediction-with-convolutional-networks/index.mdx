<Definition>
Dense prediction is the family of tasks in which a network outputs a value at every position of a grid rather than
one value per image: a class per pixel in semantic segmentation, a box and a class per anchor or cell in object
detection, a depth or a flow vector per pixel. The architectures for it keep the spatial layout of a convolutional
backbone through to the output, and add parts that recover resolution, gather context at several scales and turn
feature maps into per-position predictions.
</Definition>

## What it is for

A classification network reduces an image to one vector of class scores and throws position away at the end. Many
vision tasks need the position: which pixels are road, where each car is, how far each pixel lies from the camera.
Dense prediction architectures reuse the classifier's convolutional layers, which already compute a feature vector at
every position, and replace the head. They underlie <NoteLink to="semantic-segmentation" />,
<NoteLink to="object-detection" />, <NoteLink to="instance-and-panoptic-segmentation" /> and, through the U-Net, the
denoising networks of <NoteLink to="diffusion-models" />. This chapter covers the building blocks; the task notes in
Part VII cover datasets, losses and evaluation.

## Main ideas

**Keep the grid.** A fully connected layer applied at every position is a convolution, so a classifier rewritten with
convolutions only accepts any input size and outputs a score map <Cite id="long2015" />. The map is coarse, at the
backbone's output stride, usually 32, and thin structures can vanish from it. See
<NoteLink to="fully-convolutional-network-and-u-net" />.

**Recover resolution with skips.** Upsampling by a <NoteLink to="transposed-convolution" /> or by interpolation
restores the size but not the detail. Encoder-decoder networks bring the fine encoder maps back in at each resolution:
U-Net concatenates them, FCN-8s adds score maps from earlier layers, and DeepLabv3+ joins one stride-4 map. See
<NoteLink to="fully-convolutional-network-and-u-net" /> and <NoteLink to="segmentation-decoders" />.

**Gather context without losing resolution.** Atrous (dilated) convolutions grow the receptive field while the map
stays large, so the encoder can stop at output stride 16 or 8. Context modules then look at several scales at once:
parallel atrous rates (ASPP) or pooling over grids of several sizes (PSPNet). See
<NoteLink to="receptive-field-and-dilated-convolution" /> and <NoteLink to="segmentation-decoders" />.

**Give every scale strong features.** A feature pyramid network sends semantics from the coarsest backbone map down to
the fine ones by a top-down path with lateral $1 \times 1$ connections, and every level gets the same width so one head
serves all of them <Cite id="lin2017fpn" />. Each object is handled on the level where it spans a few cells. See
<NoteLink to="feature-pyramid-network" />.

**Turn a fixed tensor into a variable set.** A detection head makes a fixed number of guesses per cell, anchors with
offsets or points with distances to the box edges, and training decides which guesses are responsible for which
object. Non-maximum suppression, or one-to-one assignment, removes the duplicates. See
<NoteLink to="detection-heads-and-anchors" />.
