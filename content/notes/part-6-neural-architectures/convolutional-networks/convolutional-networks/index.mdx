<Definition>
A **convolutional network** is a neural network whose main layers compute each output from a small window of the
input, using one set of weights shared across all window positions. The input is a grid, such as an image, an audio
spectrogram or a time series. Weight sharing makes the layer translation equivariant: shifting the input shifts the
output. Stacks of such layers, interleaved with downsampling, build features from local edges up to whole objects
<Cite id="lecun1998b" />.
</Definition>

## What it is for

A fully connected layer on a 224 × 224 colour image needs about 150,000 weights per output unit and ignores the fact
that nearby pixels are related. A convolutional layer needs only the weights of one small filter per output channel,
whatever the image size, and it applies the same detector everywhere. This saving in parameters and the built-in
assumption of locality made deep learning practical for images <Cite id="goodfellow2016" />.

Convolutional networks were the dominant architecture for <NoteLink to="image-classification" />,
<NoteLink to="object-detection" /> and <NoteLink to="semantic-segmentation" /> from 2012, and remain common where data
or compute are limited. One-dimensional convolutions process audio and time series, and the residual connection,
introduced for convolutional networks, is now part of every deep architecture.

## Main ideas

**Local, shared filters.** A <NoteLink to="convolutional-layer" /> slides a kernel over the input and computes a
weighted sum at each position. Its output size follows from the kernel size, stride and padding, and its cost and
parameter count from the numbers of input and output channels. Translation equivariance and the receptive field, the
region of the input that affects one output, are its defining properties.

**Downsampling grows the receptive field.** <NoteLink to="pooling-and-strides" /> shrink feature maps by taking the
maximum or mean of each window, or by evaluating a convolution only at every $s$-th position. The receptive field then
grows geometrically with depth instead of linearly, so a few dozen layers see the whole image. Pooling also gives some
invariance to small shifts; striding without a low-pass filter can alias.

**Residual blocks make depth trainable.** A <NoteLink to="residual-network" /> builds each block as
$\yvec = \xvec + F(\xvec)$, so the block learns a correction to the identity and the gradient passes through every
block unchanged. This allowed networks with hundreds of layers to train.

**Architectures grew deeper and more uniform.** <NoteLink to="classic-convolutional-network-architectures" /> compares
LeNet-5, AlexNet, VGG-16 and ResNet-152. Over 1998 to 2015 depth rose from a handful of layers to 152, large kernels
gave way to stacks of $3 \times 3$ kernels, tanh gave way to <Gloss name="relu" />, and batch normalisation and
<NoteLink to="residual-connections">residual connections</NoteLink> appeared.
