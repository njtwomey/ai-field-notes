<Definition>
Let $A$ be a learning algorithm, $S$ a source sample drawn from $p_S(\xvec, y)$, $T$ a target sample drawn from
$p_T(\xvec, y)$ (labelled, unlabelled or both), and $R_T(h)$ the risk of a hypothesis $h$ on the target distribution.
**Negative transfer** occurs when
$$
R_T\paren{A(S, T)} > R_T\paren{A(\emptyset, T)},
$$
that is, when the algorithm does worse on the target with the source data than without it. The **negative transfer
gap** is $\text{NTG} = R_T\paren{A(S, T)} - R_T\paren{A(\emptyset, T)}$; negative transfer occurs when it is positive
<Cite id="wang2019negative" />.
</Definition>

## Intuition

Transfer adds information and adds bias. The source sample is usually large, so it reduces variance. It comes from the
wrong distribution, so it pulls the learner towards the source's answer. Negative transfer is the case in which the
pull costs more than the <NoteLink to="variance-reduction">variance reduction</NoteLink> saves.

The comparison in the definition is deliberate. Comparing a transfer method with the best possible target-only method
would mix two effects: the effect of the source data and the effect of a different algorithm. Wang et al. fix the
algorithm and remove only the source, so the gap measures what the source data did <Cite id="wang2019negative" />.

## Three factors

Wang et al. argue that negative transfer depends on three factors <Cite id="wang2019negative" />.

1. **The algorithm.** One method can gain from a source on which another method loses. An algorithm that can down-weight
   unhelpful source examples is less exposed than one that uses every source example equally.
2. **The divergence between the joint distributions** $p_S(\xvec, y)$ and $p_T(\xvec, y)$. If the source conditional
   $p_S(y \mid \xvec)$ carries no information about the target conditional, no algorithm can extract anything useful
   from source labels. In the extreme case in which $p_S(y \mid \xvec)$ is uniform for every $\xvec$, the source labels
   are noise.
3. **The amount of labelled target data.** With few target labels, a biased source is better than a noisy target
   estimate. With many, the target alone is accurate, and any bias from the source is a net loss. The same source can
   therefore help at 10 target labels and hurt at 10000.

The third factor is quantified in <NoteLink to="when-does-transfer-help" />: for a mean estimated from a biased source
and an unbiased target, pooling the samples helps only while the source bias is small compared with the target's
<NoteLink to="standard-error">standard error</NoteLink>.

## Matching marginals is not enough

Many <Gloss name="domain-adaptation">domain-adaptation</Gloss> methods align the marginal distributions of the features, $p_S(\zvec)$ and $p_T(\zvec)$ with
$\zvec = \phivec(\xvec)$, and hope that the source classifier then transfers. The divergence between marginals is blind
to the labels, so it cannot detect a change in $p(y \mid \xvec)$.

### Worked example: identical inputs, reversed labels

Let both domains have the same input distribution, an equal mixture of $\Gauss(-1, \sigma^2)$ and $\Gauss(1,
\sigma^2)$. In the source, the component at $-1$ is class $0$ and the component at $+1$ is class $1$. In the target the
roles are reversed, so $y_T = 1 - y_S$ for the same input distribution.

Every divergence between $p_S(x)$ and $p_T(x)$ is zero, because the two marginals are the same distribution. For any
classifier $h$, the target labels are the source labels flipped, so
$$
R_T(h) = \pr\paren{h(x) \ne 1 - y} = \pr\paren{h(x) = y} = 1 - R_S(h).
$$
The best source classifier, the threshold at $0$, has source error $\Phi(-1/\sigma)$, where $\Phi$ is the standard
<NoteLink to="gaussian-distribution">normal distribution</NoteLink> function. Its target error is $1 - \Phi(-1/\sigma)$. For $\sigma = 0.5$ these are $0.023$ and
$0.977$. An algorithm that trusts the source is almost always wrong, while a target-only learner given a handful of
labels finds the reversed threshold.

The bound of <NoteLink to="domain-adaptation-theory" /> accounts for this case through its third term, the error of the
best joint hypothesis, $\lambda = \min_h \brack{R_S(h) + R_T(h)}$. Here $R_S(h) + R_T(h) = 1$ for every $h$, so
$\lambda = 1$ and the bound is vacuous <Cite id="bendavid2010" />. The divergence term is zero and does not warn. Zhao et al. turn this observation
into a lower bound: when the label distributions of the two domains differ, learning features whose distributions match
across domains forces the sum of source and target errors up <Cite id="zhao2019invariant" />.

## Measuring negative transfer

- **Report the gap, not only the accuracy.** Train the same algorithm with and without the source and report the
  difference on held-out target data <Cite id="wang2019negative" />.
- **Report it as a function of target data.** The gap changes sign as the amount of labelled target data grows, so a
  single number hides where the crossover lies.
- **In <Gloss name="multi-task-learning">multi-task learning</Gloss>, compare with single-task training.** A task suffers negative transfer if training it with
  the others lowers its accuracy compared with training it alone. Standley et al. found that which tasks help one
  another depends on the network size and the amount of data <Cite id="standley2020" />.

## Avoiding negative transfer

Zhang et al. review about fifty methods in four groups: secure transfer, which aims never to do worse than the
target-only learner; domain similarity estimation, which decides whether and what to transfer; distant transfer,
which bridges unrelated domains through intermediate ones; and mitigation inside a transfer algorithm
<Cite id="zhang2023negative" />. Three common strategies are the following.

- **Select or weight sources.** Estimate how related each source, or each source example, is to the target, and down-weight
  the unrelated ones. Wang et al. weight each labelled source example by an estimate of the joint density ratio
  $p_T(\xvec, y) / p_S(\xvec, y)$, obtained from a discriminator that sees both the features and the label. They added
  this *discriminator gate* to domain-adversarial training and reported that it reduced negative transfer across four
  benchmarks <Cite id="wang2019negative" />.
- **Learn how much to borrow.** Hierarchical Bayesian models estimate the between-domain variance from the data and
  shrink less when the domains differ. See <NoteLink to="hierarchical-bayesian-transfer" />.
- **Keep a target-only fallback.** Online methods that mix a source model with a target learner, such as
  <NoteLink to="online-transfer-learning" />, have mistake bounds relative to the better of the two, so their loss from
  a useless source is bounded.

## Pitfalls

- **Blaming the source for a weak algorithm.** Without the same-algorithm, target-only baseline, a low score cannot be
  attributed to the source.
- **Tuning on the target.** Choosing hyperparameters with target labels that the method is not supposed to have
  hides negative transfer in reported results.
- **Assuming related-looking domains are related.** Two domains can share inputs and differ in labels, as in the worked
  example.
