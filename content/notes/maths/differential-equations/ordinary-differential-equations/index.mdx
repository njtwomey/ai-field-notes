<Definition>
An **ordinary differential equation** (ODE) for an unknown function $\xvec : \reals \to \reals^d$ is a rule

$$
\dot{\xvec}(t) = \fvec\paren{t, \xvec(t)},
$$

where $\dot{\xvec} = d\xvec/dt$ and $\fvec : \reals \times \reals^d \to \reals^d$ is given. An **initial value
problem** adds a starting state $\xvec(t_0) = \xvec_0$. A **solution** is a differentiable function that satisfies both
on an interval containing $t_0$ <Cite id="teschl2012" />. "Ordinary" means there is one independent variable, $t$; an
equation with <NoteLink to="partial-derivatives">partial derivatives</NoteLink> in several variables is a
<NoteLink to="partial-differential-equations">partial differential equation</NoteLink>.
</Definition>

## What an ODE says

An ODE does not say where the state is. It says which way the state is moving and how fast, at every possible state
and time. A leaf on a stream is a good picture: the stream's velocity at each point is the rule $\fvec$, the leaf's
starting point is the initial value, and the leaf's path is the solution.

Three examples in one dimension:

- $\dot x = -0.2\,x$: a drug concentration falls at 20% of its current value per hour.
- $\dot x = x(1 - x)$: a population grows in proportion to its size and to the room left, $1 - x$.
- $\dot x = -x + \sin t$: a state is pulled towards 0 and pushed by a periodic input. The rule depends on $t$ as well as
  $x$, so the equation is **non-autonomous**.

In $d$ dimensions, $\fvec$ is a vector field: an arrow at every point of $\reals^d$. The pendulum
$\dot\theta = \omega$, $\dot\omega = -\sin\theta$ has a two-dimensional state (angle $\theta$, angular velocity
$\omega$), and its solutions trace closed loops for small swings.

## Order and linearity

The **order** of an ODE is the highest <NoteLink to="derivative">derivative</NoteLink> it contains. Newton's second law for a mass on a spring,
$\ddot x = -\omega^2x$, is second order. Any order-$n$ equation becomes a first-order system by taking the lower
derivatives as extra state variables. With $v = \dot x$, the spring becomes

$$
\dot x = v, \qquad \dot v = -\omega^2 x,
$$

a first-order equation for $\xvec = (x, v)$. First-order systems therefore cover every case, and the rest of this
section uses them.

An ODE is **linear** when $\fvec$ is linear in $\xvec$: $\dot{\xvec} = \Amat(t)\,\xvec + \bvec(t)$. Linear equations
have closed-form solutions built from exponentials, and sums of solutions of the homogeneous equation
($\bvec = \zeros$) are again solutions. Nonlinear equations, such as the logistic and pendulum equations, rarely have
closed forms. They are studied through their fixed points and linearisations, and solved numerically.

## Existence and uniqueness

Rewriting the initial value problem as an integral equation shows what a solution must satisfy. Integrating both
sides from $t_0$ gives

$$
\xvec(t) = \xvec_0 + \int_{t_0}^t \fvec\paren{s, \xvec(s)}\,ds.
$$

**Picard iteration** starts from the constant guess $\xvec^{(0)}(t) = \xvec_0$ and repeatedly substitutes the current
guess into the right side:

$$
\xvec^{(k + 1)}(t) = \xvec_0 + \int_{t_0}^t \fvec\paren{s, \xvec^{(k)}(s)}\,ds.
$$

**Worked example ($\dot x = x$, $x(0) = 1$).** The iterates are $x^{(0)} = 1$, then
$x^{(1)} = 1 + \int_0^t 1\,ds = 1 + t$, then $x^{(2)} = 1 + \int_0^t (1 + s)\,ds = 1 + t + t^2/2$. Each iteration adds
the next term of the <NoteLink to="taylor-series">Taylor series</NoteLink>, and the iterates converge to $e^t$.

The iteration converges when $\fvec$ cannot change too fast with $\xvec$. The function $\fvec$ is **Lipschitz** in
$\xvec$ with constant $L$ if

$$
\norm{\fvec(t, \xvec) - \fvec(t, \yvec)} \le L\,\norm{\xvec - \yvec}
$$

for all $\xvec$, $\yvec$ near $\xvec_0$ and $t$ near $t_0$. A function with a bounded derivative in $\xvec$ is
Lipschitz, with $L$ the bound.

**Picard–Lindelöf theorem.** If $\fvec$ is continuous in $t$ and Lipschitz in $\xvec$ near $(t_0, \xvec_0)$, the
initial value problem has exactly one solution on some interval $[t_0 - \delta, t_0 + \delta]$ with $\delta > 0$
<Cite id="teschl2012" />.

The proof shows that each Picard step shrinks the distance between two candidate solutions. Over a short interval of
length $\delta$ with $L\delta < 1$, the integral changes by at most $L\delta$ times the change in its input, so the
iteration is a contraction and has one fixed point.

<Derivation title="Why the Picard step is a contraction">
Let $\xvec$ and $\yvec$ be continuous functions on $I = [t_0, t_0 + \delta]$ and write $P$ for the Picard map. Then for
$t \in I$,

$$
\norm{P\xvec(t) - P\yvec(t)} = \norm{\int_{t_0}^t \brack{\fvec(s, \xvec(s)) - \fvec(s, \yvec(s))}\,ds}
\le \int_{t_0}^t L\norm{\xvec(s) - \yvec(s)}\,ds \le L\delta\,\max_{s \in I}\norm{\xvec(s) - \yvec(s)}.
$$

With $L\delta < 1$ the map shrinks the maximum distance between functions by a fixed factor, so by the <NoteLink to="bellman-equations">Banach fixed
point theorem</NoteLink> it has exactly one fixed point, the solution. The full proof also restricts $\delta$ so that the iterates
stay in the region where the Lipschitz bound holds.
</Derivation>

Uniqueness has a geometric consequence. When $\fvec$ is Lipschitz, two solutions of an autonomous equation
$\dot{\xvec} = \fvec(\xvec)$ can never cross or touch, because at the meeting point both would solve the same initial value problem.

### When uniqueness fails

**Worked example ($\dot x = \sqrt x$, $x(0) = 0$).** The constant $x(t) = 0$ is a solution. So is $x(t) = t^2/4$, since
$\dot x = t/2 = \sqrt{t^2/4}$. So is every function that rests at 0 until a time $c \ge 0$ and then follows
$(t - c)^2/4$. The initial value problem has infinitely many solutions.

The right side $\sqrt x$ has derivative $1/(2\sqrt x)$, which is unbounded as $x \to 0$. No Lipschitz constant exists
at the starting point, so the theorem does not apply. Physically, the equation describes water draining from a tank
through a hole (Torricelli's law) run backwards in time. An empty tank gives no information about when it emptied.

<NonUniqueness />

### When solutions stop existing

**Worked example ($\dot x = x^2$, $x(0) = 1$).** Separating variables gives $-1/x = t - 1$, so $x(t) = 1/(1 - t)$. The
solution exists only for $t < 1$ and blows up as $t \to 1$. The right side $x^2$ is Lipschitz on every bounded set, so
the solution is unique while it exists, but its Lipschitz constant $2\abs{x}$ grows with the state. The theorem
guarantees only a local interval. A global solution exists when $\fvec$ grows at most linearly in $\norm{\xvec}$, as it
does for every linear equation.

## How the pieces connect

The thread through the section is one question: how does a distribution of particles move? An ODE moves one particle.
Its flow map moves every particle at once, so it carries a whole probability density. The density then obeys the
continuity equation, and its log-density changes along each path at the rate $-\nabla\cdot\fvec$. Adding noise to each
particle's motion turns the ODE into a stochastic differential equation and adds a diffusion term, the heat equation's
Laplacian, to the density's equation. <Gloss name="diffusion-model">Diffusion models</Gloss> run this picture forwards to turn data into noise and backwards
to generate.

## Variants

- **Autonomous** equations $\dot{\xvec} = \fvec(\xvec)$ have a rule that does not depend on time. Their solutions from
  a given state are the same whenever they start.
- **Stiff** equations mix very fast and very slow rates and need implicit solvers.
- **Boundary value problems** fix the state at two times instead of one, as in the
  <NoteLink to="euler-lagrange-equation">Euler–Lagrange equation</NoteLink>.
- <NoteLink to="stochastic-differential-equations">Stochastic differential equations</NoteLink> add a random forcing
  term driven by
  <NoteLink to="brownian-motion">Brownian motion</NoteLink>.
- **Difference equations** replace $\dot{\xvec}$ by $\xvec_{k + 1} - \xvec_k$; see
  <NoteLink to="difference-equations">difference equations</NoteLink> and the
  <NoteLink to="state-space-representation">state-space representation</NoteLink> of control theory.
