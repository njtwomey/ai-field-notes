<Definition>
A norm on $\reals^n$ is a function $\norm{\cdot} : \reals^n \to [0, \infty)$ such that, for all vectors $\xvec, \yvec$
and scalars $\alpha$,

1. $\norm{\xvec} = 0$ only if $\xvec = \zeros$,
2. $\norm{\alpha\xvec} = \abs{\alpha}\,\norm{\xvec}$,
3. $\norm{\xvec + \yvec} \le \norm{\xvec} + \norm{\yvec}$ (the triangle inequality).

For $1 \le p < \infty$ the $\ell_p$ norm is $\norm{\xvec}_p = \paren{\sum_{i=1}^n \abs{x_i}^p}^{1/p}$, and
$\norm{\xvec}_\infty = \max_i \abs{x_i}$ <Cite id="horn2012" />.
</Definition>

## The common norms

| Norm          | Formula               | Name                      | Unit ball in $\reals^2$ |
| ------------- | --------------------- | ------------------------- | ----------------------- |
| $\ell_1$      | $\sum_i \abs{x_i}$    | Manhattan or taxicab norm | diamond                 |
| $\ell_2$      | $\sqrt{\sum_i x_i^2}$ | Euclidean norm            | disc                    |
| $\ell_\infty$ | $\max_i \abs{x_i}$    | max or Chebyshev norm     | square                  |

The Euclidean norm is the one induced by the dot product, $\norm{\xvec}_2 = \sqrt{\xvec^\top\xvec}$. Without a
subscript, $\norm{\xvec}$ usually means $\norm{\xvec}_2$.

The unit ball of a norm is $\set{\xvec : \norm{\xvec} \le 1}$. It determines the norm completely: $\norm{\xvec}$ is the
factor by which the ball must be scaled to reach $\xvec$. As $p$ grows, the $\ell_p$ ball swells from the diamond
through the disc towards the square, because large $p$ lets the largest entry dominate the sum.

## Relations between the norms

For every $\xvec \in \reals^n$,

$$
\norm{\xvec}_\infty \le \norm{\xvec}_2 \le \norm{\xvec}_1 \le \sqrt{n}\,\norm{\xvec}_2 \le n\,\norm{\xvec}_\infty.
$$

Each inequality has a one-line proof. Let $M = \max_i \abs{x_i}$.

1. $\norm{\xvec}_\infty \le \norm{\xvec}_2$, because $M^2$ is one of the terms of $\sum_i x_i^2$ and the others are
   nonnegative.
2. $\norm{\xvec}_2 \le \norm{\xvec}_1$, because squaring the right side gives
   $\paren{\sum_i \abs{x_i}}^2 = \sum_i x_i^2 + \sum_{i \neq j} \abs{x_i}\abs{x_j} \ge \sum_i x_i^2$.
3. $\norm{\xvec}_1 \le \sqrt{n}\,\norm{\xvec}_2$, by the <NoteLink to="dot-product">Cauchy–Schwarz inequality</NoteLink> applied to the vector of absolute
   values $(\abs{x_1}, \dots, \abs{x_n})$ and the all-ones vector $\ones$: $\sum_i \abs{x_i} \cdot 1 \le \norm{\xvec}_2
   \norm{\ones}_2 = \sqrt{n}\,\norm{\xvec}_2$.
4. $\sqrt{n}\,\norm{\xvec}_2 \le n\,\norm{\xvec}_\infty$, because each of the $n$ terms of $\sum_i x_i^2$ is at most
   $M^2$, so $\norm{\xvec}_2 \le \sqrt{n}\,M$.

Each bound is attained. The first two are equalities for a vector with one nonzero entry, and the last two for a
vector whose entries all have the same absolute value.

All norms on $\reals^n$ are equivalent in this sense: each is bounded above and below by constant multiples of any
other. The chain proves it for $\ell_1$, $\ell_2$ and $\ell_\infty$. The general proof uses the compactness of the unit
sphere. A sequence that converges in one norm therefore converges in all of them. The constants grow with $n$, so in
high dimension the choice of norm changes the numbers a lot.

Hölder's inequality $\abs{\xvec^\top\yvec} \le \norm{\xvec}_p\,\norm{\yvec}_q$ holds whenever $1/p + 1/q = 1$, reading
$1/\infty$ as 0. The norms $\ell_p$ and $\ell_q$ are called dual; $\ell_1$ and $\ell_\infty$ are dual to each other, and
$\ell_2$ is dual to itself, which makes Hölder's inequality with $p = q = 2$ the Cauchy–Schwarz inequality.

<Derivation title="Hölder's inequality and the triangle inequality for p-norms">
The first two norm conditions are immediate for $\norm{\cdot}_p$. The triangle inequality, called Minkowski's inequality
for $\ell_p$, needs Hölder's inequality, which in turn needs Young's inequality.

**Young's inequality.** For $a, b \ge 0$ and $1/p + 1/q = 1$ with $1 < p < \infty$, $ab \le a^p/p + b^q/q$. For
$a, b > 0$ this follows from the concavity of the logarithm:

$$
\log\paren{\frac{a^p}{p} + \frac{b^q}{q}} \ge \frac{1}{p}\log a^p + \frac{1}{q}\log b^q = \log(ab).
$$

**Hölder's inequality.** If either vector is $\zeros$ there is nothing to prove. Otherwise set
$a_i = \abs{x_i}/\norm{\xvec}_p$ and $b_i = \abs{y_i}/\norm{\yvec}_q$, so that $\sum_i a_i^p = \sum_i b_i^q = 1$.
Young's inequality for each $i$, summed, gives

$$
\sum_i a_i b_i \le \frac{1}{p}\sum_i a_i^p + \frac{1}{q}\sum_i b_i^q = \frac{1}{p} + \frac{1}{q} = 1.
$$

Multiplying back by $\norm{\xvec}_p\norm{\yvec}_q$ gives $\sum_i \abs{x_i y_i} \le \norm{\xvec}_p\,\norm{\yvec}_q$, and
$\abs{\xvec^\top\yvec} \le \sum_i \abs{x_i y_i}$. The cases $p = 1$, $q = \infty$ follow from
$\sum_i \abs{x_i y_i} \le \max_j \abs{y_j} \sum_i \abs{x_i}$.

**Minkowski's inequality.** For $p > 1$, split one factor of $\abs{x_i + y_i}^p$:

$$
\norm{\xvec + \yvec}_p^p = \sum_i \abs{x_i + y_i}\,\abs{x_i + y_i}^{p-1}
\le \sum_i \abs{x_i}\,\abs{x_i + y_i}^{p-1} + \sum_i \abs{y_i}\,\abs{x_i + y_i}^{p-1}.
$$

Apply Hölder's inequality to each sum with $q = p/(p-1)$, so that $(p-1)q = p$:

$$
\norm{\xvec + \yvec}_p^p \le \paren{\norm{\xvec}_p + \norm{\yvec}_p} \norm{\xvec + \yvec}_p^{p-1}.
$$

Dividing by $\norm{\xvec + \yvec}_p^{p-1}$ gives $\norm{\xvec + \yvec}_p \le \norm{\xvec}_p + \norm{\yvec}_p$. The case
$p = 1$ is the triangle inequality for absolute values, applied entry by entry.
</Derivation>

## Worked example

For $\xvec = (3, -4, 0, 1)$: $\norm{\xvec}_1 = 3 + 4 + 0 + 1 = 8$, $\norm{\xvec}_2 = \sqrt{9 + 16 + 0 + 1} = \sqrt{26}
\approx 5.10$ and $\norm{\xvec}_\infty = 4$. The chain $4 \le 5.10 \le 8 \le 2 \cdot 5.10 \le 4 \cdot 4$ holds with
$n = 4$.

## Below $p = 1$

For $0 < p < 1$ the same formula is not a norm. The triangle inequality fails: with $p = 1/2$,
$\norm{(1, 0)}_{1/2} + \norm{(0, 1)}_{1/2} = 2$ but $\norm{(1, 1)}_{1/2} = (1 + 1)^2 = 4$. The unit ball is star-shaped
and not convex. The count of nonzero entries, often written $\norm{\xvec}_0$, is not a norm either, since it does not
scale with $\alpha$.

## In machine learning

- **Sparsity from $\ell_1$.** The lasso minimises squared error subject to a bound on $\norm{\wvec}_1$
  <Cite id="tibshirani1996" />. The $\ell_1$ ball has corners on the coordinate axes. The smallest level set of the loss
  that touches the ball usually touches it at a corner or an edge, where some weights are exactly zero.
- **<Gloss name="weight-decay">Weight decay</Gloss> from $\ell_2$.** A penalty $\lambda\norm{\wvec}_2^2$ shrinks all weights smoothly towards zero and
  rarely sets any exactly to zero. See <NoteLink to="linear-regression">linear regression</NoteLink>.
- **Adversarial robustness with $\ell_\infty$.** An $\ell_\infty$ bound of $\epsilon$ lets an attacker change every
  pixel by up to $\epsilon$. To first order the loss changes by $\gvec^\top\deltab$, where $\gvec = \nabla_{\xvec} L$.
  Inside the box $\norm{\deltab}_\infty \le \epsilon$,
  $\gvec^\top\deltab \le \epsilon\sum_i \abs{g_i} = \epsilon\norm{\gvec}_1$, with equality at
  $\deltab = \epsilon\,\sgn(\gvec)$. That step is the <NoteLink to="adversarial-examples">fast gradient sign method</NoteLink> <Cite id="goodfellow2015" />.
- **Gradient clipping** rescales the <NoteLink to="gradient">gradient</NoteLink> when its $\ell_2$ norm exceeds a threshold.

## Pitfalls

- **Squared norm is not a norm.** $\norm{\xvec}_2^2$ is convenient to differentiate, but it fails the scaling rule. Its
  gradient $2\xvec$ vanishes near zero, while the gradient of $\norm{\xvec}_2$ has unit length everywhere except at
  $\zeros$.
- **Units matter.** Norms add entries measured on different scales. Standardise features before comparing distances or
  applying a penalty.
