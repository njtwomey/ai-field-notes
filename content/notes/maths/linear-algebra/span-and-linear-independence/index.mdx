<Definition>
The span of vectors $\vvec_1, \dots, \vvec_k \in \reals^n$ is the set of all their linear combinations,

$$
\Span\set{\vvec_1, \dots, \vvec_k} = \set{c_1\vvec_1 + \dots + c_k\vvec_k : c_1, \dots, c_k \in \reals}.
$$

The vectors are linearly independent if $c_1\vvec_1 + \dots + c_k\vvec_k = \zeros$ holds only for
$c_1 = \dots = c_k = 0$. A linearly independent set that spans a subspace is a basis of that subspace
<Cite id="axler2015" />.
</Definition>

## Span

A span is always a subspace. It contains $\zeros$, the combination with every coefficient 0. It is closed under
addition, because $\sum_i c_i\vvec_i + \sum_i d_i\vvec_i = \sum_i (c_i + d_i)\vvec_i$ is again a combination. It is
closed under scaling, because $a\sum_i c_i\vvec_i = \sum_i (a c_i)\vvec_i$. In $\reals^3$, the span of
one nonzero vector is a line through the origin. The span of two vectors that do not lie on one line is a plane through
the origin. Adding a vector that already lies in a span leaves the span unchanged.

The span of the columns of a matrix $\Amat$ is its column space. The product $\Amat\cvec$ is the combination of the
columns with coefficients $\cvec$, so $\Amat\cvec = \bvec$ has a solution exactly when $\bvec$ lies in the column space.

## Linear independence

Linear dependence means redundancy. If $c_1\vvec_1 + \dots + c_k\vvec_k = \zeros$ with some $c_j \neq 0$, then

$$
\vvec_j = -\frac{1}{c_j}\sum_{i \neq j} c_i \vvec_i,
$$

so $\vvec_j$ lies in the span of the other vectors and removing it leaves the span unchanged. Three equivalent tests for
independence of $\vvec_1, \dots, \vvec_k$:

- No vector is a linear combination of the others.
- The matrix $\Vmat = [\vvec_1 \cdots \vvec_k]$ has rank $k$.
- The null space of $\Vmat$ contains only $\zeros$.

More than $n$ vectors in $\reals^n$ are always dependent. Exactly $n$ vectors in $\reals^n$ are independent if and only
if the square matrix $\Vmat$ has a nonzero determinant.

<Derivation title="Why more than n vectors in n dimensions are dependent">
Independence of $\vvec_1, \dots, \vvec_k$ asks whether $\Vmat\cvec = \zeros$ has a nonzero solution $\cvec$. That is a
system of $n$ equations in $k$ unknowns. Gaussian elimination reduces $\Vmat$ to echelon form without changing the
solutions. Each nonzero row of the echelon form has one pivot, in its own column, so there are at most $n$ pivot
columns. When $k > n$ at least one column has no pivot. Its unknown is free: set it to 1, set the other free unknowns
to 0, and solve for the pivot unknowns by back substitution. The result is a nonzero $\cvec$ with $\Vmat\cvec = \zeros$,
so the vectors are dependent.

For $k = n$, the vectors are independent exactly when every column has a pivot, that is, when $\Vmat$ is invertible,
which holds exactly when $\det\Vmat \neq 0$ (see <NoteLink to="determinant">determinant</NoteLink>).
</Derivation>

## Basis and coordinates

Every vector $\xvec$ in the span of a basis $\vvec_1, \dots, \vvec_k$ has unique coordinates. If two combinations gave
$\xvec$, their difference would be a combination equal to $\zeros$ with some nonzero coefficient, which independence
rules out. Independence therefore makes coordinates unique, and spanning makes them exist.

All bases of a subspace have the same number of vectors. That number is the dimension of the subspace
<Cite id="strang2016" />. The standard basis $\evec_1, \dots, \evec_n$ of $\reals^n$ has a 1 in one position and zeros
elsewhere, so the coordinates of $\xvec$ in it are the entries of $\xvec$.

<Derivation title="Why all bases have the same size">
Let $\uvec_1, \dots, \uvec_m$ and $\wvec_1, \dots, \wvec_p$ be two bases of the same subspace $S$. Write each $\wvec_j$
in the first basis, $\wvec_j = \sum_i a_{ij}\uvec_i$, and collect the coefficients into the $m \times p$ matrix $\Amat$.
Suppose $p > m$. Then the $p$ columns of $\Amat$ are $p$ vectors in $\reals^m$, which are dependent by the result above:
some nonzero $\cvec$ has $\Amat\cvec = \zeros$. Then

$$
\sum_j c_j \wvec_j = \sum_j c_j \sum_i a_{ij}\uvec_i = \sum_i (\Amat\cvec)_i\, \uvec_i = \zeros,
$$

a nonzero combination of the $\wvec_j$ equal to $\zeros$. That contradicts their independence, so $p \le m$. Swapping
the roles of the two bases gives $m \le p$, so $m = p$.
</Derivation>

## Worked example

Take $\vvec_1 = (1, 0, 1)$, $\vvec_2 = (0, 1, 1)$ and $\vvec_3 = (1, 1, 2)$. Then $\vvec_3 = \vvec_1 + \vvec_2$, so the
three vectors are dependent, and their span is the plane spanned by $\vvec_1$ and $\vvec_2$. That plane has dimension 2.
The vector $\bvec = (2, 3, 5)$ lies in it, with coordinates $(2, 3)$ in the basis $\vvec_1, \vvec_2$:
$2\vvec_1 + 3\vvec_2 = (2, 3, 5)$. The vector $(0, 0, 1)$ does not lie in it. Any combination
$c_1\vvec_1 + c_2\vvec_2 = (c_1, c_2, c_1 + c_2)$ with first two entries 0 has third entry 0.

## In machine learning

- **Collinear features.** If one feature column is a linear combination of others, the columns of the design matrix
  are dependent. Least-squares weights are then not unique: adding any null-space vector to the weights leaves every
  prediction unchanged. See <NoteLink to="linear-regression">linear regression</NoteLink>.
- **Representations.** A linear layer $\hvec = \Wmat\xvec$ produces combinations of the columns of $\Wmat$, so every
  output lies in the column space of $\Wmat$. The outputs occupy a subspace of dimension at most $\rank\Wmat$, however
  many inputs are fed through.

## Pitfalls

- **Near-dependence.** Floating-point vectors are rarely exactly dependent. Vectors that are almost dependent behave
  badly in practice: coordinates in such a basis become large and sensitive to small changes. The singular values of
  $\Vmat$ measure how close a set is to dependence.
- **The zero vector.** Any set containing $\zeros$ is dependent, since $1 \cdot \zeros = \zeros$.
