<Definition>
The Moore–Penrose pseudoinverse of $\Amat \in \reals^{m \times n}$ is the unique matrix
$\Amat^+ \in \reals^{n \times m}$ that satisfies the four Penrose conditions

$$
\Amat\Amat^+\Amat = \Amat, \qquad \Amat^+\Amat\Amat^+ = \Amat^+, \qquad (\Amat\Amat^+)^\top = \Amat\Amat^+, \qquad
(\Amat^+\Amat)^\top = \Amat^+\Amat.
$$

Every matrix has exactly one pseudoinverse. When $\Amat$ is square and invertible, $\Amat^+ = \Amat^{-1}$
<Cite id="penrose1955" />.
</Definition>

## Computation from the SVD

Write the <NoteLink to="singular-value-decomposition">singular value decomposition</NoteLink> as
$\Amat = \Umat\Sigmamat\Vmat^\top$, with $r$ nonzero singular values $\sigma_1 \ge \dots \ge \sigma_r > 0$. Then

$$
\Amat^+ = \Vmat\Sigmamat^+\Umat^\top,
$$

where $\Sigmamat^+ \in \reals^{n \times m}$ is the transpose of $\Sigmamat$ with each nonzero $\sigma_i$ replaced by
$1/\sigma_i$. Zero singular values stay zero.

$\Amat$ maps each right singular vector $\vvec_i$ to $\sigma_i\uvec_i$. $\Amat^+$ maps $\uvec_i$ back to
$\vvec_i/\sigma_i$ for $i \le r$, and maps the remaining $\uvec_i$ to zero. The pseudoinverse therefore undoes $\Amat$
on the directions that $\Amat$ keeps, and discards the directions that $\Amat$ cannot reach.

<Derivation title="The SVD formula satisfies the Penrose conditions">
Substitute $\Amat = \Umat\Sigmamat\Vmat^\top$ and $\Amat^+ = \Vmat\Sigmamat^+\Umat^\top$. The orthogonal factors cancel
in pairs, $\Vmat^\top\Vmat = \eye$ and $\Umat^\top\Umat = \eye$, so each condition reduces to the same condition for the
rectangular diagonal matrices $\Sigmamat$ and $\Sigmamat^+$. For example,
$\Amat\Amat^+\Amat = \Umat\Sigmamat\Sigmamat^+\Sigmamat\Vmat^\top$. The product $\Sigmamat\Sigmamat^+$ is diagonal with
a 1 in each of the first $r$ positions and 0 elsewhere, so $\Sigmamat\Sigmamat^+\Sigmamat = \Sigmamat$ and
$\Sigmamat^+\Sigmamat\Sigmamat^+ = \Sigmamat^+$. Both products $\Sigmamat\Sigmamat^+$ and $\Sigmamat^+\Sigmamat$ are
diagonal, hence symmetric, which gives the last two conditions. When $\Amat$ is square and invertible, every $\sigma_i$
is nonzero, $\Sigmamat^+ = \Sigmamat^{-1}$, and the formula is $\Amat^{-1}$.
</Derivation>

## Closed forms for full rank

- **Full column rank** ($\rank \Amat = n$, a tall matrix): $\Amat^+ = (\Amat^\top\Amat)^{-1}\Amat^\top$. This is the
  matrix of the normal equations. It is a left inverse: $\Amat^+\Amat = (\Amat^\top\Amat)^{-1}\Amat^\top\Amat = \eye_n$.
  In SVD terms, $\Amat^\top\Amat = \Vmat\Sigmamat^\top\Sigmamat\Vmat^\top$, so
  $(\Amat^\top\Amat)^{-1}\Amat^\top = \Vmat(\Sigmamat^\top\Sigmamat)^{-1}\Sigmamat^\top\Umat^\top$, and
  $(\Sigmamat^\top\Sigmamat)^{-1}\Sigmamat^\top = \Sigmamat^+$ when all $n$ singular values are nonzero.
- **Full row rank** ($\rank \Amat = m$, a wide matrix): $\Amat^+ = \Amat^\top(\Amat\Amat^\top)^{-1}$. It is a right
  inverse: $\Amat\Amat^+ = \Amat\Amat^\top(\Amat\Amat^\top)^{-1} = \eye_m$. The SVD argument is the same with the roles
  of $\Umat$ and $\Vmat$ swapped.

Neither formula applies when $\Amat$ is rank-deficient, because the inner matrix is then singular. The SVD form
always applies.

## Least squares and minimum norm

For the system $\Amat\xvec = \bvec$, the vector $\xvec^+ = \Amat^+\bvec$ has two properties <Cite id="golub2013" />:

1. It minimises the residual $\norm{\Amat\xvec - \bvec}$. When the system has no exact solution, $\xvec^+$ is a
   least-squares solution.
2. Among all minimisers of the residual, $\xvec^+$ has the smallest Euclidean norm. When the system has infinitely many
   solutions, $\xvec^+$ is the one closest to the origin.

Both properties come out of one calculation in the coordinates of the SVD. Orthogonal matrices preserve length, so
multiplying the residual by $\Umat^\top$ does not change its norm. Write $\yvec = \Vmat^\top\xvec$ and
$\cvec = \Umat^\top\bvec$. Then $\norm{\xvec} = \norm{\yvec}$ and

$$
\norm{\Amat\xvec - \bvec}^2 = \norm{\Umat^\top(\Umat\Sigmamat\Vmat^\top\xvec - \bvec)}^2 = \norm{\Sigmamat\yvec - \cvec}^2
= \sum_{i=1}^{r} (\sigma_i y_i - c_i)^2 + \sum_{i=r+1}^{m} c_i^2.
$$

The second sum does not depend on $\yvec$: it is the part of $\bvec$ outside the column space, which no choice of
$\xvec$ can reach. The first sum is zero exactly when $y_i = c_i/\sigma_i$ for $i \le r$. The coordinates
$y_{r+1}, \dots, y_n$ do not appear at all, so every choice of them gives a minimiser. Those coordinates are the
null-space directions.

The minimisers therefore form the set $\xvec^+ + \Null(\Amat)$. Among them, $\norm{\xvec}^2 = \norm{\yvec}^2 =
\sum_{i \le r} (c_i/\sigma_i)^2 + \sum_{i > r} y_i^2$ is smallest when the free coordinates are 0. That choice is
$\yvec = \Sigmamat^+\cvec$, which is $\xvec = \Vmat\Sigmamat^+\Umat^\top\bvec = \Amat^+\bvec$.

Two consequences follow. The fitted vector $\Amat\xvec^+ = \Amat\Amat^+\bvec$ keeps the components $c_1, \dots, c_r$ of
$\bvec$ along $\uvec_1, \dots, \uvec_r$ and drops the rest, so it is the <NoteLink to="orthogonal-projection">orthogonal
projection</NoteLink> of $\bvec$ onto the column space. And $\xvec^+$ lies in the span of $\vvec_1, \dots, \vvec_r$, the
row space, which is orthogonal to the null space. Pythagoras then gives
$\norm{\xvec^+ + \nvec}^2 = \norm{\xvec^+}^2 + \norm{\nvec}^2$ for every $\nvec \in \Null(\Amat)$.

## Worked example

Take the single equation $x_1 + 2x_2 = 5$, so $\Amat = [1 \;\; 2]$ and $\bvec = 5$. The row has full row rank, so

$$
\Amat^+ = \Amat^\top(\Amat\Amat^\top)^{-1} = \frac{1}{5}\begin{bmatrix} 1 \\ 2 \end{bmatrix}, \qquad
\xvec^+ = \Amat^+\bvec = \begin{bmatrix} 1 \\ 2 \end{bmatrix}.
$$

Every solution has the form $(1, 2) + t(2, -1)$ for a real $t$, where $(2, -1)$ spans the null space. The squared norm
is $5 + 5t^2$, which is smallest at $t = 0$. The minimum-norm solution $(1, 2)$ is parallel to the row $(1, 2)$.

## In machine learning

- **Linear regression.** With a full-column-rank design matrix $\Xmat$, the least-squares weights are
  $\hat\wvec = \Xmat^+\yvec$. With more features than examples, $\Xmat^+\yvec$ interpolates the data with the
  smallest-norm weights. Gradient descent started from zero converges to the same solution on this problem. Every
  gradient $\Xmat^\top(\Xmat\wvec - \yvec)$ lies in the row space of $\Xmat$, so iterates that start at zero never leave
  it, and the only least-squares solution in the row space is $\Xmat^+\yvec$.
- **Ridge regression as a limit.** Substituting the SVD gives
  $(\Amat^\top\Amat + \lambda\eye)^{-1}\Amat^\top = \Vmat\,\diag\paren{\sigma_i/(\sigma_i^2 + \lambda)}\,\Umat^\top$.
  Each factor $\sigma_i/(\sigma_i^2 + \lambda)$ tends to $1/\sigma_i$ as $\lambda \to 0^+$ when $\sigma_i > 0$, and is 0
  when $\sigma_i = 0$, so the ridge solution tends to $\Amat^+$. For $\lambda > 0$ the factor stays bounded as
  $\sigma_i \to 0$.

## Pitfalls

- **Discontinuity.** $\Amat^+$ is not continuous in $\Amat$. When a singular value shrinks to zero, $1/\sigma_i$ grows
  without bound, then drops to zero once $\sigma_i$ is exactly zero and the rank falls. For example, $\diag(1,
  \epsilon)^+ = \diag(1, 1/\epsilon)$ for $\epsilon \ne 0$, but $\diag(1, 0)^+ = \diag(1, 0)$.
- **Numerical rank.** Libraries treat singular values below a tolerance, such as $\max(m, n)\,\sigma_1$ times the
  machine epsilon, as zero. The result depends on that tolerance when singular values are small.
- **Forming $\Amat^\top\Amat$.** The closed form squares the condition number. Solve least-squares problems with a QR
  factorisation or the SVD instead.
- **$(\Amat\Bmat)^+ \ne \Bmat^+\Amat^+$ in general.** The reversal rule of the inverse does not carry over.
