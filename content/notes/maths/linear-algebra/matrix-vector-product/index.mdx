<Definition>
For $\Amat \in \reals^{m \times n}$ and $\xvec \in \reals^n$, the product $\Amat\xvec \in \reals^m$ has entries

$$
(\Amat\xvec)_i = \sum_{j=1}^{n} a_{ij} x_j, \qquad i = 1, \dots, m.
$$

The map $\xvec \mapsto \Amat\xvec$ is linear: $\Amat(\alpha\xvec + \beta\yvec) = \alpha\Amat\xvec + \beta\Amat\yvec$.
Every linear map from $\reals^n$ to $\reals^m$ is multiplication by exactly one $m \times n$ matrix
<Cite id="strang2016" />.
</Definition>

## Row view

Write $\avec_i^\top$ for row $i$ of $\Amat$. Then each output entry is a dot product,

$$
(\Amat\xvec)_i = \avec_i^\top\xvec.
$$

The rows act as $m$ measurements of $\xvec$, each taken along its own direction. The system $\Amat\xvec = \bvec$ reads,
row by row, as $m$ equations. In $\reals^2$ and $\reals^3$ each equation $\avec_i^\top\xvec = b_i$ is a line or a plane,
and the solution is where they meet.

## Column view

Write $\cvec_j$ for column $j$ of $\Amat$. Then

$$
\Amat\xvec = x_1\cvec_1 + x_2\cvec_2 + \dots + x_n\cvec_n.
$$

The entries of $\xvec$ are the weights of a combination of the columns. Two facts follow at once. The output always lies
in the span of the columns, the column space. And column $j$ is $\Amat\evec_j$, the image of the $j$-th standard basis
vector, so a matrix is known once the images of the basis vectors are known.

## Why the two views agree

Both views compute the same double array of products $a_{ij}x_j$ and add them up in different orders. The row view
sums across each row first: entry $i$ is $\sum_j a_{ij}x_j$. The column view scales each column first and then adds
the scaled columns: entry $i$ of $\sum_j x_j\cvec_j$ is $\sum_j x_j a_{ij}$. The two sums have the same terms, so they
are equal.

## Linear maps are matrices

The product is linear, because each entry $\sum_j a_{ij}(\alpha x_j + \beta y_j)$ splits into
$\alpha\sum_j a_{ij}x_j + \beta\sum_j a_{ij}y_j$.

The converse also holds. Let $T : \reals^n \to \reals^m$ be any linear map, and let $\Amat$ be the matrix whose column
$j$ is $T(\evec_j)$. Every $\xvec$ is the combination $\sum_j x_j\evec_j$ of the standard basis vectors, so linearity
gives

$$
T(\xvec) = T\paren{\sum_j x_j\evec_j} = \sum_j x_j\, T(\evec_j) = \sum_j x_j\cvec_j = \Amat\xvec,
$$

where the last step is the column view. The matrix is unique, because $\Amat\evec_j$ is column $j$ of $\Amat$, so any
matrix that represents $T$ must have column $j$ equal to $T(\evec_j)$. A linear map is therefore fully described by
where it sends the $n$ basis vectors.

## Worked example

$$
\begin{bmatrix} 1 & 2 \\ 3 & 4 \\ 5 & 6 \end{bmatrix} \begin{bmatrix} 2 \\ -1 \end{bmatrix}.
$$

By rows: $1 \cdot 2 + 2 \cdot (-1) = 0$, $3 \cdot 2 + 4 \cdot (-1) = 2$ and $5 \cdot 2 + 6 \cdot (-1) = 4$. By columns:
$2\,(1, 3, 5) - 1\,(2, 4, 6) = (0, 2, 4)$. Both give $(0, 2, 4)$. The first entry is 0 because $(2, -1)$ is orthogonal
to the first row.

## Cost

The product takes $mn$ multiplications and about as many additions. The entries can be visited row by row or column by
column. The order matters for speed, not for the result: memory layout decides which is faster. Row-major storage
favours the row view, and column-major storage the column view.

## In machine learning

- **Linear layers.** A fully connected layer computes $\Wmat\xvec + \bvec$. In the row view, each output unit takes a
  dot product with its own weight vector, a learned feature detector. In the column view, the output is a mixture of
  the columns, and input feature $j$ contributes $x_j$ times column $j$.
- **Linear models.** Predictions for a data set are $\hat\yvec = \Xmat\wvec$. Each row of $\Xmat$ is one example, so the
  row view gives one prediction per example; see <NoteLink to="linear-regression">linear regression</NoteLink>.
- **Embeddings.** Multiplying a matrix by a one-hot vector $\evec_j$ returns column $j$. An embedding lookup is this
  product, computed by indexing instead of multiplying.

## Pitfalls

- **Shapes.** $\Amat\xvec$ needs $\xvec$ to have as many entries as $\Amat$ has columns. Libraries that broadcast
  one-dimensional arrays can hide a transposed matrix; check shapes explicitly.
- **Left versus right multiplication.** $\xvec^\top\Amat$ combines the rows of $\Amat$, not the columns, and gives a row
  vector with $n$ entries when $\xvec \in \reals^m$.
