<Definition>
For a scalar function $f$ of a matrix $\Xmat \in \reals^{m \times n}$, the <NoteLink to="gradient">gradient</NoteLink> $\partial f / \partial \Xmat$ is the
$m \times n$ matrix of <NoteLink to="partial-derivatives">partial derivatives</NoteLink> $\partial f / \partial X_{ij}$. It is characterised by the differential

$$
df = \trace\!\paren{\Gmat^\top d\Xmat} = \sum_{i,j} G_{ij}\,dX_{ij} \quad \Longleftrightarrow \quad \frac{\partial
f}{\partial \Xmat} = \Gmat.
$$

Vectors are the special case $n = 1$, where $df = \gvec^\top d\xvec$ and $\nabla f = \gvec$ <Cite id="magnus2019" />.
</Definition>

## Convention

This note uses the gradient convention: the <NoteLink to="derivative">derivative</NoteLink> of a scalar with respect to a vector or matrix has the same
shape as that vector or matrix. This is sometimes called denominator layout. Derivatives of vector-valued functions are
<NoteLink to="jacobian">Jacobians</NoteLink>, $m \times n$ for a map $\reals^n \to \reals^m$, as in the rest of the
site. References disagree on layout, so identities copied from elsewhere may come transposed <Cite
id="petersen2012" />.

## The differential method

Computing partial derivatives entry by entry is slow and error-prone. The differential method works with whole matrices.
The differential $df$ is the first-order change in $f$ when $\Xmat$ changes by $d\Xmat$. It obeys the rules of
ordinary differentiation:

$$
d(\Amat\Xmat\Bmat) = \Amat\,d\Xmat\,\Bmat, \qquad d(\Xmat\Ymat) = d\Xmat\,\Ymat + \Xmat\,d\Ymat, \qquad d(\Xmat^\top) =
(d\Xmat)^\top,
$$

for constant $\Amat$, $\Bmat$. The recipe is:

1. Compute $df$ with these rules.
2. Rearrange it into the form $\trace(\Gmat^\top d\Xmat)$, using linearity of the trace, $\trace(\Amat^\top) =
   \trace(\Amat)$, and the cyclic property $\trace(\Amat\Bmat\Cmat) = \trace(\Cmat\Amat\Bmat)$.
3. Read off $\partial f/\partial \Xmat = \Gmat$.

A scalar equals its own trace, so step 2 can start by wrapping any scalar expression in $\trace$.

## Vector identities

**Linear function.** $f = \avec^\top\xvec$ has $df = \avec^\top d\xvec$, so $\nabla f = \avec$.

**<NoteLink to="positive-definite-matrices">Quadratic form</NoteLink>.** $f = \xvec^\top\Amat\xvec$ has $df = d\xvec^\top\Amat\xvec + \xvec^\top\Amat\,d\xvec$. The first term
is a scalar, so it equals its transpose $\xvec^\top\Amat^\top d\xvec$. Hence

$$
df = \xvec^\top(\Amat + \Amat^\top)\,d\xvec, \qquad \nabla f = (\Amat + \Amat^\top)\,\xvec,
$$

which is $2\Amat\xvec$ when $\Amat$ is symmetric.

**Squared residual.** $f = \norm{\Amat\xvec - \bvec}^2 = \rvec^\top\rvec$ with $\rvec = \Amat\xvec - \bvec$ has
$df = 2\rvec^\top d\rvec = 2\rvec^\top\Amat\,d\xvec$, so

$$
\nabla f = 2\Amat^\top(\Amat\xvec - \bvec).
$$

## Matrix identities

**Trace of a product.** $f = \trace(\Amat\Xmat)$ has $df = \trace(\Amat\,d\Xmat)$, which is
$\trace\bigl((\Amat^\top)^\top d\Xmat\bigr)$, so $\partial f / \partial \Xmat = \Amat^\top$.

**Inverse.** Differentiate $\Xmat\Xmat^{-1} = \eye$: $d\Xmat\,\Xmat^{-1} + \Xmat\,d(\Xmat^{-1}) = \zeros$, so

$$
d(\Xmat^{-1}) = -\Xmat^{-1}\,d\Xmat\,\Xmat^{-1}.
$$

This is the matrix version of $d(1/x) = -dx/x^2$. For example, $f = \trace(\Amat\Xmat^{-1})$ has $df =
-\trace(\Amat\Xmat^{-1}\,d\Xmat\,\Xmat^{-1}) = -\trace(\Xmat^{-1}\Amat\Xmat^{-1}\,d\Xmat)$ by the cyclic property, so
$\partial f / \partial \Xmat = -\Xmat^{-\top}\Amat^\top\Xmat^{-\top}$.

**Log-determinant.** For invertible $\Xmat$,

$$
\det(\Xmat + d\Xmat) = \det\Xmat\,\det(\eye + \Xmat^{-1}d\Xmat) = \det\Xmat\,\bigl(1 + \trace(\Xmat^{-1}d\Xmat) +
O(\norm{d\Xmat}^2)\bigr).
$$

The second step uses $\det(\eye + \Emat) = \prod_i(1 + \mu_i) = 1 + \sum_i\mu_i + \dots$ over the eigenvalues $\mu_i$ of
a small $\Emat$, and $\sum_i \mu_i = \trace\Emat$. Taking logarithms,

$$
d\log\det\Xmat = \trace(\Xmat^{-1}d\Xmat), \qquad \frac{\partial \log\det\Xmat}{\partial\Xmat} = \Xmat^{-\top},
$$

which is $\Xmat^{-1}$ for symmetric $\Xmat$.

| $f$ | $df$ | $\partial f / \partial (\cdot)$ |
| --- | --- | --- |
| $\avec^\top\xvec$ | $\avec^\top d\xvec$ | $\avec$ |
| $\xvec^\top\Amat\xvec$ | $\xvec^\top(\Amat + \Amat^\top)\,d\xvec$ | $(\Amat + \Amat^\top)\xvec$ |
| $\norm{\Amat\xvec - \bvec}^2$ | $2(\Amat\xvec - \bvec)^\top\Amat\,d\xvec$ | $2\Amat^\top(\Amat\xvec - \bvec)$ |
| $\trace(\Amat\Xmat)$ | $\trace(\Amat\,d\Xmat)$ | $\Amat^\top$ |
| $\trace(\Amat\Xmat^{-1})$ | $-\trace(\Xmat^{-1}\Amat\Xmat^{-1}d\Xmat)$ | $-\Xmat^{-\top}\Amat^\top\Xmat^{-\top}$ |
| $\log\det\Xmat$ | $\trace(\Xmat^{-1}d\Xmat)$ | $\Xmat^{-\top}$ |

## Worked example: least squares

<NoteLink to="linear-regression">Linear regression</NoteLink> minimises $L(\wvec) = \norm{\Xmat\wvec - \yvec}^2$ over the
weights. The squared-residual identity gives $\nabla L = 2\Xmat^\top(\Xmat\wvec - \yvec)$. Setting it to zero gives the
normal equations

$$
\Xmat^\top\Xmat\,\wvec = \Xmat^\top\yvec.
$$

## Worked example: the Gaussian covariance

Given centred observations $\xvec_1, \dots, \xvec_n \in \reals^d$ (subtract the mean first) and
$\Smat = \sum_i \xvec_i\xvec_i^\top$, the log-likelihood of a
<NoteLink to="multivariate-normal-distribution">multivariate normal</NoteLink> covariance $\Sigmamat$ is, up to a
constant,

$$
\ell(\Sigmamat) = -\frac{n}{2}\log\det\Sigmamat - \frac{1}{2}\sum_i \xvec_i^\top\Sigmamat^{-1}\xvec_i
= -\frac{n}{2}\log\det\Sigmamat - \frac{1}{2}\trace(\Sigmamat^{-1}\Smat).
$$

The second form uses $\xvec^\top\Amat\xvec = \trace(\Amat\xvec\xvec^\top)$. The log-determinant and inverse rules give

$$
d\ell = -\frac{n}{2}\trace(\Sigmamat^{-1}d\Sigmamat) + \frac{1}{2}\trace(\Sigmamat^{-1}d\Sigmamat\,\Sigmamat^{-1}\Smat)
= \frac{1}{2}\trace\bigl((\Sigmamat^{-1}\Smat\Sigmamat^{-1} - n\Sigmamat^{-1})\,d\Sigmamat\bigr).
$$

The gradient is zero when $\Sigmamat^{-1}\Smat\Sigmamat^{-1} = n\Sigmamat^{-1}$, that is

$$
\hat\Sigmamat = \frac{1}{n}\Smat = \frac{1}{n}\sum_i \xvec_i\xvec_i^\top.
$$

The maximum-likelihood covariance is the average <NoteLink to="matrix-multiplication">outer product</NoteLink>, which divides by $n$ rather than $n - 1$.

## Pitfalls

- **Layout.** A formula from a source using numerator layout is the transpose of the one here. Check shapes: the
  gradient must have the shape of the variable.
- **Symmetric variables.** When $\Xmat$ is constrained to be symmetric, its entries $X_{ij}$ and $X_{ji}$ are one
  variable, and some references then write $\partial\log\det\Xmat/\partial\Xmat = 2\Xmat^{-1} - \diag(\Xmat^{-1})$.
  Setting a gradient to zero gives the same stationary points either way; the difference matters when the gradient is
  used in an update.
- **Checking.** Compare every hand-derived gradient with central finite differences on a random small input before
  relying on it.
