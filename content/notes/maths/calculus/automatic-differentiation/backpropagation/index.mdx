<Definition>
The <NoteLink to="derivative">chain rule</NoteLink> states that for $y = g(u)$ and $u = h(x)$,
$\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}$. In several variables, the <NoteLink to="jacobian">Jacobian</NoteLink> of
a composition is the product of the Jacobians. Backpropagation is reverse-mode automatic differentiation: it applies the
chain rule from the output towards the inputs <Cite id="rumelhart1986" />.
</Definition>

## Problem

A neural network's loss is a scalar that depends on millions of parameters through a long composition of functions.
Training needs the <NoteLink to="gradient">gradient</NoteLink> of the loss with respect to every parameter. Finite
differences would need one extra evaluation of the loss per parameter. Symbolic differentiation produces expressions
that grow exponentially with depth.

## Mechanism

Break the computation into a graph of primitive operations, each with a known local derivative. For a scalar output
$f$, define the **adjoint** of each intermediate value $v$ as $\bar v = \partial f / \partial v$.

1. **Forward pass.** Evaluate every node from the inputs to $f$, storing each value.
2. **Seed.** Set $\bar f = 1$.
3. **Backward pass.** Visit the nodes in reverse order. For each node $v$, sum over the nodes $w$ that use it:
   $$
   \bar v = \sum_{w \,:\, v \to w} \bar w \,\frac{\partial w}{\partial v}.
   $$

The adjoints of the inputs are the gradient. The sum over uses is the
<NoteLink to="multivariable-chain-rule">multivariable chain rule</NoteLink>: a value that feeds several later
computations collects a contribution from each.

## Example

Take the function of two inputs

$$
f(x, y) = \paren{xy + \sin x}^2.
$$

As a graph of primitive operations it is

$$
a = xy, \qquad b = \sin x, \qquad c = a + b, \qquad f = c^2,
$$

so $x$ feeds two nodes, $a$ and $b$, and its adjoint collects a contribution from each.

### Local derivatives

Each node depends on its inputs through one primitive operation, so each <NoteLink to="partial-derivatives">partial
derivative</NoteLink> is a single rule of calculus:

$$
\begin{aligned}
a &= xy: & \frac{\partial a}{\partial x} &= y, & \frac{\partial a}{\partial y} &= x & &\text{(the other factor is held fixed)} \\[10pt]
b &= \sin x: & \frac{\partial b}{\partial x} &= \cos x & & & & \\[10pt]
c &= a + b: & \frac{\partial c}{\partial a} &= 1, & \frac{\partial c}{\partial b} &= 1 & &\text{(a sum changes one-for-one with each term)} \\[10pt]
f &= c^2: & \frac{\partial f}{\partial c} &= 2c & & & &\text{(power rule)}
\end{aligned}
$$

These are local: each is computed from the node's own inputs, without reference to the rest of the graph.

### Backward pass

Start from $\bar f = \partial f / \partial f = 1$ and apply $\bar v = \sum_{w} \bar w\, \partial w / \partial v$ to each
node in reverse order. Every node except $x$ is used by exactly one later node, so its sum has one term:

$$
\begin{aligned}
\bar c &= \bar f\, \frac{\partial f}{\partial c} = 2c, \\[10pt]
\bar a &= \bar c\, \frac{\partial c}{\partial a} = \bar c, \qquad
\bar b = \bar c\, \frac{\partial c}{\partial b} = \bar c, \\[10pt]
\bar y &= \bar a\, \frac{\partial a}{\partial y} = \bar a\, x.
\end{aligned}
$$

The input $x$ is used by both $a$ and $b$, so its adjoint has two terms, one for each path from $x$ to $f$:

$$
\bar x = \bar a\, \frac{\partial a}{\partial x} + \bar b\, \frac{\partial b}{\partial x} = \bar a\, y + \bar b \cos x.
$$

Substituting $\bar a = \bar b = \bar c = 2c$ and $c = xy + \sin x$ gives the gradient:

$$
\frac{\partial f}{\partial x} = 2(xy + \sin x)(y + \cos x), \qquad \frac{\partial f}{\partial y} = 2(xy + \sin x)\,x.
$$

Differentiating $f$ directly with the chain rule gives the same result, since
$\partial f / \partial x = 2(xy + \sin x) \cdot \partial (xy + \sin x) / \partial x$. The backward pass reaches it
without ever forming the expression for $f$: it multiplies numbers along the graph.

## Cost

Reverse mode computes the full gradient of a scalar output in a small constant multiple of the cost of evaluating $f$,
whatever the number of inputs <Cite id="griewank2008" />. This is the cheap gradient principle, and it is why
networks with billions of parameters can be trained.

<NoteLink to="forward-mode-autodiff">Forward mode</NoteLink> is the alternative: it propagates derivatives from the
inputs, one input direction per pass. It is efficient when there are few inputs and many outputs. Reverse mode is
efficient in the opposite case, one scalar loss and many parameters, which is the machine-learning case
<Cite id="baydin2018" />.

## Trade-offs

- **Memory.** The backward pass needs the forward values, so they must be stored. Activation memory, not arithmetic,
  often limits the <NoteLink to="minibatching-and-batch-size">batch size</NoteLink>.
  <NoteLink to="gradient-checkpointing">Gradient checkpointing</NoteLink> stores only some values and recomputes the
  rest.
- **Vector–Jacobian products.** Each backward step multiplies a row vector of adjoints by a local Jacobian. The full
  Jacobian is never formed; see <NoteLink to="jacobian-vector-products-and-higher-order-derivatives">JVPs, VJPs and
  higher-order derivatives</NoteLink>.
- **Implementations.** Libraries find the operations to reverse by recording them at run time
  (<NoteLink to="operator-overloading-and-tapes">operator overloading and tapes</NoteLink>) or by transforming the
  program before it runs (<NoteLink to="source-transformation-autodiff">source transformation</NoteLink>). The
  <NoteLink to="history-of-automatic-differentiation">history of automatic differentiation</NoteLink> compares them.
- **Numerical checks.** Compare the result with central finite differences, $\paren{f(x + \epsilon) - f(x -
  \epsilon)}/(2\epsilon)$, on a few inputs when implementing a new operation.

## Pitfalls

- **<NoteLink to="vanishing-and-exploding-gradients">Vanishing and exploding gradients</NoteLink>.** The backward pass
  multiplies many local derivatives. When they are consistently below or above 1, gradients in early layers shrink or
  grow exponentially with depth.
- **Non-differentiable operations.** Rounding, sorting and sampling have zero or undefined derivatives. They need
  surrogate gradients or reparameterisation.
