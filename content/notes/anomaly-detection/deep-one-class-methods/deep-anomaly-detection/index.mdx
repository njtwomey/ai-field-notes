<Definition>
A deep anomaly detector computes its <NoteLink to="anomaly-detection">anomaly score</NoteLink> in a feature space produced by a neural network $\phi$. The score is
a distance, such as $\norm{\phi(\xvec) - \cvec}^2$ or the distance to the nearest normal feature, or a probability,
such as that of a classifier's correct answer. The detectors differ in how $\phi$ is obtained: trained on normal data
with a one-class objective, trained with a few labelled or generated anomalies, trained on a <NoteLink to="self-supervised-learning">pretext task</NoteLink>, or
pretrained on unrelated labelled data <Cite id="ruff2021" />.
</Definition>

## The shared problem: what the features should keep

Shallow detectors such as the <NoteLink to="one-class-support-vector-machine">one-class support vector machine</NoteLink> and
<NoteLink to="support-vector-data-description">support vector data description</NoteLink> fix the feature map through a kernel and learn a boundary in it. For
images, audio or text no fixed kernel captures the variations that matter. Deep detectors learn or borrow the feature
map instead. A review by Ruff and colleagues frames every detector, shallow or deep, by the same components: a feature
map, a model on top of it, a loss and a regulariser <Cite id="ruff2021" />.

Learning a feature map from normal data alone raises one problem that shallow methods never face. An objective that
asks normal data to be compact, or far from the origin, is satisfied perfectly by a network that ignores its input. This
**feature collapse** is the thread that connects the family: each method is defined as much by how it rules out the
constant map as by its objective.

## Comparison

| Method | Objective | Supervision | Main assumption | Collapse guard | Works well when |
| --- | --- | --- | --- | --- | --- |
| <NoteLink to="deep-support-vector-data-description">Deep SVDD</NoteLink> | pull embeddings to a fixed centre $\cvec$ | normal data only | normal data share features anomalies lack | fixed $\cvec$, no biases, unbounded activations | data are clean and a good initial network exists |
| <NoteLink to="deep-semi-supervised-anomaly-detection">Deep SAD</NoteLink> | Deep SVDD plus $\eta/d$ for labelled anomalies | a few labelled anomalies | anomalies are not concentrated | labelled anomalies make $\phi \equiv \cvec$ costly | some anomalies are known, future ones may differ |
| <NoteLink to="one-class-neural-networks">OC-NN</NoteLink> | one-class SVM margin on learned features | normal data only | features exist that lift all normal data away from the origin | <Gloss name="weight-decay">weight decay</Gloss>; frozen pretrained input | a good pretrained code needs a shallow refinement |
| <NoteLink to="fully-convolutional-data-description">FCDD</NoteLink> | pseudo-Huber distance per output cell, cross-entropy on negatives | normal data plus auxiliary or synthetic anomalies | anomalies are local | negatives make the constant map suboptimal | defects must be located and explained |
| <NoteLink to="deep-robust-one-class-classification">DROCC</NoteLink> | classify data against adversarial points at distance $r$ to $\gamma r$ | normal data only | normal data lie on a well-sampled low-dimensional manifold | generated negatives | input-space distances are meaningful at scale $r$ |
| <NoteLink to="self-supervised-anomaly-detection">Transformation prediction</NoteLink> (GEOM, GOAD) | classify which of $M$ transformations was applied | normal data only | normal data carry a signature of each transformation | a constant network cannot solve the task | images with a canonical orientation; tabular data with random affine maps (GOAD) |
| <NoteLink to="self-supervised-anomaly-detection">CSI</NoteLink> | <NoteLink to="contrastive-learning">contrastive learning</NoteLink> with shifted copies as negatives | normal data only | some transformations shift the distribution | contrastive negatives | natural images, semantic anomalies |
| <NoteLink to="pretrained-features-for-anomaly-detection">k-NN on pretrained features</NoteLink> | none: nearest-neighbour distance | normal data plus a pretrained network | the pretraining domain resembles the target | frozen features cannot collapse | natural images; few normal examples |
| <NoteLink to="pretrained-features-for-anomaly-detection">PANDA, mean-shifted contrastive</NoteLink> | compactness or contrastive fine-tuning of pretrained features | normal data plus a pretrained network | as above | <NoteLink to="early-stopping">early stopping</NoteLink>, <NoteLink to="regularisation-based-continual-learning">elastic weight consolidation</NoteLink>, mean-shifted angles | pretrained features are good but not tuned to the class |
| <NoteLink to="pretrained-features-for-anomaly-detection">PatchCore</NoteLink> | nearest-neighbour distance per patch, maximum over patches | normal data plus a pretrained network | defects change local mid-level features | frozen features | industrial inspection and defect segmentation |
| <NoteLink to="autoencoder-anomaly-detection">Autoencoder</NoteLink> | reconstruction error | normal data only | anomalies reconstruct badly | the decoder must reproduce the input | smooth, low-dimensional normal data |

## Choosing a method

- **With a pretrained network for the domain, start there.** A nearest-neighbour score on frozen pretrained features is
  simple, cannot collapse and has been hard to beat on natural images <Cite id="bergman2020b" />. For defects, use patch
  features with a memory bank <Cite id="roth2022" />.
- **With some known anomalies, use them as negatives.** Deep SAD, FCDD and outlier exposure all turn a one-class
  problem into a better-posed one. Evaluate on anomaly types absent from the labelled set.
- **Without pretraining or labels, prefer a task that needs discrimination.** Transformation prediction, contrastive
  learning with shifts and DROCC all train on a task that the constant map fails. Pure one-class objectives such as Deep
  SVDD and OC-NN need architectural restrictions and a good initialisation to avoid collapse.
- **Data without a spatial or semantic structure** (tabular records, sensor vectors) benefit less from deep features.
  Compare against shallow detectors such as the <NoteLink to="isolation-forest">isolation forest</NoteLink> before choosing a deep one.

In every case the detector's notion of normality is its feature space. An anomaly that the features cannot express,
whether they were learned, generated or borrowed, is invisible to the score.
