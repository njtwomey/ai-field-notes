<Definition>
A **generative classifier** models the joint distribution $p(\xvec, y) = p(y)\,p(\xvec \mid y)$ of features and
label. It estimates a prior $p(y)$ for each class and a class-conditional density $p(\xvec \mid y)$, then classifies a
new input by Bayes' theorem, $p(y \mid \xvec) \propto p(y)\,p(\xvec \mid y)$. The classifiers in this topic differ
only in the model they choose for $p(\xvec \mid y)$.
</Definition>

## What it is for

Generative classifiers train fast, often in a single pass of counting or averaging, and work with few examples. They
handle missing features by marginalising them out, and they can generate typical inputs for each class. Naive Bayes
remains a standard baseline for <NoteLink to="text-classification">text classification</NoteLink> and spam filtering.
Linear discriminant analysis is used both as a classifier and as a supervised projection for visualisation.

## Main ideas

**The density model sets the boundary.** If every class is Gaussian with one shared covariance matrix, the quadratic
terms cancel and the boundary between two classes is a hyperplane: <NoteLink to="linear-discriminant-analysis" />
(LDA). If each class has its own covariance, the boundaries are quadrics:
<NoteLink to="quadratic-discriminant-analysis" /> (QDA). QDA needs a covariance matrix per class, which costs
$d(d+1)/2$ parameters each for $d$ features.

**Independence assumptions buy data efficiency.** <NoteLink to="naive-bayes" /> assumes the features are conditionally
independent given the class, so $p(\xvec \mid y) = \prod_j p(x_j \mid y)$. Each factor is estimated separately, from
counts or one-dimensional densities. The assumption is usually false. Naive Bayes still ranks and classifies well, but
its probabilities are overconfident.

**Relaxing independence one dependency at a time.** <NoteLink to="tree-augmented-naive-bayes" /> (TAN) lets each
feature depend on one other feature as well as the class. The best tree is a maximum spanning tree weighted by
conditional mutual information <Cite id="friedman1997" />. <NoteLink to="averaged-one-dependence-estimators" /> (AODE)
averages over models in which a single feature is the parent of all the others, which avoids learning any structure.
Both sit between naive Bayes and a full <NoteLink to="bayesian-network" />.

**Generative against discriminative.** A discriminative model such as logistic regression fits $p(y \mid \xvec)$
directly. <NoteLink to="generative-vs-discriminative" /> compares the pair naive Bayes and logistic regression, which
share the same form of posterior: the discriminative model has lower asymptotic error, and the generative model
approaches its own limit with far fewer examples <Cite id="ng2002" />.

The notes assume <NoteLink to="bayes-theorem" /> and the <NoteLink to="multivariate-normal-distribution">multivariate

trees.

Generative classifiers connect to several other topics. A <NoteLink to="gaussian-mixture-model" /> is QDA with the
labels unobserved. The posterior of LDA has the same form as <NoteLink to="logistic-regression">logistic
regression</NoteLink> and, for $K$ classes, <NoteLink to="multinomial-logistic-regression">multinomial logistic
regression</NoteLink>. <NoteLink to="hidden-markov-model">Hidden Markov models</NoteLink> in
<NoteLink to="structured-prediction">structured prediction</NoteLink> are generative classifiers for sequences.
