<Definition>
A **Markov decision process** (MDP) models an agent that repeatedly observes a state, chooses an action, receives a
reward and moves to a new state with probabilities that depend only on the current state and action. **Dynamic
programming** computes the best policy of a known MDP by solving the Bellman equations, which express the value of a
state through the values of its successors <Cite id="puterman1994" />. <Gloss name="rl">Reinforcement learning</Gloss>
solves the same problem when the transition probabilities and rewards are unknown.
</Definition>

## What it is for

MDPs formalise inventory control, queueing and maintenance scheduling, robot navigation, game playing and dialogue.
Every reinforcement-learning algorithm in this Part assumes an MDP, and its notation, <Gloss name="value-function">value
functions</Gloss> and Bellman operators come from this topic. Dynamic programming also gives the reference solution
against which sampled methods are checked on small problems.

## Main ideas

**Returns, policies and values.** The <NoteLink to="markov-decision-process" /> note defines the tuple
$(\Scal, \Acal, p, r, \gamma)$, the discounted return $\sum_t \gamma^t R_{t+1}$ with discount $\gamma \in [0, 1)$, a
policy $\pi(a \mid s)$, and the value $v_\pi(s)$, the expected return from state $s$ when following $\pi$. Action
values $q_\pi(s, a)$ condition also on the first action <Cite id="sutton2018" />.

**Bellman equations.** <NoteLink to="bellman-equations" /> writes each value as the immediate reward plus the
discounted value of the next state. For a fixed policy the equations are linear in $v_\pi$. For the optimal value $v_*$
they contain a maximum over actions. Both right-hand sides are $\gamma$-contractions, so each equation has a unique
solution and repeated application converges to it.

**Evaluate, then improve.** <NoteLink to="policy-iteration" /> alternates solving for $v_\pi$ exactly and making the
policy greedy with respect to it. The policy improvement theorem guarantees each new policy is at least as good, and a
finite MDP is solved in finitely many iterations.

**Iterate the optimality operator.** <NoteLink to="value-iteration" /> applies the Bellman optimality update
repeatedly. The error shrinks by a factor $\gamma$ per sweep, and the greedy policy of the current values becomes
optimal before the values converge.

**From planning to learning.** <NoteLink to="solving-a-maze" /> solves one small MDP three ways: by value iteration with
the model, and by <NoteLink to="q-learning">Q-learning</NoteLink> and <Gloss name="sarsa" /> from experience. The routes
they learn differ near traps, which shows the difference between learning optimal values and learning the values of an
exploring policy.

## Prerequisites and next steps

The notes assume <NoteLink to="expectation">expectation</NoteLink>, <NoteLink to="conditional-probability">conditional
probability</NoteLink>, the <NoteLink to="law-of-total-expectation">law of total expectation and variance</NoteLink> and
the idea of a <NoteLink to="markov-chain" />, which an MDP becomes once a policy is fixed.

<NoteLink to="value-based-methods" /> replace the known model with sampled transitions. <NoteLink to="policy-methods" />
optimise a parameterised policy directly. <NoteLink to="optimal-control" /> and the
<NoteLink to="linear-quadratic-regulator">linear-quadratic regulator</NoteLink> solve the continuous-state counterpart,
where the Bellman equation for linear dynamics and quadratic cost has a closed-form solution.
