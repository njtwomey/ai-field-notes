<Definition>
**Pseudo-labelling** is self-training inside one training run of a network. For each unlabelled input $\xvec$ the
network's most probable class $\hat y = \argmax_k p_\theta(k \mid \xvec)$ is used as a hard target, the
**pseudo-label**, if its probability reaches a confidence threshold $\tau$. The training loss adds the cross-entropy on
pseudo-labelled points to the cross-entropy on labelled points, and pseudo-labels are recomputed as the network changes
<Cite id="lee2013pseudo" />.
</Definition>

## Problem

<NoteLink to="self-training">Self-training</NoteLink> refits a model from scratch each round on a growing labelled set.
For a network trained by <Gloss name="sgd">stochastic gradient descent</Gloss>, a full refit per round is wasteful, and
the network's predictions change every step anyway. Pseudo-labelling folds the labelling into training: every minibatch
of unlabelled inputs is labelled by the current network, and those labels train it on the same step. It keeps
self-training's idea, that a model's confident predictions on unlabelled data are mostly right, and changes the schedule
from rounds to steps.

The method needs no extra model, no augmentation pipeline and no change to the architecture, which is why it remains a
building block in 2024 to 2026 practice. It is rarely used alone on images now. The pseudo-label half of
<NoteLink to="fixmatch">FixMatch</NoteLink> and its successors is pseudo-labelling with a threshold, and teacher
models, including <Gloss name="language-model">language models</Gloss> labelling text (see
<NoteLink to="labelling-with-language-models">labelling with language models</NoteLink>), supply pseudo-labels for
distillation.

## Mechanism

### The loss

Let a minibatch hold $B$ labelled pairs $(\xvec_b, y_b)$ and $\mu B$ unlabelled inputs $\xvec'_u$, with $\mu$ the ratio
of unlabelled to labelled batch size. Write $p_\theta(\cdot \mid \xvec) \in [0, 1]^K$ for the network's class
probabilities over $K$ classes, $c_u = \max_k p_\theta(k \mid \xvec'_u)$ for the confidence and $\hat y_u$ for the arg
max. The loss is

$$
\mathcal{L}(\theta) = \frac{1}{B}\sum_{b=1}^{B} -\log p_\theta(y_b \mid \xvec_b)
+ \alpha(t)\,\frac{1}{\mu B}\sum_{u=1}^{\mu B} \indicator[c_u \ge \tau]\,\bigl(-\log p_\theta(\hat y_u \mid \xvec'_u)\bigr).
$$

The pseudo-label $\hat y_u$ is treated as a constant: no gradient flows through the arg max. The weight
$\alpha(t) \ge 0$ balances the two terms. Lee raised it linearly from 0 at epoch $T_1 = 100$ to $\alpha_f = 3$ at epoch
$T_2 = 600$, so that the network first learns from labels and only later from its own predictions
<Cite id="lee2013pseudo" />. Lee used no threshold ($\tau = 0$, every unlabelled point pseudo-labelled); thresholds came
later and are now the default.

### Why it helps: entropy minimisation

For one unlabelled point the pseudo-label term is $-\log\max_k p_\theta(k \mid \xvec)$. It is small when the network is
confident and large when its probabilities are spread out. The Shannon entropy of the prediction,
$H(p) = -\sum_k p_k \log p_k$, behaves the same way, and the two are ordered: $H(p)$ is the average of $-\log p_k$ under
$p$, and an average is at least its smallest term, so

$$
-\log\max_k p_k \le H(p).
$$

Both vanish exactly at one-hot predictions. Training on hard pseudo-labels therefore minimises a lower bound on the
prediction entropy on unlabelled data that is zero exactly where the entropy is, which Lee identified as
<NoteLink to="entropy-minimisation">entropy minimisation</NoteLink> <Cite id="lee2013pseudo" /> (Grandvalet and
Bengio's regulariser, <Cite id="grandvalet2005" />). Low entropy everywhere on the unlabelled data is possible only if
the decision boundary avoids them, so the loss pushes the boundary into low-density regions.

### The threshold

The threshold decides which predictions count. Each pseudo-labelled point adds a target that is right with some
probability. A high $\tau$ keeps few points, nearly all right. A low $\tau$ keeps many, more of them wrong. The best
$\tau$ depends on how well the confidences are calibrated: if 95% confidence means 95% accuracy, $\tau = 0.95$ admits
pseudo-labels about 5% wrong. Networks trained with cross-entropy are usually overconfident, so the real error rate is
higher (see <NoteLink to="classifier-calibration">classifier calibration</NoteLink>). FixMatch uses $\tau = 0.95$ on
images <Cite id="sohn2020" />.

### Confirmation bias

A pseudo-label is a target the network chose for itself. If it is wrong, the gradient pushes the prediction further
towards the wrong class. The derivative of the cross-entropy $-\log p_\theta(\hat y \mid \xvec)$ with respect to the
logit of class $k$ is $p_k - \indicator[k = \hat y]$, so the step always raises the probability of the class the network
already favours. A mistake becomes more confident, stays above the threshold and is reinforced at every later step.
Arazo and colleagues named this **confirmation bias** and showed it on two moons with four labels per class
<Cite id="arazo2020pseudo" />. The figure below shows the same effect: at $\tau = 0.5$ the first model's mistakes are
all pseudo-labelled at once, and the refitted model reproduces them.

## Worked example

A binary network gives $p = P(y = 1 \mid \xvec)$ on six unlabelled points:

| point | $p$  | pseudo-label | confidence $\max(p, 1 - p)$ | true class |
| ----- | ---- | ------------ | --------------------------- | ---------- |
| 1     | 0.97 | 1            | 0.97                        | 1          |
| 2     | 0.88 | 1            | 0.88                        | 1          |
| 3     | 0.64 | 1            | 0.64                        | 0          |
| 4     | 0.45 | 0            | 0.55                        | 1          |
| 5     | 0.12 | 0            | 0.88                        | 0          |
| 6     | 0.03 | 0            | 0.97                        | 0          |

**Which points are used.** With $\tau = 0.85$ points 1, 2, 5 and 6 qualify, all four correctly labelled. With
$\tau = 0.6$ point 3 joins with the wrong label 1: five pseudo-labels, one wrong (20%). With no threshold all six are
used and points 3 and 4 are wrong (33%).

**The loss.** With $\tau = 0.85$ the unlabelled term is the mean of $-\log 0.97 = 0.031$, $-\log 0.88 = 0.128$,
$-\log 0.88 = 0.128$ and $-\log 0.97 = 0.031$, which is $0.079$. The confident points contribute little: the
logit gradient $p - \hat y$ is $-0.03$ for point 1 and $-0.12$ for point 2.

**The mistake.** With $\tau = 0.6$, point 3 has pseudo-label 1 and logit gradient $0.64 - 1 = -0.36$.
<NoteLink to="gradient-descent">Gradient descent</NoteLink> moves its logit up, so $p$ rises above 0.64 towards 1, away
from its true class 0. The next step sees a more confident mistake and pushes it further. This is confirmation bias in
one point.

**On two moons.** The figure runs pseudo-labelling as rounds of refitting, with a
<NoteLink to="logistic-regression">logistic regression</NoteLink> on 40 <NoteLink to="random-fourier-features">random
Fourier features</NoteLink> (a network with a frozen random first layer) and four labels per class. With data seed 3 the
labelled points alone give accuracy $0.942$ on the 292 unlabelled points. At $\tau = 0.5$ all 292 are pseudo-labelled in
round 0, 17 of them (5.8%) wrongly, and the refit reproduces exactly those labels: the run stops at $0.942$. At
$\tau = 0.9$ round 0 admits 207 pseudo-labels, none wrong; the boundary moves, and by round 2 every unlabelled point is
classified correctly. At $\tau = 0.99$ only 32 points qualify at first, and the run creeps to $0.949$ by round 8.

## Cost

Each step adds a forward pass over $\mu B$ unlabelled inputs and a backward pass through the ones above the threshold.
With $\mu = 7$, FixMatch's ratio, an unlabelled step costs about seven times a labelled one. No extra parameters are
stored. Round-based variants, such as curriculum labelling, retrain the network once per round.

## Trade-offs

- **Threshold against coverage.** A fixed high threshold admits few points early in training, when the network is
  unsure everywhere, and favours classes that are easy to learn. Curriculum labelling instead admits the most
  confident 20% of unlabelled points in the first round, 40% in the second and so on, retraining from a fresh
  initialisation each round so that early mistakes are not inherited <Cite id="cascantebonilla2021curriculum" />.
  FlexMatch lowers each class's threshold according to how many confident predictions that class already gets
  <Cite id="zhang2021flexmatch" />. See <NoteLink to="adaptive-confidence-thresholds">adaptive confidence
  thresholds</NoteLink>.
- **Hard against soft labels.** A hard label discards the network's uncertainty. Training on the soft prediction itself
  gives zero gradient (the target equals the prediction), so soft pseudo-labels need a sharpened or a separate teacher.
  Arazo and colleagues used soft pseudo-labels with <NoteLink to="mixup-and-cutmix">mixup</NoteLink> and a minimum
  number of labelled examples per minibatch, both of which reduce confirmation bias <Cite id="arazo2020pseudo" />.
- **Confidence against uncertainty.** Uncertainty-aware selection keeps a pseudo-label only when the prediction is both
  confident and stable under an uncertainty estimate, and adds negative pseudo-labels for classes the input surely
  does not belong to <Cite id="rizve2021ups" />.
- **Self against teacher.** Using a separate teacher, frozen or slowly updated, breaks the loop in which a model
  confirms its own errors. <NoteLink to="noisy-student">Noisy Student</NoteLink> trains a new student per round; Meta
  Pseudo Labels updates the teacher from the student's performance on labelled data <Cite id="pham2021meta" />.

## Pitfalls

- **Early mistakes are permanent.** Without a ramp-up of $\alpha(t)$ or a threshold, the untrained network's guesses
  become targets in the first epochs and are reinforced from then on.
- **<NoteLink to="class-imbalance">Class imbalance</NoteLink> in the pseudo-labels.** Easy classes clear the threshold
  first and dominate the unlabelled loss, which pushes the boundary into the harder classes. Per-class caps or per-class
  thresholds counter this.
- **<Gloss name="ood">Out-of-distribution</Gloss> unlabelled data.** Inputs from classes absent from the labelled set
  are confidently assigned to some known class and corrupt it (see
  <NoteLink to="open-set-semi-supervised-learning">open-set semi-supervised learning</NoteLink>).
- **A weak base model.** If the labelled-only model is wrong on a whole cluster, pseudo-labelling labels that cluster
  wrongly with confidence. No threshold fixes a confident systematic mistake.
