## Architecture

The item-side models differ in how much structure they aggregate. PinSage is a <Gloss name="gcn">graph convolutional network</Gloss>: two layers
of a dense transform, a mean weighted by <NoteLink to="random-walk">random-walk</NoteLink> visit counts and a concatenation with the node's own vector
<Cite id="ying2018pinsage" />. ItemSage aggregates no graph at all. It treats a product's image embeddings and text
fields as a set of 32 tokens and reads them with one transformer layer through a `[CLS]` token
<Cite id="baltescu2022itemsage" />. OmniSage combines the two ideas: it samples graph neighbourhoods as PinSage does, but
reads the node's and neighbours' features with a transformer, as ItemSage reads a product's features
<Cite id="badrinath2025omnisage" />.

The user-side models differ in when they run and whether they see the candidate. PinnerSage and PinnerFormer run once a
day and produce vectors that do not depend on the candidate; they can be looked up in a feature store or used as
nearest-neighbour queries. TransAct and PinFM run inside the ranker for every candidate and attend to the user's actions
together with the candidate's embedding, which is more accurate and far more expensive
<Cite id="xia2023transact" /> <Cite id="chen2025pinfm" />.

## Training

- **PinSage.** Max-margin loss on pins engaged with in sequence; 500 shared random negatives per batch; hard negatives
  ranked 2,000 to 5,000 by personalised PageRank, added one more per epoch.
- **PinnerSage.** No training. Quality comes from the fixed PinSage embeddings, Ward's criterion and the threshold
  $\alpha$.
- **PinnerFormer.** Each sampled position predicts a random positive engagement from the next 28 days; mixed in-batch and
  random negatives with a <NoteLink to="two-tower-model">logQ correction</NoteLink>.
- **ItemSage.** Separate in-batch and random-negative softmax terms, with positives from four engagement types allocated
  within each batch.
- **TransAct.** Trained end to end with the ranker's weighted cross-entropy; a random time-window mask of up to 24 hours
  in training.
- **OmniSage.** Weighted sum of entity–entity, entity–feature and next- and future-entity contrastive losses.
- **PinFM.** Pretrained with next-, multi- and future-token contrastive losses on two years of activity, then fine-tuned
  with the ranker at about a tenth of its <Gloss name="learning-rate">learning rate</Gloss>.

## What is distinctive

- **PinSage** made graph convolutions work on billions of nodes, with <NoteLink to="graphsage">neighbourhood sampling</NoteLink>, <NoteLink to="pinsage">producer–consumer
  minibatches</NoteLink> and layer-wise MapReduce inference.
- **PinnerSage** represents a user by as many vectors as the data supports, chosen as real pins so that results can be
  cached by pin id.
- **PinnerFormer** trains for a long horizon so that a daily embedding loses less to staleness.
- **ItemSage** makes one embedding compatible with two frozen query spaces, so three surfaces share one index.
- **TransAct** pairs a real-time sequence model with the daily PinnerFormer embedding in one ranker.
- **OmniSage** trains graph embeddings end to end on user sequences as well as on graph and content signals.
- **PinFM** transfers one pretrained sequence model to several rankers and serves it by deduplicating user histories.

## Comparison

Reported headline results are measured on different tasks, surfaces and baselines, so they cannot be ranked against each
other.

| model        | compared with                          | reported online effect                                             |
| ------------ | -------------------------------------- | ------------------------------------------------------------------ |
| PinSage      | annotation and visual embeddings       | repin rate +10% to +30% on homefeed                                |
| PinnerSage   | single decay-average user embedding    | homefeed engagement volume +4%; shopping +20%                      |
| PinnerFormer | aggregated PinnerSage in the ranker    | homefeed repins +7.5%; daily active users +0.4%                    |
| ItemSage     | sum-pooling product embeddings         | clicks +11.34% on Home; GMV per user +6.85% on Closeup             |
| TransAct     | ranker without real-time sequences     | homefeed repin volume +11.0%; hide volume −10.0%                   |
| OmniSage     | PinSage in five applications           | sitewide repins about +2.5%                                        |
| PinFM        | homefeed ranker without PinFM          | sitewide saves +1.20%; fresh saves +5.70%                          |

PinnerSage and PinnerFormer are each compared with the user representation they replaced, so the chain decay
