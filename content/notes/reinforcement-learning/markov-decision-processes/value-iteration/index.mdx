<Definition>
**Value iteration** computes the optimal value function of a
<NoteLink to="markov-decision-process">Markov decision process</NoteLink> with known transitions $p$ and rewards $r$.
It starts from any value vector $V_0$, for example $V_0 = 0$, and applies the Bellman optimality operator $T$ to every
state:

$$
V_{k+1}(s) = \max_a\brack{r(s, a) + \gamma\sum_{s'}p(s' \mid s, a)\,V_k(s')}.
$$

It stops when successive iterates are close and returns the greedy policy
$\pi(s) \in \argmax_a[r(s, a) + \gamma\sum_{s'}p(s' \mid s, a)V_k(s')]$ <Cite id="bellman1957" />.
</Definition>

## Intuition

$V_k(s)$ is the best expected return an agent can collect in $k$ steps from $s$ and then receive $V_0$ of wherever it
ends up. With $V_0 = 0$ it is exactly the optimal $k$-step return. Each sweep looks one step further ahead. Information
about rewards spreads outwards from where they are earned, one transition per sweep; in a gridworld the values fill in
from the goal like a wave. Discounting makes the far future matter less, so the $k$-step answer approaches the
infinite-horizon one.

## Convergence

The <NoteLink to="bellman-equations">Bellman equations</NoteLink> note proves that $T$ is a $\gamma$-contraction in the
sup norm and that its unique fixed point is $v_*$. Since $V_{k+1} = TV_k$ and $v_* = Tv_*$,

$$
\norm{V_{k+1} - v_*}_\infty = \norm{TV_k - Tv_*}_\infty \le \gamma\norm{V_k - v_*}_\infty,
$$

and by induction $\norm{V_k - v_*}_\infty \le \gamma^k\norm{V_0 - v_*}_\infty$. The error shrinks by at least a factor
$\gamma$ per sweep from any start. Reaching accuracy $\varepsilon$ from an initial error $e_0$ takes
$\log(e_0/\varepsilon)/\log(1/\gamma) \approx (1 - \gamma)^{-1}\log(e_0/\varepsilon)$ sweeps, so the cost grows with the
effective horizon $1/(1 - \gamma)$.

**A computable stopping rule.** $v_*$ is unknown, but the change between sweeps is observed. By the triangle
inequality and contraction,

$$
\norm{V_{k+1} - v_*}_\infty \le \gamma\norm{V_k - v_*}_\infty \le \gamma\norm{V_k - V_{k+1}}_\infty + \gamma\norm{V_{k+1} - v_*}_\infty,
$$

and rearranging gives

$$
\norm{V_{k+1} - v_*}_\infty \le \frac{\gamma}{1 - \gamma}\norm{V_{k+1} - V_k}_\infty.
$$

Stopping when the change falls below $\varepsilon(1 - \gamma)/\gamma$ guarantees values within $\varepsilon$ of optimal.

**The policy converges first.** The greedy policy $\pi$ of a value vector $V$ loses at most
$2\gamma\norm{V - v_*}_\infty/(1 - \gamma)$ in every state. In a finite MDP there are finitely many deterministic
policies, and the non-optimal ones fall short of $v_*$ by at least some gap. Once the bound is below that gap, the
greedy policy is exactly optimal, typically many sweeps before the values settle.

<Derivation title="The greedy policy's loss bound">
Let $\pi$ be greedy with respect to $V$, so $T_\pi V = TV$, and let $\varepsilon = \norm{V - v_*}_\infty$. Write

$$
v_* - v_\pi = (Tv_* - TV) + (T_\pi V - T_\pi v_\pi),
$$

using $v_* = Tv_*$, $TV = T_\pi V$ and $v_\pi = T_\pi v_\pi$. The first bracket has sup norm at most $\gamma\varepsilon$
by contraction. The second is $\gamma P_\pi(V - v_\pi) = \gamma P_\pi(V - v_*) + \gamma P_\pi(v_* - v_\pi)$, and a
stochastic matrix does not increase the sup norm. So

$$
\norm{v_* - v_\pi}_\infty \le 2\gamma\varepsilon + \gamma\norm{v_* - v_\pi}_\infty
\quad\Longrightarrow\quad
\norm{v_* - v_\pi}_\infty \le \frac{2\gamma\varepsilon}{1 - \gamma}.
$$
</Derivation>

## Worked example

Take the machine MDP of the <NoteLink to="markov-decision-process">MDP</NoteLink> note with $\gamma = 0.9$. A good
machine run pays 2 and stays good with probability 0.8, else wears; a worn machine run pays 1 and stays worn; a repair
costs 1 and makes the machine good. Start from $V_0 = (0, 0)$ for (good, worn).

| sweep $k$ | $V_k(\text{good})$ | $V_k(\text{worn})$ | change $\norm{V_k - V_{k-1}}_\infty$ | greedy action when worn |
| --- | --- | --- | --- | --- |
| 1 | 2.00 | 1.00 | 2.00 | run |
| 2 | 3.62 | 1.90 | 1.62 | run |
| 3 | 4.95 | 2.71 | 1.33 | repair |
| 10 | 10.44 | 7.90 | 0.55 | repair |
| 70 | 15.415 | 12.872 | 0.001 | repair |

Sweep 2, for the good state: running gives $2 + 0.9\,(0.8 \cdot 2 + 0.2 \cdot 1) = 3.62$ and repairing gives
$-1 + 0.9 \cdot 2 = 0.8$, so $V_2(\text{good}) = 3.62$. For the worn state, running gives $1 + 0.9 \cdot 1 = 1.9$ and
repairing gives $-1 + 0.9 \cdot 2 = 0.8$, so $V_2(\text{worn}) = 1.9$.

The optimal values are $v_* = (15.42, 12.88)$. The greedy policy of $V_3$ is already optimal, although $V_3$ is still
10.5 below $v_*$. The error falls by a factor close to 0.9 per sweep and is below 0.01 after 70 sweeps, which the
bound $\norm{V_0 - v_*}_\infty\,\gamma^{70} = 15.42 \cdot 0.9^{70} = 0.010$ guarantees.

and compares it with Q-learning and SARSA on the same problem.

## Variants

- **Asynchronous (Gauss–Seidel) updates.** Update states one at a time in place, so later states in a sweep use values
  already updated in the same sweep. Convergence still holds as long as every state is updated infinitely often
  <Cite id="bertsekas2017" />.
- **Prioritised sweeping.** Update first the states whose values would change most, keeping a queue ordered by the
  Bellman residual. Useful when rewards are sparse <Cite id="sutton2018" />.
- **Q-value iteration.** Iterate the optimality equation for $q_*$. It needs a table of size
  $\abs{\Scal}\abs{\Acal}$, and its sampled version is <NoteLink to="q-learning">Q-learning</NoteLink>.
- **Finite horizon.** With $T$ steps to go and $V_0$ the terminal reward, $T$ sweeps give the exact optimal
  time-dependent values and policies.

## Cost

One sweep costs $O(\abs{\Scal}^2\abs{\Acal})$ for dense transitions, or $O(\abs{\Scal}\abs{\Acal}b)$ when each
state-action pair leads to at most $b$ successors. Memory is one value per state.

## Pitfalls

- **Stopping on a small change alone.** A change of $10^{-3}$ with $\gamma = 0.999$ allows an error of 1 by the bound
  above.
- **Large or continuous state spaces.** The table has one entry per state, and a gridded continuous space grows
  exponentially with its dimension. Fitted value iteration replaces the table by a regression model and loses the
  contraction guarantee.
- **Needing the model.** Value iteration requires $p$ and $r$. Without them, sample-based methods such as
  <NoteLink to="temporal-difference-learning">temporal-difference learning</NoteLink> estimate the same fixed point.
