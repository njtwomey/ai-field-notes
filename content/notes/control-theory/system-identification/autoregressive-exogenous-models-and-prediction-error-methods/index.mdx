<Definition>
A **prediction-error method** (PEM) estimates the parameters $\thetavec$ of a model

$$
y_t = G(q, \thetavec)\,u_t + H(q, \thetavec)\,e_t
$$

by minimising $V_N(\thetavec) = \frac1N\sum_{t=1}^N \varepsilon_t(\thetavec)^2$, where
$\varepsilon_t(\thetavec) = y_t - \hat{y}_{t \mid t-1}(\thetavec)$ is the error of the model's one-step-ahead
prediction. Here $u_t$ is the measured input, $y_t$ the measured output, $e_t$ white noise, and $q$ the shift operator,
$q^{-1}y_t = y_{t-1}$, so $G$ and $H$ are rational transfer functions in $q^{-1}$ with $H$ monic
<Cite id="ljung1999" />. The **ARX model** is the special case

$$
y_t + a_1y_{t-1} + \dots + a_{n_a}y_{t-n_a} = b_1u_{t-1} + \dots + b_{n_b}u_{t-n_b} + e_t,
$$

written $A(q)y_t = B(q)u_t + e_t$: autoregressive with an exogenous input.
</Definition>

## The one-step predictor

A model is used to predict, so the natural measure of fit is how well it predicts. For the general model, write
$y_t = Gu_t + e_t + (H - 1)e_t$. Because $H$ is monic, $(H - 1)e_t$ involves only past noise, which can be recovered
from past data as $e = H^{-1}(y - Gu)$. The best prediction of $y_t$ from the past replaces the unpredictable $e_t$ by
zero:

$$
\hat{y}_{t \mid t-1} = Gu_t + (H - 1)H^{-1}(y_t - Gu_t) = H^{-1}G\,u_t + \paren{1 - H^{-1}}y_t.
$$

The prediction error is then $\varepsilon_t = H^{-1}(y_t - Gu_t)$: the output residual, filtered by the inverse of the
noise model. When the model is correct, $\varepsilon_t = e_t$, white noise. If the noise is Gaussian, minimising the sum
of <NoteLink to="principal-component-reconstruction-error">squared prediction errors</NoteLink> is maximum likelihood,
and the estimate inherits its efficiency <Cite id="ljung1999" />.

## ARX is least squares

For ARX, $G = B/A$ and $H = 1/A$. The prediction error is $\varepsilon_t = A(q)y_t - B(q)u_t$, and the predictor is

$$
\hat{y}_{t \mid t-1} = \varphivec_t^\top\thetavec, \qquad
\varphivec_t = (-y_{t-1}, \dots, -y_{t-n_a}, u_{t-1}, \dots, u_{t-n_b}), \qquad
\thetavec = (a_1, \dots, a_{n_a}, b_1, \dots, b_{n_b}).
$$

The predictor is linear in $\thetavec$, so minimising $\sum_t(y_t - \varphivec_t^\top\thetavec)^2$ is
<NoteLink to="linear-regression">linear regression</NoteLink> of $y_t$ on the regressor $\varphivec_t$. Stack the
regressors as rows of $\Phimat$ and the outputs in $\yvec$. Setting the <NoteLink to="gradient">gradient</NoteLink> $-2\Phimat^\top(\yvec -
\Phimat\thetavec)$ to zero gives the normal equations and the estimate

$$
\hat{\thetavec} = \paren{\Phimat^\top\Phimat}^{-1}\Phimat^\top\yvec.
$$

With no input this is the least-squares fit of an <NoteLink to="autoregressive-model">autoregressive model</NoteLink>.
The estimate can also be updated one sample at a time by <NoteLink to="recursive-least-squares-filter">recursive least
squares</NoteLink>, which is how adaptive controllers identify their plant online.

### When least squares is consistent

Substitute the true model $y_t = \varphivec_t^\top\thetavec_0 + e_t$ into the estimate:

$$
\hat{\thetavec} - \thetavec_0 = \paren{\frac1N\sum_t\varphivec_t\varphivec_t^\top}^{-1}\frac1N\sum_t\varphivec_t e_t.
$$

As $N \to \infty$ the second average tends to $\expect[\varphivec_t e_t]$. If $e_t$ is white and the input is
independent of it, $\varphivec_t$ contains only past outputs and inputs, which are uncorrelated with $e_t$, and the
estimate is consistent. If the disturbance is coloured, the past outputs in $\varphivec_t$ are correlated with the
current disturbance and the estimate is biased, however much data there is.

The first average must also be invertible. The input must be **persistently exciting**: rich enough in frequency
content that no nonzero parameter combination is invisible in the data. An input with power at $k$ distinct
frequencies can identify at most $2k$ parameters of $B$; a white-noise input or a pseudo-random binary sequence
excites every frequency.

## Other model structures

| Model        | $G$   | $H$   | Predictor linear in $\thetavec$? |
| ------------ | ----- | ----- | -------------------------------- |
| ARX          | $B/A$ | $1/A$ | yes                              |
| ARMAX        | $B/A$ | $C/A$ | no                               |
| Output error | $B/F$ | $1$   | no                               |
| Box–Jenkins  | $B/F$ | $C/D$ | no                               |

ARX forces the noise to pass through the same poles as the input, $1/A$. When that is false, a structure with a separate
noise model is needed, and the prediction error is a nonlinear function of $\thetavec$. PEM then minimises $V_N$ by
Gauss–Newton or Levenberg–Marquardt iterations, often started from an ARX or subspace estimate. Under standard
conditions the estimate converges to the parameters that minimise $\expect[\varepsilon_t^2]$, and to the true ones when
the model set contains the true system <Cite id="ljung1999" />. The <Gloss name="arma" /> and
<NoteLink to="autoregressive-integrated-moving-average-model">ARIMA models</NoteLink> of time-series analysis are the
same structures without an input.

## Worked example

Simulate $y_t = 0.8y_{t-1} + 0.5u_{t-1} + e_t$ for $N = 1000$ samples, with $u_t$ a random sequence of $\pm1$ and
$e_t \sim \Gauss(0, 0.1^2)$. In ARX form, $a_1 = -0.8$ and $b_1 = 0.5$. Least squares on
$\varphivec_t = (y_{t-1}, u_{t-1})$ (the sign of the first regressor flipped so the coefficient is $0.8$) returned
$(0.794, 0.501)$ with <NoteLink to="standard-error">standard errors</NoteLink> $(0.004, 0.003)$ for one realisation. The
model structure is right, so the estimate is consistent.

Now let the disturbance enter at the output instead: $x_t = 0.8x_{t-1} + 0.5u_{t-1}$ and $y_t = x_t + v_t$ with
$v_t \sim \Gauss(0, 0.5^2)$, an output-error system. In terms of $y$, the equation becomes
$y_t = 0.8y_{t-1} + 0.5u_{t-1} + w_t$ with $w_t = v_t - 0.8v_{t-1}$, a coloured disturbance correlated with the
regressor $y_{t-1}$: $\cov(y_{t-1}, w_t) = -0.8\var(v) = -0.2$. The input is uncorrelated with $y_{t-1}$, so the bias
of the first coefficient is this covariance divided by $\var(y) = 0.25/(1 - 0.64) + 0.25 = 0.944$, which is $-0.21$.
Least squares converges to $0.59$ instead of $0.8$, and the average over 200 simulated data sets was $0.587$. An
output-error model fitted by PEM, whose prediction error is $y_t - (B/F)u_t$, removes the bias.

## Assumptions

- The system is linear, time-invariant and in the model set, or close to it. The noise is stationary.
- The input is persistently exciting and, for open-loop data, independent of the noise. With data collected in closed
  loop, the input depends on past noise, and methods that are consistent in open loop (output-error, instrumental
  variables) can be biased. PEM with a correct noise model remains consistent.

## Pitfalls

- **Fitting simulation with a one-step criterion.** A model with small one-step prediction errors can simulate poorly,
  because one-step prediction leans on the measured past outputs. Validate by simulating the model from the input alone
  and comparing with held-out data.
- **Order selection.** Too few parameters bias the model; too many fit noise and produce near pole-zero cancellations.
  <NoteLink to="information-criteria">Information criteria</NoteLink>, cross-validation on fresh data and residual
  whiteness tests guide the choice.
- **Local minima.** Nonlinear PEM criteria have local minima. A good initial estimate from ARX or
  <NoteLink to="subspace-identification">subspace identification</NoteLink> matters.
