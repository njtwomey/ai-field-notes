<Definition>
A positional encoding is a vector $\pvec_t \in \reals^{d}$ added to the embedding of the token at position
$t$. Without it, self-attention produces the same output for any permutation of the input tokens.
</Definition>

## Sinusoidal encoding

The original transformer uses fixed sinusoids <Cite id="vaswani2017" />:

$$
p_{t,2i} = \sin\!\left(\frac{t}{10000^{2i/d}}\right), \qquad p_{t,2i+1} = \cos\!\left(\frac{t}{10000^{2i/d}}\right)
$$

Each pair of dimensions is a rotation at its own frequency. The wavelengths form a geometric progression from
$2\pi$ to $10000 \cdot 2\pi$.

## Relative position

For a fixed offset $k$, $\pvec_{t+k}$ is a linear function of $\pvec_t$. The linear map is a rotation that
depends on $k$ but not on $t$. This lets attention express relative offsets <Cite id="kazemnejad2019" />.
