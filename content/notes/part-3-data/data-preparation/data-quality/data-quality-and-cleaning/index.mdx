<Definition>
**Data quality** is the degree to which a dataset is fit for its use. It is judged along dimensions such as accuracy,
completeness, consistency, validity, uniqueness and timeliness <Cite id="wang1996" />. **Data cleaning** detects
records that fall short on one of these dimensions and corrects, removes or flags them. A cleaning step is part of the
model: it is fitted on training data and applied unchanged at prediction time.
</Definition>

## What it is for

Defects in data turn into defects in a model. A unit mix-up in one column biases a coefficient. Missing values that
depend on the outcome bias every fill. Duplicates that cross the
<NoteLink to="train-validation-and-test-splits">train-test split</NoteLink> inflate the test score. A column whose type
was guessed wrongly at load time silently becomes zeros. Cleaning finds these problems before training and stops them
from recurring in production. Its cost is set by the downstream model: trees tolerate outliers that ruin a linear fit,
and a fix is worth doing only if it lowers validation error.

## Main ideas

**Quality has several dimensions.** <NoteLink to="data-quality-dimensions" /> separates accuracy (is the value true),
completeness (is it there), consistency (do related values agree), validity (is it admissible), uniqueness (is each
entity recorded once) and timeliness (is it current). A value can be valid and still wrong: an age of 45 for a person
aged 23 passes every range check.

**Missing values need a model of why they are missing.** Whether a fill is unbiased depends on the missingness
mechanism: missing completely at random, at random given observed values, or not at random <Cite id="little2019" />.
<NoteLink to="missing-data-and-imputation" /> opens the section, which runs from deletion and
<NoteLink to="single-imputation">single imputation</NoteLink> to multiple imputation, learned imputers and sensitivity
analysis.

**Errors and outliers are different things.** A gross error is a wrong value, such as an impossible date. An outlier
is a value far from the rest, which may be wrong or genuine. <NoteLink to="outliers-and-gross-errors" /> sets out the
choices to correct, remove, cap or keep. <NoteLink to="outlier-detection-methods" /> flags candidates by robust scores,
distances, density and isolation. <NoteLink to="constraint-based-repair" /> states rules the data must satisfy and
changes the fewest values that restore them.

**Equal things must look equal.** <NoteLink to="parsing-and-type-inference" /> reads raw files into typed columns and
catches sentinel values and lossy coercions. <NoteLink to="value-standardisation" /> reduces each quantity to one unit,
each date to one format and each category to one spelling. <NoteLink to="deduplication-and-record-linkage" /> decides
which records describe the same entity, and <NoteLink to="near-duplicate-detection" /> finds records that differ only
slightly, using MinHash, SimHash, perceptual hashes and embedding neighbours.

**Cleaning and evaluation interact.** <NoteLink to="cleaning-and-evaluation" /> sets the rules: fit cleaning
parameters on training rows only, run every automated fix again at serving time, correct test labels but never
hand-clean test features, and judge each fix by validation error. <NoteLink to="data-validation" /> turns the
expectations into checks run on every new batch, and a data contract fixes them between producer and consumer
<Cite id="polyzotis2018" />.

## How the notes fit together

Start with <NoteLink to="data-quality-dimensions" />, then <NoteLink to="cleaning-and-evaluation" />. Five sections
follow, one per kind of defect:

- **Missing data and imputation** handles absent values, in eight notes;
- **Errors and outliers** handles wrong and extreme values;
- **Parsing and standardisation** reads raw files into typed columns and normalises their values;
- **Deduplication and record linkage** handles repeated entities;
- **Validation and data contracts** keeps the cleaned data clean as new batches arrive.

Each section can be read on its own after the two opening notes.
