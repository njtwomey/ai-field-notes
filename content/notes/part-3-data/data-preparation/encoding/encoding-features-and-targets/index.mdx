<Definition>
An **encoding** maps a value of some type to a fixed-length numeric vector a model can take as input, or maps a target
to the form a loss can compare against. The type decides the encoding: a category, a number with a non-linear effect, a
time of day, a position, a set of tags, a missing value or a structured output. A good encoding gives the model the
structure of the type directly, so that it need not learn it from data.
</Definition>

## What it is for

Most models compute with real vectors. A model cannot multiply the string `"red"` by a weight. It also has no way to
know that hour 23 sits next to hour 0, that the order in which tags were listed is irrelevant, or that a blank field may
itself predict the target. Each encoding states one such fact. The choice changes accuracy, model size, and whether the
target leaks into the inputs. Target-based encodings are fitted to data, so they belong in the training fold.

## Main ideas

**Categories become indicators, statistics or vectors.** <NoteLink to="categorical-encoding" /> compares the families.
<NoteLink to="one-hot-and-contrast-coding" /> gives each level an indicator and chooses a reference with contrasts.
<NoteLink to="mean-target-encoding" /> replaces a level by its shrunk mean target <Cite id="micci2001" />, fitted out of
fold. <NoteLink to="count-and-frequency-encoding" />, <NoteLink to="feature-hashing" /> <Cite id="weinberger2009" /> and
<NoteLink to="category-embeddings" /> trade interpretability for scale.
<NoteLink to="high-cardinality-and-unseen-levels" /> and <NoteLink to="identifier-features" /> handle the hard cases.

**Numbers can be expanded into bases.** <NoteLink to="numeric-encoding" /> replaces $x$ by bin indicators,
piecewise-linear hat functions, B-splines or sinusoids. A model linear in the expansion is non-linear in $x$, with the
shape set by the basis <Cite id="hastie2009" />.

**Cycles and positions need geometry.** <NoteLink to="cyclical-encoding" /> places a periodic value $v$ with period $P$
on a circle as $(\sin 2\pi v/P, \cos 2\pi v/P)$, so the end of the cycle meets its start.
<NoteLink to="positional-and-coordinate-encoding" /> encodes a location in a sequence, image, graph or on the globe,
with Fourier features to resolve fine differences.

**Variable-length fields become fixed-size vectors.** <NoteLink to="multi-valued-field-encoding" /> encodes tags,
genres and baskets by multi-hot vectors, weighted counts, pooled embeddings and set encoders that ignore order.
<NoteLink to="sequence-length-and-chunking" /> truncates or chunks inputs too long for a model and pads the rest.

**Absence is information.** <NoteLink to="encoding-missingness" /> adds an indicator column, a sentinel or a learned
missing token, or lets a tree route missing values itself, so the model can use the fact that a value is missing.

**Targets are encoded too.** <NoteLink to="encoding-targets" /> covers class indices, smoothed one-hot vectors, ordinal,
hierarchical and multi-label codes and transformed numeric targets. <NoteLink to="structured-target-encodings" />
covers boxes against anchors, masks, keypoint heatmaps and span tags.
