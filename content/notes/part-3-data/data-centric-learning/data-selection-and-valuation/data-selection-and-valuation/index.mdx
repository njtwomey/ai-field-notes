<Definition>
**Data selection** decides which examples a model trains on, how often and in what order. **Data valuation** assigns
each example, or each source, a number that measures its contribution to a model's performance. Valuation informs
selection: low-value examples are candidates for removal or inspection, and high-value sources for more collection.
</Definition>

## What it is for

Not every example helps. Some are mislabelled, some duplicate others, some teach a shortcut, and many add little once
similar examples are present. At small scale, valuing examples finds label errors and justifies paying for data. At
large scale, the question is which subset, mixture and order of data gives the best model for a fixed compute budget.
Data pruning can beat the usual power-law scaling of error with dataset size when examples are chosen well
<Cite id="sorscher2022pruning" />. For <Gloss name="language-model">language models</Gloss>, compute-optimal training
balances tokens against parameters <Cite id="hoffmann2022" />.

## Main ideas

**Value is the effect of removal.** <NoteLink to="data-valuation" /> starts from leave-one-out values, the change in
validation performance when one example is removed. Data Shapley averages that change over all subsets, which shares
credit fairly among redundant examples <Cite id="ghorbani2019shapley" />. Influence functions approximate the effect of
removal from the Hessian of the loss, without retraining.

**Smaller sets can train as well.** <NoteLink to="coresets-and-data-pruning" /> covers coresets, weighted subsets whose
gradients match the full set's, pruning by difficulty scores, and dataset distillation, which synthesises a few
prototypes that train a model almost as well as the whole set.

**Order and proportion matter.** <NoteLink to="curricula-and-data-mixtures" /> covers curriculum and self-paced
learning, which order examples from easy to hard, and the choice of domain proportions, repetition and epochs in
large-scale pretraining. Data scaling laws predict how loss falls with more data and more parameters.
