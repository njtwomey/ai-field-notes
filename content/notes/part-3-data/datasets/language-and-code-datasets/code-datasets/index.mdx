<Definition>
**Code datasets** are curated software corpora and benchmark collections encompassing open-source repository source
trees, version control diff histories, docstring-to-function alignments, and unit-tested competitive programming
problems. They serve as the pretraining foundation for code LLMs (e.g. Codex, StarCoder, Code Llama) and benchmark
functional code synthesis, semantic search, type inference, and automated vulnerability repair
<Cite id="chen2021b, li2023starcoder" />.
</Definition>

Unlike natural language which tolerates informal phrasing and minor syntactic slips, source code enforces rigid formal
grammar and deterministic compiler/interpreter semantics. A single missing delimiter or off-by-one indexing error causes
runtime execution failure, necessitating unit-test execution benchmarks <Cite id="chen2021b" />.

---

## What These Datasets Measure

Code corpora and benchmarks evaluate models along distinct dimensions:
1. **Functional Program Synthesis**: Generating executable code from function signatures and docstrings, evaluated
   strictly via functional execution correctness rather than surface text matching (BLEU):
   $$
   \text{Pass@}k = \mathbb{E}\left[ 1 - \frac{\binom{n - c}{k}}{\binom{n}{k}} \right]
   $$
   where $n$ candidates are sampled per problem, and $c$ passes all unit test assertions <Cite id="chen2021b" />.
2. **Multi-File Context & Dependency Resolution**: Reasoning over repository-level dependency graphs, import
   hierarchies, and class structures.
3. **Semantic Code Search**: Retrieving relevant code snippets given natural language queries, measured by Mean
   Reciprocal Rank (MRR) (CodeSearchNet) <Cite id="husain2019codesearchnet" />.
4. **Algorithmic Problem Solving**: Generating complete solutions for competitive coding problems with strict memory and
   runtime limits (APPS, Codeforces).

## Detailed Benchmark Profiles

### The Stack: Permissively Licensed Pretraining at Scale (2023–2024)

Created by the BigCode Project (Li et al. <Cite id="li2023starcoder" />):
- **Scale and Languages**: Over 6 TB of source code spanning 384 programming languages harvested from GitHub.
- **Strict License Hygiene**: Filtered down strictly to permissively licensed code (e.g. MIT, Apache 2.0, BSD),
  excluding copyleft (GPL) and non-commercial licenses.
- **Opt-Out Mechanism**: Established the "Am I in The Stack?" tool allowing developers to verify and request the removal
  of their repositories from pretraining distributions.
- **Foundation of StarCoder**: Provided the clean data engine for StarCoder, StarCoder2, and Granite Code foundation
  models.

### HumanEval: Standardizing Functional Execution (2021)

Introduced by Mark Chen et al. <Cite id="chen2021b" /> alongside OpenAI Codex:
- **Handwritten Benchmark**: 164 original programming challenges crafted specifically to avoid historical contamination
  from pre-existing competitive coding sites.
- **Composition**: Each problem includes a function signature, docstring specification, reference implementation, and an
  average of 7.7 unit tests.
- **Impact of Pass@k**: Discarded BLEU/ROUGE for code evaluation, demonstrating that n-gram overlap correlates poorly
  with functional correctness. An unbiased estimator for $\text{Pass@}k$ was established that remains the standard
  evaluation metric across the AI industry.

### MBPP: Mostly Basic Python Problems (2021)

Constructed by Google Research (Austin et al. <Cite id="austin2021mbpp" />):
- **Problem Range**: 974 crowd-sourced Python programming problems designed for introductory programmers (e.g. string
  manipulation, elementary mathematical series, dictionary operations).
- **Format**: Each task contains a task description, reference code solution, and 3 unit test assertions. Used widely
  alongside HumanEval to provide larger sample statistical confidence.

### CodeSearchNet: Semantic Code Retrieval (2019)

Curated by GitHub and Microsoft Research (Husain et al. <Cite id="husain2019codesearchnet" />):
- **Scale**: Over 2 million (docstring, code body) pairs across 6 major languages: Python, Java, JavaScript, PHP, Ruby,
  and Go.
- **Role**: Catalyzed dual-encoder code search models (e.g. CodeBERT, GraphCodeBERT) by defining standard cross-language
  information retrieval leaderboards.

## Choosing a Code Dataset

- **Foundation Pretraining Across Multiple Languages**:
  - The Stack v2 (Permissively licensed, 300+ languages, deduped)
- **Standard Functional Synthesis Benchmarking**:
  - *Clean handwritten Python standard*: HumanEval
  - *Large elementary task sample (N=974)*: MBPP
- **Semantic Search & Code Information Retrieval**:
  - CodeSearchNet (2M paired docstring-code snippets across 6 languages)
- **Complex Competitive Programming & Algorithms**:
  - APPS / Codeforces (Advanced data structures, strict time limits)

## Known Problems and Benchmark Pitfalls

1. **Test Set Contamination & LeetCode Memorization**: HumanEval and MBPP problems have been republished across
   thousands of public repositories and blog posts, making zero-shot evaluation on newer LLMs suspect without strict
   contamination checks.
2. **Weak Unit Test Coverage**: Many HumanEval and MBPP problems contain only 3 or 4 basic unit test assertions. A naive
   or buggy model prediction can pass minimal assertions while failing basic boundary edge cases (addressed by
   HumanEval+ and MBPP+).
3. **Copyleft and PII Leakage**: Scraped code corpora frequently contain hard-coded private API keys, credentials,
   copyrighted copyleft source code, and uncredited author attributions <Cite id="li2023starcoder" />.
