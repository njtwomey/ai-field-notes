<Definition>
**Document understanding datasets** are multimodal benchmark collections containing scanned paper documents,
born-digital PDFs, forms, receipts, and scientific preprints pairing pixel page images
$I \in \mathbb{R}^{H \times W \times C}$ with optical character recognition (OCR) bounding box geometries
$b_i = (x_0, y_0, x_1, y_1)$ and semantic entity annotations. They benchmark document layout analysis, structured form
key-value linking, document classification, and visually rich document question answering (DocVQA)
<Cite id="jaume2019funsd, mathew2021docvqa, zhong2019publaynet" />.
</Definition>

Standard language models operate strictly on 1D textual streams, assuming left-to-right grammatical flow. Visually rich
documents (VRDs)—such as invoices, medical intake forms, and tax declarations—encode meaning through 2D spatial
arrangement, tabular grids, font hierarchies, and visual dividers <Cite id="xu2020layoutlm" />.

---

## What These Datasets Measure

Document AI benchmarks evaluate models along distinct structural dimensions:
1. **Document Layout Analysis (DLA)**: Segmenting page images into functional layout blocks (*text paragraphs*,
   *tables*, *figures*, *headers*, *lists*), evaluated via mAP at bounding box $\text{IoU} \ge 0.5$ (PubLayNet)
   <Cite id="zhong2019publaynet" />.
2. **Form Key-Value Extraction & Entity Linking**: Identifying semantic entity types (*header*, *question*, *answer*)
   and predicting directed relational links $(e_{\text{question}} \to e_{\text{answer}})$ across irregular form fields
   (FUNSD) <Cite id="jaume2019funsd" />.
3. **Document Visual Question Answering**: Answering natural questions about invoice line items, chart legends, or stamp
   endorsements where reasoning requires synthesizing OCR text with spatial layout coordinates (DocVQA)
   <Cite id="mathew2021docvqa" />.
4. **Document Image Classification**: Categorizing multi-page business documents into 16 functional classes (e.g.
   *letter*, *form*, *email*, *memo*, *invoice*, *advertisement*) (RVL-CDIP).

## Detailed Benchmark Profiles

### FUNSD: Form Understanding in Noisy Scanned Documents (2019)

Introduced by Jaume et al. <Cite id="jaume2019funsd" />:
- **Scanned Noise**: 199 real-world historical scanned forms sampled from the Truth Tobacco Industry Documents archive,
  exhibiting scanning artifacts, low contrast, paper skew, coffee stains, and handwritten checkmarks.
- **Hierarchical Annotations**: 31,485 word-level bounding boxes grouped into 9,707 semantic entities categorized into
  four labels: *header*, *question*, *answer*, and *other*.
- **Entity Linking Challenge**: Evaluates whether models can pair isolated text blocks (e.g. connecting a checkbox
  question *"Smoking History?"* to a distant marked answer *"Yes"*).

### DocVQA: Question Answering on Document Images (2021)

Developed by Mathew, Karatzas, and Jawahar <Cite id="mathew2021docvqa" />:
- **Dataset Composition**: 50,000 questions grounded on 12,767 document images harvested from industry archives.
- **Evaluation Metric**: Evaluated via **Average Normalized Levenshtein Similarity (ANLS)**:
  $$
  \text{ANLS} = 1 - \frac{\min(d_L(p, g), \tau)}{\tau}
  $$
  where $d_L(p, g)$ is the edit distance between predicted string $p$ and ground truth $g$ normalized by string length,
  and $\tau = 0.5$ truncates severe errors to zero.

### PubLayNet: Large-Scale Scientific Layout Parsing (2019)

Constructed by IBM Research (Zhong et al. <Cite id="zhong2019publaynet" />):
- **Automated High-Quality Labels**: Parsed 360,000 scientific PDF document pages from PubMed Central Open Access subset
  by aligning PDF layout stream coordinates with structured XML publication sources, avoiding error-prone human
  labeling.
- **Five Standard Classes**: Identifies *text*, *title*, *list*, *table*, and *figure* bounding regions, serving as the
  universal pretraining and evaluation benchmark for document object detection architectures (Faster R-CNN, Mask R-CNN,
  LayoutLMv3).

## Choosing a Document Understanding Dataset

- **Complex Form Key-Value Extraction & Entity Linking**:
  - FUNSD (Scanned forms with question-answer links)
- **Document Visual Question Answering (DocVQA)**:
  - DocVQA (50k questions, ANLS metric)
- **Large-Scale Document Layout Segmentation (DLA)**:
  - PubLayNet (360k pages, 5 structural layout categories)
- **Retail Receipt Parsing & Information Extraction**:
  - CORD (Restaurant receipts, itemized line items)
- **Document Page Classification**:
  - RVL-CDIP (400k pages, 16 business document classes)

## Known Problems and Benchmark Pitfalls

1. **OCR Cascading Error Propagation**: In 2-stage pipelines (OCR engine followed by language model), recognition
   mistakes in early character extraction (e.g. OCR misreading `"0"` as `"O"`) propagate irreversibly to downstream
   extraction models <Cite id="jaume2019funsd" />.
2. **Reading Order Ambiguity**: In multi-column layouts, tables, and sidebars, serializing 2D layout boxes into a 1D
   token stream introduces reading order confusion, causing cross-column text interleaving.
3. **High Resolution and Computational Memory Limits**: High-resolution document scans
   ($300\text{ DPI} \approx 2550 \times 3300$ pixels) exceed standard vision transformer input resolutions
   ($224 \times 224$), requiring aggressive patch pooling or specialized sliding-window architectures
   <Cite id="xu2020layoutlm" />.
