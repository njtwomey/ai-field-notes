<Definition>
**Versioning and change** concerns datasets that are not fixed. Rows arrive, are corrected and are deleted. Columns are
added, renamed or redefined. The same feature may be computed in batch over complete data
and in a stream as events arrive. Versioning records which state of the data produced which model. Change management
keeps a change in the data from silently changing what a model computes.
</Definition>

## What it is for

A model is a function of its code and its data. Code is versioned as a matter of course. Data often are not, so a model
trained last month cannot be reproduced, and a drop in accuracy cannot be traced to the rows or the schema change that
caused it. Changes upstream are a common source of production failures <Cite id="polyzotis2018" />: a column whose
units change from seconds to milliseconds, a category that is renamed, a backfill that rewrites history, a streaming
job that drops late events. None of these raises an error. The notes here give the mechanisms that make such changes
visible and reversible.

## Main ideas

**Snapshot by content and query as of a time.** <NoteLink to="dataset-versioning-and-lineage" /> identifies each
dataset state by a content hash, so that a model can be traced to the exact data it was trained on. As-of queries
reconstruct the data as they stood at a past time. Lineage links each model to its sources through every
transformation.

**Schemas evolve, and features break.** <NoteLink to="schema-evolution" /> covers added and renamed columns, changed
units and enumerations, and backfills that rewrite past values. Each needs a contract and a test, or downstream
features change meaning without notice <Cite id="breck2017" />.

**Batch and stream disagree.** <NoteLink to="batch-and-stream-processing" /> contrasts batch jobs over complete data
with stream jobs that compute as events arrive, late and out of order. Watermarks decide when a window is complete
<Cite id="akidau2015" />. A feature computed both ways can take different values for the same entity.
