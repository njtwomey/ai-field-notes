<Definition>
An **arcade or video-game environment** is a visually rich, partially observable Markov decision process (POMDP)
$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{O}, \mathcal{P}, \mathcal{R}, \Omega, \gamma \rangle$ where
internal computational states $\mathbf{s}_t \in \mathcal{S}$ (RAM memory, collision registers, velocities) are obscured,
and the agent perceives high-dimensional pixel observations $\mathbf{o}_t \in \{0, \dots, 255\}^{H \times W \times C}$
generated by an observation emission function $\Omega(\mathbf{o}_t \mid \mathbf{s}_t)$ <Cite id="bellemare2013" />
<Cite id="mnih2015" />.
</Definition>

## What these environments test

Video games provide rigorous, diverse benchmarks that isolate several long-standing challenges in artificial
intelligence:

1. **Representation learning from pixels**: Deep Q-Networks (DQN <Cite id="mnih2015" />) demonstrated that convolutional
   neural networks can learn spatial feature hierarchies directly from raw RGB screen buffers without hand-engineered
   object detectors.
2. **Overcoming partial observability via frame stacking**: A single static frame cannot reveal whether a ball is
   traveling left or right, turning the MDP into a POMDP. Stacking $k=4$ consecutive frames into a tensor $[4, 84, 84]$
   provides the network with first and second temporal derivatives (velocity and acceleration).
3. **Extreme exploration bottlenecks**: Games like *Montezuma's Revenge* and *Pitfall!* feature highly sparse rewards:
   an agent must navigate multiple platforms, climb ladders, dodge moving hazards, and collect keys across hundreds of
   timesteps before receiving a single scalar reward signal.
4. **Hierarchical real-time decision making**: In complex strategy environments like StarCraft II
   <Cite id="vinyals2019" />, agents operate under fog-of-war uncertainty, managing thousands of micro-actions per
   minute while pursuing multi-hour macroeconomic expansion strategies.

## Catalogue

### Arcade Learning Environment (ALE / Atari 2600)
Introduced by Bellemare et al. <Cite id="bellemare2013" />, ALE interfaces with the Stella Atari 2600 emulator across a
benchmark suite of 57 games:
- **Action space**: Discrete joystick inputs $\mathcal{A} \subseteq \{0, \dots, 17\}$, covering directional movements,
  button presses, and neutral actions.
- **Canonical DQN preprocessing pipeline** <Cite id="mnih2015" />:
  1. **Color downsampling**: Convert raw $210 \times 160$ RGB frames into grayscale $Y = 0.299R + 0.587G + 0.114B$.
  2. **Spatial resizing**: Bilinear interpolation down to $84 \times 84$ resolution.
  3. **Phosphor flicker filtering**: Max-pooling across consecutive frames ($t$ and $t-1$) to eliminate visual
     flickering caused by the Atari 2600 sprite interlacing hardware.
  4. **Frame skipping**: Repeat the selected action across $4$ hardware frames (`frame_skip=4`), updating the agent at
     an effective decision frequency of $15\text{ Hz}$ instead of $60\text{ Hz}$.
- **Sticky actions**: To prevent open-loop memorization of deterministic emulator seed sequences, Machado et al.
  introduced sticky actions: at each step, the emulator executes the agent's previous action with probability
  $\zeta = 0.25$, forcing policies to generalize dynamically.

### VizDoom
A first-person 3D shooter benchmark built on the classic Doom engine:
- Delivers egocentric 3D vision buffers (RGB frames, depth buffers, segmentation masks).
- Tests 3D spatial navigation, depth perception, projectile trajectory prediction, and fast adversarial combat.

### Minecraft environments (Malmo and MineRL)
A 3D open-world voxel sandbox featuring complex physics, procedural terrain generation, crafting hierarchies, and
day-night survival cycles:
- **The `ObtainDiamond` challenge**: Requires harvesting wood, crafting crafting-tables, mining stone, building
  pickaxes, locating iron ore, smelting iron in a furnace, and delving into underground caves to locate diamond veins.
- Serves as the primary proving ground for foundation agents (e.g., Voyager) combining visual perception, large language
  models, and tool synthesis.

### StarCraft II (PySC2 and SMAC)
A premier real-time strategy (RTS) benchmark:
- **Combinatorial action spaces**: Action selection requires choosing an action type, target unit, screen coordinate,
  and minimap coordinate, spanning over $10^{26}$ discrete action combinations per step.
- **AlphaStar**: DeepMind's AlphaStar <Cite id="vinyals2019" /> achieved Grandmaster ranking against human professionals
  using transformer-based spatial architectures, imitation learning from human replays, and multi-agent competitive
  league training.

## Interfaces and versions

In Gymnasium, Atari games are accessed via the `ALE/` namespace with integrated wrappers:

```python
import gymnasium as gym
from gymnasium.wrappers import AtariPreprocessing, FrameStackObservation

# Create standardized Atari environment
env = gym.make("ALE/Breakout-v5", frameskip=1)
env = AtariPreprocessing(
    env,
    screen_size=84,
    grayscale_obs=True,
    frame_skip=4,
    noop_max=30,
)
env = FrameStackObservation(env, stack_size=4)

obs, info = env.reset(seed=42)
assert obs.shape == (4, 84, 84)  # 4 stacked grayscale frames
```

## Known problems and limitations

1. **Deterministic memorization**: Early reinforcement learning algorithms solved games like *Q*bert* and *Montezuma's
   Revenge* by memorizing exact sequences of keypresses rather than learning visual concepts. Benchmarking requires
   sticky actions or random initial no-op delays (`noop_max=30`).
2. **Extreme compute requirements**: Unlike 2D grid worlds that execute millions of steps per second per core, rendering
   full 3D video game engines (Doom, Minecraft, StarCraft) is computationally demanding, requiring distributed
   actor-learner architectures (e.g. IMPALA, SEED RL).
3. **Score clipping distortion**: DQN clipped all environment rewards to $\{-1, 0, +1\}$ to ensure uniform gradient
   scaling across games with wildly differing scoring scales (e.g., *Pong* scores $\pm 1$ while *Centipede* awards tens
   of thousands of points). Reward clipping destroys the agent's ability to distinguish between high-value and low-value
   objectives.
