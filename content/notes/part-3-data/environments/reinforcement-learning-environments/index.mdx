<Definition>
A **reinforcement learning environment** is a simulator that returns an observation and a reward for each action an
agent takes, with a fixed interface, reward and termination rule. An **offline dataset** replaces the simulator with a
fixed log of trajectories. Both play the role for reinforcement learning that datasets play for
<NoteLink to="supervised-learning">supervised learning</NoteLink>: the shared ground on which methods are trained and
compared.
</Definition>

## What it is for

A reinforcement learning agent learns from its own interaction, so its data depend on the
environment and on the agent itself. Comparing methods needs environments that everyone runs the same way. Gym fixed a
common interface for this <Cite id="brockman2016" />, and the Arcade Learning Environment turned dozens of Atari 2600
games into a benchmark <Cite id="bellemare2013" />. Each family of environments tests one difficulty: exact solution,
perception from pixels, continuous control, generalisation to new levels, coordination among agents, acting through
language, or learning without interaction <Cite id="fu2020d4rl" />. Environment versions matter. A change to sticky
actions or a time limit changes the reported scores.

## Main ideas

**Small problems can be solved exactly.** <NoteLink to="classic-control-environments" /> covers cart-pole, mountain car,
acrobot and pendulum. <NoteLink to="grid-worlds-and-discrete-environments" /> covers grid worlds, frozen lake, cliff
walking, taxi and MiniGrid, small enough for dynamic programming and for inspecting every policy.

**Pixels and physics scale the problem up.** <NoteLink to="arcade-and-video-game-environments" /> covers the Atari
suite, VizDoom, Minecraft and StarCraft II, played from pixels. <NoteLink to="continuous-control-benchmarks" /> covers
MuJoCo locomotion, the DeepMind Control Suite and manipulation suites with continuous actions.

**Generalisation needs fresh levels.** <NoteLink to="procedurally-generated-environments" /> covers Procgen, the NetHack
Learning Environment and Crafter, which generate a new level for each episode and test on levels never seen in
training.

**Other agents and language change the setting.** <NoteLink to="multi-agent-environments" /> covers PettingZoo, the
multi-agent particle environments, SMAC and Hanabi. <NoteLink to="agent-environments" /> covers WebArena, ALFWorld,
OSWorld and Habitat, where <Gloss name="language-model">language-model</Gloss> and embodied agents act through browsers,
operating systems, tools or simulated homes.

**Logs replace simulators offline.** <NoteLink to="offline-reinforcement-learning-datasets" /> covers D4RL, Minari, RL
Unplugged and the Atari <Gloss name="dqn" /> replay data, whose quality ranges from random to expert behaviour.

## How the notes fit together

Start with <NoteLink to="classic-control-environments" /> and <NoteLink to="grid-worlds-and-discrete-environments" />,
which the reinforcement learning notes use as running examples. The arcade, continuous-control and procedural notes
follow in increasing difficulty. Multi-agent, agent and offline notes each stand alone.
