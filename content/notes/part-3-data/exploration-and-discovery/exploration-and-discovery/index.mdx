<Definition>
**Exploration and discovery** covers the methods that describe a dataset and find structure in it without fitting the
final model. Exploration checks and summarises the data at hand. Discovery looks for
structure that is not yet known: dependencies between variables, frequent patterns, causal relations and other datasets
worth joining.
</Definition>

## What it is for

Exploration finds the defects, quirks and relations that decide how data are cleaned, transformed, split and modelled.
It is the cheapest way to catch a leaking feature, a broken pipeline or a subgroup with different behaviour. Tukey
called it the detective work that comes before confirmation <Cite id="tukey1977" />. Discovery turns the same tools to
questions of their own. A retailer mines baskets for items bought together. A scientist estimates which variables cause
which. An analyst searches a data lake for a table that adds a missing feature <Cite id="chapman2020" />.

## Main ideas

**Fixed checks catch common failures.** <NoteLink to="routine-data-checks" /> lists inspections to run on every
dataset: reading raw rows, profiling the target, plotting by time and file order, comparing slices, probing with simple
baselines and keeping test rows unseen.

**Profiles summarise every column.** <NoteLink to="data-profiling" /> computes types, uniqueness, missingness, ranges,
skew and cross-column dependencies in one pass. <NoteLink to="corpus-statistics" /> does the same for text: length
distributions, vocabulary growth, Zipf's law, repetition and language mix.

**Pictures and maps show structure.** <NoteLink to="visual-exploration" /> covers plots of one and two variables,
projections such as <Gloss name="pca" />, <Gloss name="t-sne" /> and <Gloss name="umap" />, clustering for review, and
embedding neighbours for unstructured data. Very different datasets can share every summary statistic, so plots are not
optional <Cite id="anscombe1973" />.

**Dependence goes beyond correlation.** <NoteLink to="dependence-measures" /> compares Pearson and Spearman correlation,
which detect linear and monotone relations, with mutual information, distance correlation and HSIC, which detect any
dependence.

**Patterns and causes can be mined.** <NoteLink to="pattern-mining" /> finds frequent itemsets, association rules and
sequential patterns with Apriori and FP-growth. <NoteLink to="causal-discovery" /> estimates a causal graph from
observational data by independence tests, score-based search, continuous optimisation or asymmetries in the noise, under
stated assumptions.

**Data can be discovered too.** <NoteLink to="dataset-search" /> finds tables that can be joined to add features or
unioned to add rows, across public repositories and enterprise data lakes.
