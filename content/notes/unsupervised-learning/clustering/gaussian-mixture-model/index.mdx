<Definition>
A Gaussian mixture model (GMM) with $k$ components describes $n$ points $\xvec_1, \dots, \xvec_n \in \reals^d$. Each
point $\xvec_i$ has an unobserved label $z_i \in \{1, \dots, k\}$ that names the component that produced it. For each
point independently:

$$
z_i \sim \Cat(\pivec), \qquad \xvec_i \mid z_i = j \;\sim\; \Gauss(\muvec_j, \Sigma_j)
$$

Summing over the unobserved label gives the density of a point:

$$
p(\xvec_i \mid \theta) = \sum_{j=1}^{k} \pi_j \, \Gauss(\xvec_i \mid \muvec_j, \Sigma_j)
$$

The parameters are $\theta = \{\pi_j, \muvec_j, \Sigma_j\}_{j=1}^{k}$. The weights $\pi_j$ are non-negative and sum
to 1. This note uses diagonal covariances.
</Definition>

## Notation

| Symbol | Meaning |
| --- | --- |
| $n$, $i$ | Number of points; index over points. |
| $d$, $m$ | Dimension of each point; index over dimensions. |
| $k$, $j$, $l$ | Number of components; indices over components. |
| $\xvec_i$, $x_{im}$ | The $i$-th point; its $m$-th coordinate. $\Xmat$ holds all points. |
| $z_i$ | The component that produced $\xvec_i$. It is not observed. $\Zmat$ holds all labels. |
| $\pi_j$ | Mixing weight of component $j$: the prior probability $P(z_i = j)$. $\pivec$ holds all weights. |
| $\muvec_j$, $\mu_{jm}$ | Mean of component $j$; its $m$-th coordinate. |
| $\Sigma_j$, $\sigma_{jm}^2$ | Covariance of component $j$; its $m$-th diagonal entry, the variance along dimension $m$. |
| $\sigmavec_j^2$ | The vector of variances $(\sigma_{j1}^2, \dots, \sigma_{jd}^2)$. |
| $\theta$ | All parameters: $\{\pi_j, \muvec_j, \Sigma_j\}_{j=1}^{k}$. |
| $r_{ij}$ | Responsibility: the posterior probability $P(z_i = j \mid \xvec_i, \theta)$. |
| $N_j$ | Effective number of points in component $j$: $N_j = \sum_{i} r_{ij}$. |
| $\deltavec_{ij}$ | Deviation of point $i$ from the mean of component $j$: $\deltavec_{ij} = \xvec_i - \muvec_j$. |
| $\ell$ | Log-likelihood of all points: $\ell = \sum_{i} \log p(\xvec_i \mid \theta)$. |

## Generative model

The definition describes how each point is produced. First, a component is drawn with probabilities
$\pi_1, \dots, \pi_k$. Then the point is drawn from that component's Gaussian. The component is not recorded.

Clustering with a GMM reverses this process. It infers, for each point, which component probably produced it.

## Diagonal covariance

A diagonal covariance $\Sigma_j = \diag(\sigma_{j1}^2, \dots, \sigma_{jd}^2)$ gives each component its
own variance along each axis. Its contours are ellipses aligned with the axes. A component can be long and thin, but
it cannot be tilted.

A diagonal component in $d$ dimensions has $2d$ parameters: $d$ means and $d$ variances. A full covariance adds
$d(d-1)/2$ correlations. The diagonal model is cheaper to fit and needs less data. It cannot represent correlation
within a component. Several diagonal components can approximate one tilted cluster.

The estimates differ only in how each deviation $\deltavec_{ij}$ is multiplied by itself before
averaging. Each point is weighted by its responsibility $r_{ij}$, defined below, and $N_j = \sum_i r_{ij}$:

$$
\begin{aligned}
\text{full:} &\quad \Sigma_j = \frac{1}{N_j}\sum_{i} r_{ij}\, \deltavec_{ij} \deltavec_{ij}^\top
  && \text{outer product, a } d \times d \text{ matrix} \\
\text{diagonal:} &\quad \sigmavec_j^2 = \frac{1}{N_j}\sum_{i} r_{ij}\, \deltavec_{ij} \odot \deltavec_{ij}
  && \text{elementwise square, a vector of } d \text{ variances} \\
\text{spherical:} &\quad \sigma_j^2 = \frac{1}{N_j\, d}\sum_{i} r_{ij}\, \deltavec_{ij}^\top \deltavec_{ij}
  && \text{inner product, one number}
\end{aligned}
$$

The <NoteLink to="matrix-multiplication">outer product</NoteLink> records how every pair of features varies together.
The elementwise square is the diagonal of the outer product: it keeps each feature's own variance and drops the pairs.
The <NoteLink to="dot-product">inner product</NoteLink> sums those variances into one number, so a spherical component
has the same spread in every direction. Per point, the full estimate costs $O(d^2)$ and the diagonal estimate costs
$O(d)$.

## Responsibilities

The responsibility of component $j$ for point $i$ is the posterior probability that $j$ produced it:

$$
r_{ij} = P(z_i = j \mid \xvec_i) = \frac{\pi_j \, \Gauss(\xvec_i \mid \muvec_j, \Sigma_j)}
{\sum_{l=1}^{k} \pi_l \, \Gauss(\xvec_i \mid \muvec_l, \Sigma_l)}
$$

Each row of responsibilities sums to 1. A point between two components has split responsibility. This is a soft
assignment. <NoteLink to="k-means">k-means</NoteLink> makes a hard assignment instead.

## Expectation-maximisation

The parameters are fitted by maximising the log-likelihood
$\ell = \sum_{i=1}^{n} \log \sum_{j=1}^{k} \pi_j \, \Gauss(\xvec_i \mid \muvec_j, \Sigma_j)$. The sum inside the
logarithm has no closed-form maximiser. <Gloss name="em-algorithm">Expectation-maximisation (EM)</Gloss> alternates two
steps instead <Cite id="dempster1977" />:

1. **E-step.** Compute the responsibilities $r_{ij}$ under the current parameters.
2. **M-step.** Re-estimate each component from all points, each weighted by its responsibility. With
   $N_j = \sum_i r_{ij}$:

$$
\pi_j = \frac{N_j}{n}, \qquad
\muvec_j = \frac{1}{N_j}\sum_{i} r_{ij}\,\xvec_i, \qquad
\sigma_{jm}^2 = \frac{1}{N_j}\sum_{i} r_{ij}\,(x_{im} - \mu_{jm})^2
$$

Each iteration never decreases the log-likelihood <Cite id="dempster1977" />. EM stops when the increase falls below
a tolerance.

<EmStepper />

<Derivation title="Why the M-step formulas are weighted averages">
If the components $z_i$ were known, the log-likelihood would split into one Gaussian fit per component. The
maximum-likelihood mean and variance of a Gaussian are the sample mean and sample variance of its points.

EM does not know $z_i$. It replaces each indicator $[z_i = j]$ with its expected value under the current parameters,
which is $r_{ij}$. The complete-data estimates then become the responsibility-weighted mean and variance above. The
weight $\pi_j$ becomes the expected fraction of points in component $j$ <Cite id="bishop2006" />.
</Derivation>

## EM as maximising a lower bound

EM can be read as coordinate ascent on a lower bound of the log-likelihood <Cite id="neal1998" />. Let $\Zmat$
be the unobserved components and $q(\Zmat)$ any distribution over them. Then

$$
\log p(\Xmat \mid \theta) = \Lcal(q, \theta) + \KL\big(q \,\|\, p(\Zmat \mid \Xmat, \theta)\big),
\qquad
\Lcal(q, \theta) = \expect_{q}\big[\log p(\Xmat, \Zmat \mid \theta)\big] + \entropy(q)
$$

The KL divergence is never negative, so $\Lcal$ is a lower bound on the log-likelihood. It is called the
<Gloss name="elbo">evidence lower bound (ELBO)</Gloss>. $\entropy(q)$ is the <NoteLink to="entropy">entropy</NoteLink>
of $q$.

- **E-step.** Set $q$ to the posterior $p(\Zmat \mid \Xmat, \theta)$, which is the responsibilities. The
  KL term becomes zero and the bound touches the log-likelihood.
- **M-step.** Hold $q$ fixed and maximise $\Lcal$ over $\theta$. The bound rises, so the log-likelihood rises
  at least as much.

This is why the likelihood never decreases <Cite id="bishop2006" />. The same bound reappears in
<Gloss name="vi">variational inference</Gloss>, where the posterior is too complex to compute exactly and $q$ is
restricted to a simpler family.

## Relation to k-means

k-means is a limiting case of EM for a GMM. Give every component the same covariance $\varepsilon I$ and let
$\varepsilon \to 0$. Each responsibility then tends to 0 or 1, the E-step becomes the nearest-centre assignment, and
the M-step becomes the cluster mean <Cite id="bishop2006" />.

The limit shows that k-means assumes round clusters of equal size. The data above has two long, thin
clusters close together. k-means cuts them across their length. A diagonal GMM fits their shapes. On this data,
k-means matches 63% of the true labels and the diagonal GMM matches 100%.

## Initialisation

EM finds a local maximum of the likelihood. The result depends on the starting parameters. A common start takes the
means from k-means or k-means++ seeding, equal weights, and the overall data variance for every component. Running
several starts and keeping the highest likelihood is standard practice.

## Choosing k

### The likelihood always improves

Adding a component never lowers the maximised likelihood. A model with $k + 1$ components can reproduce any model
with $k$ by giving the extra component zero weight. The likelihood alone therefore always prefers more components.

The plot of $-2\ell$ against $k$ falls steeply until $k$ reaches the true
<NoteLink to="choosing-the-number-of-clusters">number of clusters</NoteLink>, then flattens. This is the same bend that
the elbow method looks for in the <NoteLink to="k-means">k-means</NoteLink> inertia curve. The elbow method reads the
bend by eye. <NoteLink to="information-criteria">Information criteria</NoteLink> locate it by adding an explicit cost
per parameter.

### AIC and BIC

Both criteria add a penalty to $-2\ell$, the deviance. Lower is better. With $p$ free parameters and $n$ points:

$$
\AIC = -2\ell + 2p, \qquad \BIC = -2\ell + p \log n
$$

For a diagonal GMM in $d$ dimensions, $p = 2kd + (k - 1)$: $kd$ means, $kd$ variances and $k - 1$ free weights.

- **AIC** estimates how well the fitted model will predict new data <Cite id="akaike1974" />. Its penalty does not
  grow with $n$.
- **BIC** approximates $-2 \log p(\Xmat \mid k)$, the log evidence for the model with $k$ components
  <Cite id="schwarz1978" />. Its penalty grows with $\log n$. It exceeds AIC's penalty once $n > e^2 \approx 7.4$.

A new component is accepted when it lowers $-2\ell$ by more than its own penalty. Each diagonal component in two
dimensions adds 5 parameters. AIC therefore requires a drop of 10. BIC requires $5 \log n$, which is 30 for
$n = 400$.

<ModelSelection />

On this data, BIC selects the true $k = 3$ at almost every sample size from 30 to 400. AIC usually selects between
4 and 8 components, because small improvements from fitting noise exceed its fixed penalty. Its choice changes from
one $n$ to the next, because its curve is almost flat beyond $k = 3$. AIC favours
prediction. BIC favours identifying the true number of components when one exists.

### Connection to the ELBO

BIC and the ELBO both target the <NoteLink to="bayes-factors-and-model-comparison">model evidence</NoteLink>
$p(\Xmat \mid k)$. BIC approximates it for large $n$ from the maximised likelihood and a parameter count. Variational
Bayesian GMMs place priors on the parameters and maximise an ELBO on $\log p(\Xmat \mid k)$ directly. That ELBO can
compare values of $k$. It also tends to drive the weights of unneeded components toward zero, which selects $k$ within a
single fit <Cite id="bishop2006" />.

## Pitfalls

- **Collapsing components.** If a component's mean lands on a single point and its variance shrinks toward zero, the
  likelihood grows without bound <Cite id="bishop2006" />. A lower bound on each variance prevents this.
- **Label switching.** Permuting the components gives the same density. Component numbers carry no meaning between
  runs.
- **Scale.** Diagonal variances are per axis, so a GMM is less sensitive to feature scale than k-means. Very different
  scales still slow EM and make the variance floor matter.
