<Definition>
For $\Amat \in \reals^{m \times n}$, the column space $\col(\Amat) \subseteq \reals^m$ is the span of the columns, and
the null space is

$$
\Null(\Amat) = \set{\xvec \in \reals^n : \Amat\xvec = \zeros}.
$$

The rank of $\Amat$ is $\dim \col(\Amat)$, and the nullity is $\dim \Null(\Amat)$. The rank–nullity theorem states

$$
\rank(\Amat) + \dim \Null(\Amat) = n
$$

<Cite id="axler2015" />.
</Definition>

## The four subspaces

A matrix $\Amat \in \reals^{m \times n}$ defines four subspaces <Cite id="strang2016" />:

| Subspace                            | Lives in   | Dimension | Meaning                            |
| ----------------------------------- | ---------- | --------- | ---------------------------------- |
| column space $\col(\Amat)$          | $\reals^m$ | $r$       | every output $\Amat\xvec$          |
| null space $\Null(\Amat)$           | $\reals^n$ | $n - r$   | inputs sent to $\zeros$            |
| row space $\col(\Amat^\top)$        | $\reals^n$ | $r$       | the span of the rows               |
| left null space $\Null(\Amat^\top)$ | $\reals^m$ | $m - r$   | outputs orthogonal to every column |

Here $r = \rank(\Amat)$. The row space and the null space are orthogonal complements in $\reals^n$: every row has a zero
dot product with every null-space vector, because $\Amat\xvec = \zeros$ says exactly that. Likewise the column space and
the left null space are orthogonal complements in $\reals^m$.

The number of independent rows always equals the number of independent columns, so $\rank(\Amat) = \rank(\Amat^\top)$.

<Derivation title="Why row rank equals column rank">
Let $r$ be the column rank and let the columns of $\Cmat \in \reals^{m \times r}$ be a basis of $\col(\Amat)$. Each
column of $\Amat$ is a combination of these basis columns, so $\Amat = \Cmat\Rmat$ for some
$\Rmat \in \reals^{r \times n}$ holding the coefficients. Read row by row, $\Amat = \Cmat\Rmat$ says that every row of
$\Amat$ is a combination of the $r$ rows of $\Rmat$. The row space therefore has dimension at most $r$: row rank $\le$
column rank. Applying the same argument to $\Amat^\top$ gives column rank $\le$ row rank, so the two are equal.
</Derivation>

It follows that $\rank(\Amat) \le \min(m, n)$. A matrix with $\rank(\Amat) = \min(m, n)$ has full rank; otherwise it is
rank deficient.

## Proof of the rank–nullity theorem

The theorem follows by building a basis of $\reals^n$ that separates what $\Amat$ loses from what it keeps.

Let $k = \dim \Null(\Amat)$ and pick a basis $\uvec_1, \dots, \uvec_k$ of the null space. Extend it to a basis
$\uvec_1, \dots, \uvec_k, \wvec_1, \dots, \wvec_{n-k}$ of $\reals^n$. The claim is that
$\Amat\wvec_1, \dots, \Amat\wvec_{n-k}$ is a basis of the column space, which gives $\rank(\Amat) = n - k$.

- **They span $\col(\Amat)$.** Every output is $\Amat\xvec$ for some $\xvec$. Write
  $\xvec = \sum_i d_i\uvec_i + \sum_j c_j\wvec_j$ in the basis. Since $\Amat\uvec_i = \zeros$,
  $\Amat\xvec = \sum_j c_j\Amat\wvec_j$.
- **They are independent.** Suppose $\sum_j c_j \Amat\wvec_j = \zeros$. By linearity
  $\Amat\paren{\sum_j c_j\wvec_j} = \zeros$, so $\sum_j c_j\wvec_j$ lies in the null space and equals some
  $\sum_i d_i\uvec_i$. Then $\sum_j c_j\wvec_j - \sum_i d_i\uvec_i = \zeros$ is a combination of the basis of
  $\reals^n$ equal to $\zeros$, so every $c_j$ and every $d_i$ is 0.

Rank–nullity is a conservation law. Each of the $n$ input dimensions either reaches the output, counted by the rank, or
is lost to the null space. A map from $\reals^n$ to $\reals^m$ with $n > m$ has rank at most $m$, so it loses at least
$n - m$ dimensions.

## What rank and nullity say about $\Amat\xvec = \bvec$

- A solution exists if and only if $\bvec \in \col(\Amat)$, because $\Amat\xvec$ is a combination of the columns.
- If $\xvec_0$ is one solution, the set of all solutions is $\xvec_0 + \Null(\Amat)$. Any other solution $\xvec$ has
  $\Amat(\xvec - \xvec_0) = \bvec - \bvec = \zeros$, so $\xvec - \xvec_0$ lies in the null space. Conversely, adding a
  null-space vector to $\xvec_0$ leaves the output unchanged.
- The solution is unique if and only if $\Null(\Amat) = \set{\zeros}$, that is, by rank–nullity, rank $n$.

## Worked example

$$
\Amat = \begin{bmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 0 & 1 \end{bmatrix}.
$$

Row 2 is twice row 1, and rows 1 and 3 are not proportional, so $\rank(\Amat) = 2$. Rank–nullity gives
$\dim \Null(\Amat) = 3 - 2 = 1$. Solving $x_1 + 2x_2 + 3x_3 = 0$ and $x_1 + x_3 = 0$ gives $x_1 = -x_3$ and
$x_2 = -x_3$, so

$$
\Null(\Amat) = \Span\set{(1, 1, -1)}.
$$

Check: $\Amat(1, 1, -1) = (1 + 2 - 3,\; 2 + 4 - 6,\; 1 + 0 - 1) = \zeros$.

Every output $\Amat\xvec$ lies in the plane spanned by $(1, 2, 1)$ and $(2, 4, 0)$, and the vector $\bvec = (0, 1, 0)$
is not reachable, because every output has second entry equal to twice its first.

## Computing the rank

Row reduction counts the pivots, which equals the rank in exact arithmetic. In floating point, the rank is computed from
the singular values: it is the number of singular values above a tolerance such as
$\max(m, n)\, \epsilon\, \sigma_1$, where $\epsilon$ is the machine precision. The right singular vectors belonging to
the remaining (near-)zero singular values form an orthonormal basis of the null space. See
<NoteLink to="singular-value-decomposition">singular value decomposition</NoteLink>. The
<NoteLink to="pseudoinverse">pseudoinverse</NoteLink> uses the same split to pick the minimum-norm solution out of
$\xvec_0 + \Null(\Amat)$. For a square matrix, the null space is the eigenspace of eigenvalue 0 (see
<NoteLink to="eigendecomposition">eigendecomposition</NoteLink>).

## In machine learning

- **Identifiability.** For a linear model $\Xmat\wvec$, any null-space vector $\nvec$ of the design matrix gives
  $\Xmat(\wvec + \nvec) = \Xmat\wvec$. The data cannot distinguish $\wvec$ from $\wvec + \nvec$, so the weights are not
  identifiable. Regularisation picks one of them.
- **Low-rank structure.** A matrix of rank $r$ factors as $\Amat = \Bmat\Cmat$ with $\Bmat \in \reals^{m \times r}$ and
  $\Cmat \in \reals^{r \times n}$. Storing the factors takes $r(m + n)$ numbers instead of $mn$. Low-rank adapters for
  fine-tuning and <NoteLink to="matrix-factorisation-for-recommendation">matrix factorisation for
  recommendation</NoteLink> both use this.
- **Bottlenecks.** $\rank(\Amat\Bmat) \le \min(\rank\Amat, \rank\Bmat)$. The columns of $\Amat\Bmat$ are combinations
  of the columns of $\Amat$, so $\col(\Amat\Bmat) \subseteq \col(\Amat)$. The rows of $\Amat\Bmat$ are combinations of
  the rows of $\Bmat$, so its row rank is at most $\rank\Bmat$. A linear layer narrower than its neighbours therefore
  caps the rank of the whole <NoteLink to="matrix-vector-product">linear map</NoteLink> through it.

## Pitfalls

- **Numerical rank depends on a tolerance.** A matrix with tiny but nonzero singular values has full rank in exact
  arithmetic yet behaves as rank deficient. Report the tolerance with the rank.
- **Null space versus left null space.** $\Null(\Amat)$ lives in the input space $\reals^n$, and $\Null(\Amat^\top)$
  in the output space $\reals^m$. They coincide in dimension only when $m = n$.
