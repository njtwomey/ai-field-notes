<Definition>
Forward-mode automatic differentiation evaluates a program on pairs $(v, \dot v)$, where $v$ is an intermediate value
and $\dot v$ is its derivative along a chosen input direction. Each primitive operation updates the pair with its own
derivative rule. At the end, the tangent of the output is the <NoteLink to="gradient">directional derivative</NoteLink>
of the program <Cite id="griewank2008" />.
</Definition>

## Dual numbers

A dual number is $a + b\varepsilon$, where $\varepsilon$ is a symbol with $\varepsilon^2 = 0$ and $\varepsilon \ne 0$.
Arithmetic follows the usual rules, with every $\varepsilon^2$ term dropped, so the $\varepsilon$ coefficient of a
product obeys the product rule. The <NoteLink to="taylor-series">Taylor series</NoteLink> of any smooth $f$ truncates
exactly on dual numbers,

$$
f(a + b\varepsilon) = f(a) + f'(a)\,b\,\varepsilon,
$$

and composition gives the chain rule: $f\bigl(g(a + \varepsilon)\bigr) = f(g(a)) + f'(g(a))\,g'(a)\,\varepsilon$.
Evaluating any program built from primitives on $a + 1\varepsilon$ therefore returns its value and its exact derivative,
with no symbolic expression and no finite-difference error <Cite id="wengert1964" />. The derivations, hyper-dual
numbers for second derivatives and the related complex-step method are in <NoteLink to="dual-numbers">dual
numbers</NoteLink>.

## Several inputs: Jacobian-vector products

For $\fvec : \reals^n \to \reals^m$, seed each input with a tangent: $\xvec + \vvec\,\varepsilon$. By the
<NoteLink to="multivariable-chain-rule">multivariable chain rule</NoteLink> the output is

$$
\fvec(\xvec + \vvec\varepsilon) = \fvec(\xvec) + \Jmat(\xvec)\,\vvec\;\varepsilon.
$$

One forward pass gives the <Gloss name="jvp">Jacobian-vector product</Gloss> $\Jmat\vvec$, the derivative of every
output along the direction $\vvec$, for about the cost of evaluating $\fvec$ a small constant number of times. Seeding
with $\vvec = \evec_j$ gives column $j$ of the <NoteLink to="jacobian">Jacobian</NoteLink>. The full Jacobian takes $n$
passes, one per input.

Reverse mode, <NoteLink to="backpropagation">backpropagation</NoteLink>, computes <Gloss name="vjp">vector-Jacobian
products</Gloss> $\uvec^\top\Jmat$ instead: one pass per output, so the full Jacobian takes $m$ passes
<Cite id="baydin2018" />.

| | Forward mode | Reverse mode |
| --- | --- | --- |
| One pass computes | $\Jmat\vvec$ (a column combination) | $\uvec^\top\Jmat$ (a row combination) |
| Passes for the full Jacobian | $n$ (inputs) | $m$ (outputs) |
| Memory | a tangent per live value | every intermediate value, for the backward pass |
| Suits | few inputs, many outputs | many inputs, one output (a loss) |

## Worked example

Take the function from the backpropagation note, $f(x, y) = (xy + \sin x)^2$, at $(x, y) = (1.5, -0.5)$, split into
$a = xy$, $b = \sin x$, $c = a + b$, $f = c^2$. Each line applies one primitive rule: $\dot a = \dot x\,y + x\,\dot y$,
$\dot b = \cos x\,\dot x$, $\dot c = \dot a + \dot b$, $\dot f = 2c\,\dot c$.

**Pass 1: seed $(\dot x, \dot y) = (1, 0)$.**

| Node | Value | Tangent |
| --- | --- | --- |
| $x$ | 1.5 | 1 |
| $y$ | −0.5 | 0 |
| $a = xy$ | −0.75 | $1 \times (-0.5) + 1.5 \times 0 = -0.5$ |
| $b = \sin x$ | 0.99749 | $\cos 1.5 \times 1 = 0.07074$ |
| $c = a + b$ | 0.24749 | $-0.42926$ |
| $f = c^2$ | 0.06125 | $2 \times 0.24749 \times (-0.42926) = -0.21248$ |

**Pass 2: seed $(\dot x, \dot y) = (0, 1)$.** Now $\dot a = x = 1.5$, $\dot b = 0$, $\dot c = 1.5$ and
$\dot f = 2 \times 0.24749 \times 1.5 = 0.74248$.

So $\nabla f(1.5, -0.5) = (-0.21248, 0.74248)$, matching the closed forms $2(xy + \sin x)(y + \cos x)$ and $2(xy +
\sin x)\,x$. Forward mode needed two passes, one per input; reverse mode gets both entries from one backward pass. A
single pass seeded with $(1, 1)$ would give the directional derivative $-0.21248 + 0.74248 = 0.53$ directly.

## In machine learning

- **Directional derivatives and Jacobian-vector products.** Forward mode is the natural tool when a whole Jacobian is
  not needed, such as sensitivities of many outputs to one hyperparameter.
- **Hessian-vector products.** Forward mode applied to a reverse-mode gradient ("forward-over-reverse") gives
  $\Hmat\vvec$ in one extra pass, the basis of Hessian-free optimisation and curvature estimates.
- **Memory.** Forward mode stores nothing for later, so it avoids the activation memory that limits backpropagation.
  JAX exposes both modes as `jvp` and `vjp`.

## Pitfalls

- **Many inputs.** A network with a million parameters would need a million forward passes for its gradient. Use
  reverse mode for scalar losses.
- **Non-differentiable primitives.** Forward mode inherits each primitive's rule. At a kink such as $\abs{x}$ at 0 it
  returns whatever rule the library defines, typically a subgradient.
- **Control flow.** Branches are evaluated at the current input, so the result is the derivative of the branch taken.
  It can differ from the derivative of the mathematical function at a branch boundary.
