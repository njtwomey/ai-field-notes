<Definition>
A set $\Ccal \subseteq \reals^n$ is **convex** if $\theta\xvec + (1-\theta)\yvec \in \Ccal$ for all
$\xvec, \yvec \in \Ccal$ and all $\theta \in [0, 1]$. A function $f : \reals^n \to \reals \cup \set{+\infty}$ is
**convex** if its domain $\set{\xvec : f(\xvec) < \infty}$ is convex and

$$
f(\theta\xvec + (1-\theta)\yvec) \le \theta f(\xvec) + (1-\theta) f(\yvec)
$$

for all $\xvec, \yvec$ in the domain and all $\theta \in [0, 1]$. The function is **strictly convex** if the inequality
is strict whenever $\xvec \ne \yvec$ and $0 < \theta < 1$. A function $f$ is **concave** if $-f$ is convex
<Cite id="boyd2004" />.
</Definition>

## Intuition

The point $\theta\xvec + (1-\theta)\yvec$ traces the segment from $\yvec$ to $\xvec$ as $\theta$ runs from 0 to 1. A
convex set has no dents or holes: a straight path between two members never leaves the set. A convex function lies on
or below every chord drawn between two points of its graph. Its graph curves upward or is flat.

The two definitions are linked by the **epigraph**, the set of points on or above the graph:
$\operatorname{epi} f = \set{(\xvec, t) : f(\xvec) \le t}$. A function is convex if and only if its epigraph is a
convex set <Cite id="rockafellar1970" />.



**Local minima are global.** Suppose $\xvec$ is a local minimum of a convex $f$ and some $\yvec$ has
$f(\yvec) < f(\xvec)$. For small $\theta > 0$ the point $\zvec = \theta\yvec + (1-\theta)\xvec$ is inside the
neighbourhood where $\xvec$ is minimal. Convexity gives
$f(\zvec) \le \theta f(\yvec) + (1-\theta) f(\xvec) < f(\xvec)$. This contradicts local minimality. No such $\yvec$
exists, so $\xvec$ is a global minimum. The same argument shows that the set of minimisers of a convex function is
convex.

## Examples

Convex sets:

- A **hyperplane** $\set{\xvec : \avec^\top\xvec = b}$ and a **halfspace** $\set{\xvec : \avec^\top\xvec \le b}$.
- A **norm ball** $\set{\xvec : \norm{\xvec} \le r}$, for any norm. The triangle inequality gives
  $\norm{\theta\xvec + (1-\theta)\yvec} \le \theta\norm{\xvec} + (1-\theta)\norm{\yvec} \le r$.
- A **polyhedron** $\set{\xvec : \Amat\xvec \le \bvec}$, the intersection of finitely many halfspaces.
- The **probability simplex** $\set{\xvec : \xvec \ge \zeros, \ones^\top\xvec = 1}$.
- The cone of symmetric <NoteLink to="positive-definite-matrices">positive semidefinite</NoteLink> matrices.

Convex functions:

- Affine functions $\avec^\top\xvec + b$. They are both convex and concave.
- Every norm $\norm{\xvec}$, by the triangle inequality and homogeneity.
- The quadratic $\tfrac12\xvec^\top\Amat\xvec + \bvec^\top\xvec$ when $\Amat$ is positive semidefinite.
- $e^{ax}$ for any $a \in \reals$, $-\log x$ on $x > 0$, and $x\log x$ on $x > 0$.
- The <NoteLink to="softmax-and-log-sum-exp">log-sum-exp</NoteLink> function $\log\sum_i e^{x_i}$.

## First-order characterisation

A differentiable $f$ with convex domain is convex if and only if

$$
f(\yvec) \ge f(\xvec) + \nabla f(\xvec)^\top(\yvec - \xvec) \quad \text{for all } \xvec, \yvec.
$$

The right-hand side is the tangent plane at $\xvec$, the first-order Taylor approximation. A differentiable function is
convex exactly when every tangent plane is a global under-estimator.

**Convexity implies the tangent bound.** Fix $\xvec, \yvec$ and $\theta \in (0, 1]$. Convexity applied to the point
$\xvec + \theta(\yvec - \xvec)$ gives $f(\xvec + \theta(\yvec - \xvec)) \le f(\xvec) + \theta(f(\yvec) - f(\xvec))$.
Rearranging,

$$
f(\yvec) - f(\xvec) \ge \frac{f(\xvec + \theta(\yvec - \xvec)) - f(\xvec)}{\theta}.
$$

As $\theta \to 0$, the right-hand side tends to the <NoteLink to="gradient">directional derivative</NoteLink>
$\nabla f(\xvec)^\top(\yvec - \xvec)$.

**The tangent bound implies convexity.** Let $\zvec = \theta\xvec + (1-\theta)\yvec$. Apply the tangent bound at
$\zvec$ twice:

$$
f(\xvec) \ge f(\zvec) + \nabla f(\zvec)^\top(\xvec - \zvec), \qquad
f(\yvec) \ge f(\zvec) + \nabla f(\zvec)^\top(\yvec - \zvec).
$$

Multiply the first by $\theta$ and the second by $1-\theta$, then add. The gradient terms combine to
$\nabla f(\zvec)^\top(\theta\xvec + (1-\theta)\yvec - \zvec) = 0$, leaving
$\theta f(\xvec) + (1-\theta) f(\yvec) \ge f(\zvec)$.

**Stationary points are global minima.** Setting $\nabla f(\xvec) = \zeros$ in the tangent bound gives
$f(\yvec) \ge f(\xvec)$ for every $\yvec$. For a convex differentiable function, the equation $\nabla f = \zeros$ is
therefore a complete certificate of optimality, not only a necessary condition.

## Second-order characterisation

A twice-differentiable $f$ with open convex domain is convex if and only if its
<NoteLink to="hessian">Hessian</NoteLink> is positive semidefinite everywhere: $\nabla^2 f(\xvec) \succeq 0$.

The proof reduces to one dimension. A function is convex if and only if its restriction to every line is convex, because
the definition involves only points on one segment at a time. Restrict $f$ to the line through $\xvec$ in direction
$\vvec$: $\phi(t) = f(\xvec + t\vvec)$. Its second <NoteLink to="derivative">derivative</NoteLink> is
$\phi''(t) = \vvec^\top\nabla^2 f(\xvec + t\vvec)\vvec$.

- If $\phi'' \ge 0$, then $\phi'$ is nondecreasing. For $s < t$, the <NoteLink to="mean-value-theorem">mean value
  theorem</NoteLink> gives $\phi(t) - \phi(s) = \phi'(c)(t - s) \ge \phi'(s)(t - s)$ for some $c$ between them. The
  same holds with $s$ and $t$ swapped. This is the first-order characterisation in one dimension, so $\phi$ is
  convex.
- If $\phi$ is convex, then its tangent bounds at $s$ and $t$ give
  $\phi'(s)(t - s) \le \phi(t) - \phi(s) \le \phi'(t)(t - s)$. So $\phi'$ is nondecreasing and $\phi'' \ge 0$.

The condition $\phi'' \ge 0$ for every $\xvec$ and $\vvec$ is exactly $\nabla^2 f \succeq 0$. A Hessian that is
positive definite everywhere implies strict convexity. The converse fails: $x^4$ is strictly convex, but its second
derivative is zero at $x = 0$.

## Strong convexity

A function is **$\mu$-strongly convex**, for $\mu > 0$, if $f(\xvec) - \tfrac{\mu}{2}\norm{\xvec}^2$ is convex.
Equivalently, for differentiable $f$,

$$
f(\yvec) \ge f(\xvec) + \nabla f(\xvec)^\top(\yvec - \xvec) + \tfrac{\mu}{2}\norm{\yvec - \xvec}^2,
$$

and, for twice-differentiable $f$, $\nabla^2 f(\xvec) \succeq \mu\Imat$. A strongly convex function has a quadratic
lower bound around every point. It therefore has exactly one minimiser, and its suboptimality controls the distance
to it: $f(\xvec) - f(\xvec^*) \ge \tfrac{\mu}{2}\norm{\xvec - \xvec^*}^2$ <Cite id="nesterov2004" />. The ratio of
the largest to the smallest curvature, $\kappa = L/\mu$, sets the speed of first-order methods (see
<NoteLink to="convergence-of-gradient-descent">convergence of gradient descent</NoteLink>).

## Operations that preserve convexity

Most convex functions in practice are recognised by building them from known convex pieces with the operations below
<Cite id="boyd2004" />.

| Operation | Result | Why |
| --- | --- | --- |
| Nonnegative weighted sum $\sum_i w_i f_i$, $w_i \ge 0$ | convex | the defining inequality adds |
| Composition with an affine map $f(\Amat\xvec + \bvec)$ | convex | an affine map sends segments to segments |
| Pointwise maximum $\max_i f_i(\xvec)$ | convex | the epigraph is the intersection of the epigraphs |
| Pointwise supremum $\sup_{\yvec} g(\xvec, \yvec)$, $g$ convex in $\xvec$ | convex | same, over infinitely many sets |
| Partial minimisation $\inf_{\yvec} g(\xvec, \yvec)$, $g$ jointly convex | convex | see below |
| $h(g(\xvec))$, $h$ convex and nondecreasing, $g$ convex | convex | chain of the two inequalities |

The pointwise maximum rule explains why the <Gloss name="hinge-loss">hinge loss</Gloss> $\max(0, 1 - z)$ and the largest
eigenvalue of a symmetric matrix, $\lambda_{\max}(\Amat) = \max_{\norm{\vvec} = 1}\vvec^\top\Amat\vvec$, are convex. The
composition rule gives convexity of $e^{g(\xvec)}$ for convex $g$.

<Derivation title="Partial minimisation preserves convexity">
Let $g(\xvec, \yvec)$ be jointly convex and $h(\xvec) = \inf_{\yvec} g(\xvec, \yvec)$, assumed finite. Fix
$\xvec_1, \xvec_2$, $\theta \in [0, 1]$ and $\epsilon > 0$. Choose $\yvec_1, \yvec_2$ with
$g(\xvec_i, \yvec_i) \le h(\xvec_i) + \epsilon$. Then

$$
h(\theta\xvec_1 + (1-\theta)\xvec_2) \le g(\theta\xvec_1 + (1-\theta)\xvec_2,\ \theta\yvec_1 + (1-\theta)\yvec_2)
\le \theta g(\xvec_1, \yvec_1) + (1-\theta) g(\xvec_2, \yvec_2) \le \theta h(\xvec_1) + (1-\theta) h(\xvec_2) + \epsilon.
$$

The first inequality holds because $h$ is an infimum over $\yvec$. The second is joint convexity. Letting
$\epsilon \to 0$ proves convexity of $h$. The distance to a convex set, $\inf_{\yvec \in \Ccal}\norm{\xvec - \yvec}$,
is an example.
</Derivation>

## Worked example: the logistic loss

The logistic regression loss for one example with label $y \in \set{0, 1}$ and score $z = \wvec^\top\xvec$ is
$\ell(z) = \log(1 + e^{z}) - yz$. Its derivatives in $z$ are $\ell'(z) = \sigma(z) - y$ and
$\ell''(z) = \sigma(z)(1 - \sigma(z))$, where $\sigma(z) = 1/(1 + e^{-z})$ is the logistic function. Since
$0 < \sigma(z) < 1$, the second derivative is positive, so $\ell$ is convex in $z$. The map $\wvec \mapsto
\wvec^\top\xvec$ is linear, so each term is convex in $\wvec$ by the affine composition rule, and the sum over examples
is convex by the weighted sum rule.

The Hessian makes this explicit. With design matrix $\Xmat$ (one row per example) and
$\Smat = \diag(\sigma(z_i)(1 - \sigma(z_i)))$, the Hessian of the total loss is $\Xmat^\top\Smat\Xmat$. For any
$\vvec$, $\vvec^\top\Xmat^\top\Smat\Xmat\vvec = \sum_i s_i (\xvec_i^\top\vvec)^2 \ge 0$. The loss of
<NoteLink to="logistic-regression">logistic regression</NoteLink> is therefore convex. Any stationary point is a global
minimum. The Hessian is not bounded below by a positive multiple of the identity, because $s_i \to 0$ as
$\abs{z_i} \to \infty$. The loss is not strongly convex, and on separable data it has no minimiser at all.

## Assumptions

- The characterisations above use differentiability. Nondifferentiable convex functions, such as $\abs{x}$, satisfy
  the first-order bound with a <NoteLink to="subgradients">subgradient</NoteLink> in place of the gradient.
- The domain matters. $1/x$ is convex on $x > 0$ and not on $\reals \setminus \set{0}$, whose domain is not convex.

## Pitfalls

- **Convex is not the same as having a unique minimiser.** A convex function can have a set of minimisers (a flat
  valley) or none (the logistic loss on separable data, or $e^x$).
- **Products and compositions are not automatically convex.** The product of the convex functions $x$ and $x^2$ is
  $x^3$, which is not convex. The composition $h(g(x))$ of the convex functions $h(u) = e^{-u}$ and $g(x) = x^2$ is
  $e^{-x^2}$, which is not convex: $h$ is decreasing, so the composition rule does not apply.
- **Quasiconvex is weaker.** A function whose sublevel sets are convex, such as $\sqrt{\abs{x}}$, is quasiconvex but not
  convex. Local minima of quasiconvex functions can be flat regions that are not global minima.
- **Nonconvex losses.** The losses of neural networks are not convex in the weights. For them, a local minimum need not
  be global and a stationary point need not be a global minimum.
