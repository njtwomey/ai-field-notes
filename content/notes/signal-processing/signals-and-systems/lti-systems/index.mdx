<Definition>
A discrete-time system $T$ maps an input sequence $x[n]$ to an output $y[n] = T\{x\}[n]$. It is **linear** if
$T\{a x_1 + b x_2\} = a\,T\{x_1\} + b\,T\{x_2\}$ for all inputs and scalars, and **time-invariant** if delaying the
input delays the output by the same amount: $x[n - n_0] \mapsto y[n - n_0]$. A linear time-invariant (LTI) system is
completely determined by its impulse response $h[n] = T\{\delta\}[n]$, the output for the unit impulse
$\delta[n]$ <Cite id="oppenheim2010" />.
</Definition>

## The impulse response determines everything

Every sequence is a weighted sum of shifted impulses:

$$
x[n] = \sum_{k=-\infty}^{\infty} x[k]\,\delta[n - k].
$$

Apply $T$. Linearity moves it inside the sum, and time invariance turns the response to $\delta[n - k]$ into
$h[n - k]$:

$$
y[n] = T\Big\{\sum_k x[k]\,\delta[\cdot - k]\Big\}[n] = \sum_k x[k]\,T\{\delta[\cdot - k]\}[n] = \sum_k x[k]\,h[n - k].
$$

This sum is the <NoteLink to="convolution">convolution</NoteLink> $y = x * h$. So measuring the response to a single
impulse predicts the response to every input. Both properties are needed: linearity to split the input into
impulses, time invariance to make every impulse's response a shifted copy of the same $h$.

## Eigenfunctions

Complex exponentials pass through an LTI system unchanged in form. With $x[n] = e^{i\omega n}$,

$$
y[n] = \sum_k h[k]\,e^{i\omega(n - k)} = e^{i\omega n}\sum_k h[k]\,e^{-i\omega k} = H(e^{i\omega})\,e^{i\omega n}.
$$

The output is the input scaled by a complex number $H(e^{i\omega})$, the <NoteLink to="frequency-response">frequency
response</NoteLink>. Its magnitude scales the amplitude and its angle shifts the phase. This is why Fourier analysis
suits LTI systems: they act on each frequency independently.

## Causality

A system is causal if the output at time $n$ depends only on inputs at times up to $n$. For an LTI system, this
holds exactly when $h[n] = 0$ for $n < 0$. In the convolution sum, the term $x[k]h[n - k]$ uses a future input
$k > n$ only when $h$ is nonzero at the negative index $n - k$. Real-time filters must be causal; offline processing
need not be, as in <NoteLink to="zero-phase-filtering">zero-phase filtering</NoteLink>.

## Stability

A system is bounded-input bounded-output (BIBO) stable if every bounded input gives a bounded output. For an LTI system,

$$
\text{BIBO stable} \iff \sum_{n=-\infty}^{\infty} \abs{h[n]} < \infty.
$$

**Sufficiency.** If $\abs{x[n]} \le M$ for all $n$, then
$\abs{y[n]} \le \sum_k \abs{h[k]}\,\abs{x[n - k]} \le M \sum_k \abs{h[k]}$, which is finite.

**Necessity.** Suppose $\sum_k \abs{h[k]} = \infty$. Choose the bounded input $x[k] = \operatorname{sgn}(h[-k])$, with
values in $\{-1, 0, 1\}$. At $n = 0$, $y[0] = \sum_k x[k]\,h[-k] = \sum_k \abs{h[-k]} = \infty$, so the output is
unbounded.

**Worked example.** The recursion $y[n] = a\,y[n - 1] + x[n]$ has impulse response $h[n] = a^n$ for $n \ge 0$. The
sum $\sum_n \abs{a}^n$ is finite exactly when $\abs{a} < 1$, so the system is stable for $\abs{a} < 1$. With
$a = 0.9$ the sum is $10$, and an input bounded by 1 gives an output bounded by 10. With $a = 1$ the system is an
accumulator, and a constant input produces an output that grows without bound. In terms of the
<NoteLink to="z-transform">z-transform</NoteLink>, the pole at $z = a$ must lie inside the unit circle; see
<NoteLink to="poles-and-zeros">poles and zeros</NoteLink>.

## Pitfalls

- **Many useful systems are not LTI.** Quantisers, clippers, squarers and adaptive filters are nonlinear or
  time-varying. Their response to an impulse says little about their response to other inputs.
- **Marginal stability.** A pole on the unit circle, such as the accumulator's, gives a response that neither
  decays nor explodes for most inputs but diverges for a resonant one. It is not BIBO stable.
