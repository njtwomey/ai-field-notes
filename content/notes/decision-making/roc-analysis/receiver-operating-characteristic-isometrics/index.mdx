<Definition>
A two-class contingency table normalised to proportions has three degrees of freedom. Flach takes them as the
<Gloss name="fpr">false-positive rate</Gloss> $\text{fpr} = \text{FP}/\text{NEG}$, the <Gloss name="tpr">true-positive rate</Gloss> $\text{tpr} = \text{TP}/\text{POS}$ and
the **skew ratio** $c = \text{NEG}/\text{POS}$, where $\text{POS}$ and $\text{NEG}$ count actual positives and
negatives. Every metric of the table is then a function $M(\text{fpr}, \text{tpr}; c)$. For fixed $c$, the curves of
constant $M$ in the $(\text{fpr}, \text{tpr})$ plane are its **isometrics** <Cite id="flach2003" />.
</Definition>

## From three dimensions to two

Plot each evaluated classifier as a point in a three-dimensional space with axes $\text{fpr}$, $\text{tpr}$ and the
fraction of positives. The key assumption of <Gloss name="roc" /> analysis is that $\text{fpr}$ and $\text{tpr}$ describe a classifier
independently of the class distribution. Under that assumption, points evaluated on test sets with different class
ratios can be projected vertically onto one horizontal slice, the one for the class ratio expected in deployment
<Cite id="flach2003" />. The familiar ROC plot is that slice. The slice leaves the classifiers' positions unchanged
but fixes $c$, and with it the behaviour of every metric that depends on $c$.

Costs fold into the same parameter. If a <Gloss name="fp">false positive</Gloss> costs $c_{\text{FP}}$ and a <Gloss name="fn">false negative</Gloss> $c_{\text{FN}}$,
multiplying the class ratio by $c_{\text{FP}}/c_{\text{FN}}$ gives an effective ratio that plays exactly the role of
$\text{NEG}/\text{POS}$ in cost-weighted accuracy. Flach therefore speaks of skew rather than class ratio or costs:
$c > 1$ means negatives matter more, $c < 1$ that positives do.

## Metrics in terms of rates

Substituting $\text{TP} = \text{tpr}\cdot\text{POS}$, $\text{FP} = \text{fpr}\cdot\text{NEG}$ and dividing by
$\text{POS}$ rewrites the common metrics <Cite id="flach2003" />:

| metric | count form | rate form |
| --- | --- | --- |
| accuracy | $\dfrac{\text{TP} + \text{TN}}{\text{POS} + \text{NEG}}$ | $\dfrac{\text{tpr} + c\,(1 - \text{fpr})}{1 + c}$ |
| precision | $\dfrac{\text{TP}}{\text{TP} + \text{FP}}$ | $\dfrac{\text{tpr}}{\text{tpr} + c\,\text{fpr}}$ |
| $F_1$ | $\dfrac{2\,\text{TP}}{2\,\text{TP} + \text{FP} + \text{FN}}$ | $\dfrac{2\,\text{tpr}}{\text{tpr} + c\,\text{fpr} + 1}$ |
| weighted relative accuracy | $\dfrac{\text{TP}}{N} - \dfrac{\text{POS}}{N}\dfrac{\text{TP} + \text{FP}}{N}$ | $\dfrac{c}{(1 + c)^2}\,(\text{tpr} - \text{fpr})$ |

For $F_1$, the denominator $2\text{TP} + \text{FP} + \text{FN}$ equals $\text{TP} + \text{FP} + \text{POS}$, which divides
by $\text{POS}$ to $\text{tpr} + c\,\text{fpr} + 1$. For weighted relative accuracy, with $N = \text{POS} + \text{NEG}$,
the difference $\text{TP}/N - (\text{POS}/N)(\text{TP} + \text{FP})/N$ simplifies to
$\text{POS}\cdot\text{NEG}\,(\text{tpr} - \text{fpr})/N^2$.

Setting $c = 1$ gives a skew-insensitive version of each metric. For accuracy it is
$(\text{tpr} + 1 - \text{fpr})/2$, the <NoteLink to="accuracy-and-balanced-accuracy">balanced accuracy</NoteLink>.

## Three shapes of isometric

Solving $M = v$ for $\text{tpr}$ gives each isometric in closed form.

- **Accuracy: parallel lines.** $\text{tpr} = c\,\text{fpr} + v(1 + c) - c$. Every isometric has slope $c$. Accuracy
  applies the same trade-off between the classes everywhere in ROC space: one false positive is worth $c$ times less
  than one <Gloss name="tp">true positive</Gloss>, per unit of rate. These are the iso-cost lines of the
  <NoteLink to="receiver-operating-characteristic-convex-hull">ROC convex hull</NoteLink> with $c = (1 - \pi)\,c_{\text{FP}}/(\pi\,c_{\text{FN}})$.
- **Precision: lines through the origin.** $\text{tpr} = \frac{v}{1 - v}\, c\,\text{fpr}$. Precision depends only on the
  angle of the line from $(0, 0)$ to the point. Its isometrics rotate about the origin, so the trade-off it applies
  varies with the level of precision.
- **$F_1$: lines through $(-1/c, 0)$.** $\text{tpr}\,(2 - v) = v\,(c\,\text{fpr} + 1)$, a line with slope
  $vc/(2 - v)$ that meets $\text{tpr} = 0$ at $\text{fpr} = -1/c$. $F_1$ behaves like precision with the pivot moved
  left of the plot. When $c$ is large, as in retrieval with many irrelevant documents, the pivot approaches the origin
  and $F_1$ behaves almost like precision.

Weighted relative accuracy has isometrics of slope 1 for every $c$: only its scale changes with $c$. Flach calls such a
metric weakly skew-insensitive. Its isometrics coincide with those of balanced accuracy.

The **effective skew** of a metric at a point is the slope of its isometric there. It is the local exchange rate between
true- and false-positive rate that the metric applies. For accuracy it is $c$ everywhere. For precision at
$(\text{fpr}, \text{tpr})$ it is $\text{tpr}/\text{fpr}$, which grows as the classifier becomes more conservative.
Optimising precision therefore pushes towards the origin, where a few confident positives give a steep line.

## Coverage plots

Rule learning evaluates candidate rules by their counts, not rates. A **coverage plot** uses unnormalised axes, false
positives $\text{FP} \in [0, \text{NEG}]$ against true positives $\text{TP} \in [0, \text{POS}]$
<Cite id="furnkranz2005" />. It is ROC space stretched to a $\text{NEG} \times \text{POS}$ rectangle. In coverage space,
accuracy isometrics have slope 1 whatever the class ratio, because one extra true positive offsets one extra false
positive. Precision isometrics still pass through the origin. Fürnkranz and Flach use this geometry to explain how rule
learning heuristics trade coverage for precision: a heuristic is characterised by its isometrics in coverage space, and
two heuristics with the same isometrics choose the same rules.

## Worked example

A classifier has $\text{fpr} = 0.2$ and $\text{tpr} = 0.7$.

| skew | accuracy | precision | $F_1$ |
| --- | --- | --- | --- |
| $c = 1$ | $(0.7 + 0.8)/2 = 0.750$ | $0.7/(0.7 + 0.2) = 0.778$ | $1.4/(0.7 + 0.2 + 1) = 0.737$ |
| $c = 4$ | $(0.7 + 3.2)/5 = 0.780$ | $0.7/(0.7 + 0.8) = 0.467$ | $1.4/(0.7 + 0.8 + 1) = 0.560$ |

Moving from balanced classes to four negatives per positive raises accuracy, because the classifier's true-negative
rate ($0.8$) exceeds its true-positive rate ($0.7$) and negatives now carry more weight. The same move cuts precision
from $0.78$ to $0.47$: each false-positive rate point now stands for four times as many false positives. The point in
ROC space has not moved. Only the slice of 3D ROC space, and with it the isometrics, has changed.

## Assumptions

- **Rates are properties of the classifier.** Projecting onto one slice assumes that $\text{fpr}$ and $\text{tpr}$
  do not change with the class ratio, which holds under <NoteLink to="cost-sensitive-learning">prior shift</NoteLink> but not when the class-conditional distributions
  change.

## Pitfalls

- **A metric's skew is part of its definition.** Precision and $F_1$ computed on a test set carry that test set's class
  ratio. Comparing them across datasets with different ratios compares different metrics.
- **Isometric shape, not value, decides model selection.** Two metrics with the same isometrics in the deployment slice
  rank classifiers identically, whatever their numeric scales.
