<Definition>
Let $s(\xvec, y)$ be a **nonconformity score**, large when $y$ looks unusual for $\xvec$ under a fitted model. Given $n$
calibration cases $(\xvec_i, y_i)$ not used to fit the model, with scores $s_i = s(\xvec_i, y_i)$, **split conformal
prediction** sets

$$
\hat q = \text{the } \lceil (n + 1)(1 - \alpha) \rceil\text{-th smallest of } s_1, \dots, s_n, \qquad
C(\xvec) = \set{y : s(\xvec, y) \le \hat q}.
$$

If the calibration cases and the test case $(\xvec_{n+1}, y_{n+1})$ are exchangeable, then
$P\paren{y_{n+1} \in C(\xvec_{n+1})} \ge 1 - \alpha$ <Cite id="vovk2005" /> <Cite id="angelopoulos2021" />.
</Definition>

## What the guarantee says

The probability is over the random draw of both the calibration set and the test case. It holds for every model, however
poor, and for every data distribution, with no asymptotics. The model and the score affect only the size of the sets: a
good model gives small sets, a bad one large sets, and both cover at the promised rate. The assumption is
**exchangeability**: the joint distribution of the $n + 1$ cases is unchanged by permuting them. Independent and
identically distributed cases are exchangeable.

## Proof of coverage

Write $s_{n+1} = s(\xvec_{n+1}, y_{n+1})$ for the test case's score, and assume for simplicity that the scores have no
ties. Because the $n + 1$ cases are exchangeable, so are their scores. Each of the $n + 1$ scores is equally likely to be
the smallest, the second smallest, and so on. The rank of $s_{n+1}$ among all $n + 1$ scores is therefore uniform on
$\set{1, \dots, n + 1}$.

The test label is in the set exactly when $s_{n+1} \le \hat q = s_{(k)}$, the $k$-th smallest calibration score, with
$k = \lceil (n + 1)(1 - \alpha) \rceil$. That happens exactly when $s_{n+1}$ ranks at most $k$ among all $n + 1$ scores.
So

$$
P\paren{y_{n+1} \in C(\xvec_{n+1})} = \frac{k}{n + 1} = \frac{\lceil (n + 1)(1 - \alpha) \rceil}{n + 1} \ge 1 - \alpha.
$$

The ceiling also gives an upper bound: $k < (n + 1)(1 - \alpha) + 1$, so the coverage is below
$1 - \alpha + 1/(n + 1)$. Split conformal prediction is almost exactly calibrated, not merely conservative
<Cite id="angelopoulos2021" />. If $k > n$, which happens when $\alpha < 1/(n + 1)$, the set must be everything.

## Coverage for a given calibration set

The guarantee averages over calibration sets. For a fixed calibration set the coverage is a random quantity. Let $F$ be
the cdf of the score. Then $F(s_1), \dots, F(s_n)$ are independent uniforms, and the coverage given the calibration set
is $F(s_{(k)})$, the $k$-th order statistic of $n$ uniforms. That has a $\Beta(k, n + 1 - k)$ distribution, which is

$$
\Beta(n + 1 - l,\ l), \qquad l = \lfloor (n + 1)\alpha \rfloor
$$

<Cite id="angelopoulos2021" />. Its standard deviation is about $\sqrt{\alpha(1 - \alpha)/n}$, so a small calibration
set gives coverage that is right on average but varies noticeably from one calibration set to another.

## Scores for regression and classification

**Absolute residual.** For a regressor $\hat f$, $s(\xvec, y) = \abs{y - \hat f(\xvec)}$ gives the interval
$\hat f(\xvec) \pm \hat q$, with the same width everywhere <Cite id="lei2018" />.

**Conformalized quantile regression.** Fit lower and upper quantile regressors $\hat t_{\text{lo}}$ and
$\hat t_{\text{hi}}$, and score $s = \max\paren{\hat t_{\text{lo}}(\xvec) - y,\ y - \hat t_{\text{hi}}(\xvec)}$. The
interval $[\hat t_{\text{lo}}(\xvec) - \hat q,\ \hat t_{\text{hi}}(\xvec) + \hat q]$ adapts its width to the input
<Cite id="romano2019" />.

**Classification, least ambiguous sets.** For a classifier with estimated probabilities $\hat p(y \mid \xvec)$, score
$s = 1 - \hat p(y \mid \xvec)$. The set is every class with $\hat p(y \mid \xvec) \ge 1 - \hat q$. Sadinle, Lei and
Wasserman showed that this score gives the smallest expected set size among sets with the required coverage, when the
probabilities are correct <Cite id="sadinle2019" />.

**Classification, adaptive sets.** Sort the classes by estimated probability and score a label by the total probability
of the classes ranked at or above it. The set adds classes in order until their total probability reaches $\hat q$. Hard
inputs, with flat probability vectors, get large sets <Cite id="romano2020" />.

## Marginal, not conditional

The guarantee is marginal: coverage averages over inputs. It does not promise $P(y \in C(\xvec) \mid \xvec) \ge 1 - \alpha$
for each $\xvec$, and no method can guarantee that for every distribution without further assumptions
<Cite id="angelopoulos2021" />. With the absolute-residual score and noise that varies with $\xvec$, intervals
over-cover where noise is small and under-cover where it is large, as the figure shows. Adaptive scores reduce the
problem. For a regression interval, marginal coverage is the same kind of statement that
<NoteLink to="quantile-calibration">quantile calibration</NoteLink> makes at one level: the advertised rate holds on
average over all cases.

## Worked example

**Calibration set of 100, $\alpha = 0.1$.** $k = \lceil 101 \times 0.9 \rceil = 91$, so $\hat q$ is the 91st smallest of the
100 calibration scores. Coverage lies between $91/101 = 0.901$ and $0.9 + 1/101 = 0.910$ on average. For one
calibration set, coverage follows $\Beta(91, 10)$, with mean $0.901$, standard deviation $0.030$ and 90% of calibration
sets giving coverage between $0.848$ and $0.945$. With 1000 calibration cases the law is $\Beta(901, 100)$, with standard
deviation $0.009$ and 90% range $[0.884, 0.915]$.

**A classification set.** A classifier gives probabilities $(0.55, 0.30, 0.10, 0.05)$ for four classes, and the
calibration step with the score $1 - \hat p$ produced $\hat q = 0.8$. The set holds every class with probability at least
$0.2$: classes 1 and 2. A confident input with probabilities $(0.95, 0.03, 0.01, 0.01)$ gets the set $\set{1}$.

## Pitfalls

- **Exchangeability fails under shift.** If the test distribution differs from the calibration distribution, coverage is
  no longer guaranteed. Time series, where later cases differ systematically, violate it too.
- **Reusing the calibration set.** Tuning the model or the score on the calibration cases breaks the exchangeability of
  their scores with the test score.
- **Coverage is not usefulness.** A trivially large set covers. Compare methods by set size at equal coverage.
