<Definition>
**Weak supervision** is supervised learning in which the training labels are weaker than one correct label per
instance. The goal is still a predictor $f : \Xcal \to \Ycal$ of the true label $y$. What is observed is a weak label
$s$, related to $y$ by a known or partly known mechanism. Zhou sorts the mechanisms into three kinds: **incomplete**
supervision (only some instances are labelled), **inexact** supervision (labels are coarser than instances) and
**inaccurate** supervision (labels may be wrong) <Cite id="zhou2018weak" />.
</Definition>

## The three kinds

- **Incomplete supervision.** A small labelled set $\set{(\xvec_i, y_i)}_{i=1}^{l}$ and a large unlabelled set
  $\set{\xvec_j}_{j=l+1}^{l+u}$. Semi-supervised learning and <Gloss name="active-learning">active learning</Gloss> address it. <NoteLink
  to="self-training" /> and <NoteLink to="label-propagation" /> are semi-supervised methods.
  <NoteLink to="positive-unlabelled-learning">Positive-unlabelled learning</NoteLink> is the extreme case in which
  every labelled instance is positive.
- **Inexact supervision.** The label describes a group of instances, or a set of possible labels, rather than one
  instance. <NoteLink to="multiple-instance-learning">Multiple-instance learning</NoteLink> labels a bag positive if at
  least one instance is positive. <NoteLink to="learning-from-label-proportions">Learning from label
  proportions</NoteLink> gives each bag its class proportions. <NoteLink to="partial-label-learning">Partial-label
  learning</NoteLink> gives each instance a set of candidate labels, and <NoteLink to="complementary-labels" /> give one
  class the instance does not belong to.
- **Inaccurate supervision.** Every instance has a label, but some labels are wrong. Label noise from a single source
  is treated in <NoteLink to="learning-with-noisy-labels" />. When several noisy sources label the same instances,
  their accuracies can be estimated from their agreements: the <NoteLink to="dawid-skene-model" /> does this for human
  annotators, and <NoteLink to="data-programming" /> does it for labelling functions written as code.

## A common structure

Every setting in the table defines a channel from the true label to the observation, $p(s \mid y, \xvec)$. Learning
from weak labels then takes one of three routes.

1. **Correct the risk.** Write the risk on true labels as an <NoteLink to="expectation">expectation</NoteLink> over weak labels, and minimise the
   empirical version. The unbiased positive-unlabelled risk and the complementary-label risk are built this way.
2. **Treat $y$ as latent.** Write the likelihood of the observations as a sum over the unknown $y$ and maximise it,
   often by <NoteLink to="expectation-maximisation" />. The Dawid–Skene model and the data-programming label model
   are latent-variable models of this kind.
3. **Constrain the predictions.** Require that the predictions agree with the weak label when aggregated: a bag's
   predicted proportion must match its given proportion, or its maximum instance score must exceed a threshold.

The channel must be **identifiable**: different true labellings must produce different distributions of weak labels.
If every bag in a label-proportion problem has proportion one half, no method can tell which instances are positive.
If two labelling functions are copies of each other, their agreement says nothing about their accuracy.

## Two-stage and end-to-end pipelines

Programmatic weak supervision and crowdsourcing usually work in two stages. A **label model** combines the weak
labels into a probabilistic label $\tilde{y}_i = p(y_i \mid s_i)$ per instance. An **end model**, any classifier that
accepts soft targets, is then trained on $(\xvec_i, \tilde{y}_i)$ and generalises beyond the instances the weak
sources cover <Cite id="ratner2016" />. Multiple-instance and label-proportion methods are usually end-to-end: one
model maps instances to predictions, and the loss aggregates them to the level of the weak label.
