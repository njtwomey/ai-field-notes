<Definition>
Let $\Hcal$ be a class of functions from $\Xcal$ to $\set{-1, +1}$. A finite set
$C = \set{\xvec_1, \dots, \xvec_m} \subset \Xcal$ is **shattered** by $\Hcal$ if every one of the $2^m$ labellings of
$C$ is produced by some $h \in \Hcal$. The **Vapnik–Chervonenkis (VC) dimension** $\operatorname{VC}(\Hcal)$ is the
largest $m$ for which some set of $m$ points is shattered, or $\infty$ if there is no largest. The **growth function**
$\Pi_{\Hcal}(m)$ is the largest number of distinct labellings that $\Hcal$ produces on any $m$ points
<Cite id="vapnik1971" />.
</Definition>

## Intuition

A finite class can be learned with a number of examples that grows with $\ln\abs{\Hcal}$ (see
<NoteLink to="probably-approximately-correct-learning">probably approximately correct (PAC) learning</NoteLink>).
Infinite classes such as linear classifiers need another measure of size. On any finite sample, an infinite class
behaves like a finite one: only the labellings it can produce on those points matter. The growth function counts them.
If the class can produce every labelling of $m$ points, it can fit any labels at all on those points, including pure
noise, and its training error says nothing about its test error. The VC dimension is where this stops: the largest
sample size at which the class can still fit anything.

## Examples

To show $\operatorname{VC}(\Hcal) \ge d$, exhibit one set of $d$ points that is shattered. To show
$\operatorname{VC}(\Hcal) < d + 1$, show that **no** set of $d + 1$ points is shattered.

- **Thresholds on the line**, $h(x) = \sgn(x - a)$: VC dimension 1. One point can be labelled either way. For two
  points $x_1 < x_2$, the labelling $(+1, -1)$ is impossible.
- **Intervals on the line**, $+1$ inside $[a, b]$: VC dimension 2. For three points $x_1 < x_2 < x_3$, the labelling
  $(+1, -1, +1)$ is impossible.
- **Axis-aligned rectangles in the plane**: VC dimension 4. Four points in a diamond are shattered. Among any five
  points, the smallest rectangle containing the leftmost, rightmost, top and bottom points also contains the fifth,
  so that point cannot be labelled $-1$ while the others are $+1$.
- **Halfspaces in $\reals^d$**, $h(\xvec) = \sgn(\wvec^\top\xvec + b)$: VC dimension $d + 1$, derived below.
- **$\sgn(\sin(\omega x))$ with one parameter $\omega$**: VC dimension $\infty$.

### Halfspaces in $\reals^d$ have VC dimension $d + 1$

**Lower bound.** Take the $d + 1$ points $\zeros, \evec_1, \dots, \evec_d$, where $\evec_j$ is the $j$-th unit vector.
For any labels $y_0, y_1, \dots, y_d \in \set{-1, +1}$, set $b = y_0/2$ and $w_j = y_j - y_0/2$. Then
$\wvec^\top\zeros + b = y_0/2$ has the sign of $y_0$, and $\wvec^\top\evec_j + b = y_j$ has the sign of $y_j$. Every
labelling is produced, so these points are shattered.

**Upper bound.** Take any $d + 2$ points $\xvec_1, \dots, \xvec_{d+2}$. The $d + 1$ linear equations
$\sum_i \lambda_i\xvec_i = \zeros$ and $\sum_i \lambda_i = 0$ in $d + 2$ unknowns have a nonzero solution $\lambdavec$.
Let $I$ be the indices with $\lambda_i > 0$ and $J$ the rest, and let $\Lambda = \sum_{i \in I}\lambda_i > 0$. Then

$$
\zvec = \sum_{i \in I}\frac{\lambda_i}{\Lambda}\xvec_i = \sum_{j \in J}\frac{-\lambda_j}{\Lambda}\xvec_j
$$

is a convex combination of the points in $I$ and also of the points in $J$ (Radon's theorem). Label $I$ positive and
$J$ negative. A halfspace with $\wvec^\top\xvec_i + b > 0$ on $I$ has $\wvec^\top\zvec + b > 0$, because $\zvec$ is
an average of those points. A halfspace with $\wvec^\top\xvec_j + b \le 0$ on $J$ has $\wvec^\top\zvec + b \le 0$ for
the same reason. Both cannot hold, so no halfspace produces this labelling and no $d + 2$ points are shattered.

## The Sauer–Shelah lemma

Below the VC dimension the growth function is $2^m$. Above it, the growth function becomes polynomial.

**Sauer–Shelah lemma.** If $\operatorname{VC}(\Hcal) = d < \infty$, then for every $m$,

$$
\Pi_{\Hcal}(m) \le \sum_{i=0}^{d}\binom{m}{i} \le \paren{\frac{em}{d}}^d \quad (m \ge d).
$$

<Cite id="sauer1972" /> <Cite id="vapnik1971" />. For $d = 3$ and $m = 20$ points the lemma allows at most 1,351
labellings, against $2^{20} = 1{,}048{,}576$ possible ones. A class with finite VC dimension can fit only a vanishing
fraction of all labellings of a large sample, so fitting the training labels becomes evidence of real structure.

## The VC generalisation bound

With probability at least $1 - \delta$ over a sample of $m$ independent examples, every $h \in \Hcal$ satisfies
<Cite id="vapnik1998" />

$$
R(h) \le \hat R_S(h) + \sqrt{\frac{d\paren{\ln(2m/d) + 1} + \ln(4/\delta)}{m}}.
$$

The argument follows the finite-class proof, with the growth function in place of $\abs{\Hcal}$:

1. **Symmetrisation.** The true risk $R(h)$ involves infinitely many points. Draw a second, "ghost" sample $S'$ of
   size $m$. With high probability $\hat R_{S'}(h)$ is close to $R(h)$, so a large gap $R(h) - \hat R_S(h)$ implies a
   large gap $\hat R_{S'}(h) - \hat R_S(h)$ between two finite samples.
2. **Finitely many behaviours.** On the $2m$ points of $S \cup S'$, the class produces at most $\Pi_{\Hcal}(2m)$
   distinct labellings, so it acts as a finite class of that size.
3. **Union bound and concentration.** <NoteLink to="hoeffdings-inequality">Hoeffding's inequality</NoteLink> and a union
   bound over those labellings give a deviation of order $\sqrt{\ln\Pi_{\Hcal}(2m)/m}$.
4. **Sauer–Shelah.** $\ln\Pi_{\Hcal}(2m) \le d\ln(2em/d)$, which gives the bound.

The consequence is the fundamental theorem of statistical learning: a binary class is PAC learnable if and only if its
VC dimension is finite, and <Gloss name="erm" /> then needs $\Theta((d + \ln(1/\delta))/\epsilon^2)$ examples in the
agnostic case <Cite id="blumer1989" /> <Cite id="shalevshwartz2014" />.

## Worked example: linear classifiers on ten features

Halfspaces in $\reals^{10}$ have $d = 11$. Take $\delta = 0.05$. The gap term
$\sqrt{(11(\ln(2m/11) + 1) + \ln 80)/m}$ is

| Sample size $m$ | Gap |
| --- | --- |
| 1,000 | 0.269 |
| 10,000 | 0.099 |
| 100,000 | 0.035 |

With 10,000 examples, a linear classifier with 5% training error has true error below about 15% with probability at
least $0.95$ over the sample, whatever the distribution. Each tenfold increase in $m$ shrinks the gap by a little less
than $\sqrt{10}$, because of the $\ln m$ factor.

## Assumptions

- **Binary classification with the 0–1 loss.** Real-valued classes use the pseudo-dimension or fat-shattering
  dimension instead.
- **Worst case over distributions and over the class.** The bound holds for every distribution and every $h$
  simultaneously, which makes it loose for any particular one.

## Pitfalls

- **VC dimension is not parameter count.** One parameter can give infinite VC dimension, as $\sgn(\sin(\omega x))$
  shows. Many parameters can give small capacity when the class is constrained.
- **Bounds for large models are vacuous.** Neural networks with millions of weights have VC dimension far above typical
  sample sizes, yet they generalise. Margin-based and norm-based measures such as
  <NoteLink to="rademacher-complexity">Rademacher complexity</NoteLink> explain more of this. The
  <NoteLink to="support-vector-machine">support vector machine</NoteLink> is motivated by margin bounds that do not
  depend on the input dimension.
