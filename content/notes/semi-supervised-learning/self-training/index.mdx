<Definition>
**Self-training** turns a supervised learner into a semi-supervised one. Train a model on the labelled set. Predict
every unlabelled point, and add those whose predicted class probability exceeds a threshold $\tau$ to the training
set, labelled with the predicted class (a **pseudo-label**). Retrain on the enlarged set and repeat until no new points
qualify or a fixed number of rounds has passed <Cite id="scudder1965" />.
</Definition>

## Problem

Labels cost money or expert time; unlabelled inputs are often free. A model trained on a few labels has a poorly
placed boundary. If the classes form separated clusters, the unlabelled points show where the clusters are, and a
boundary through the gap between them would be better. Self-training uses the model's own predictions to reach that
boundary with any classifier that outputs confidences.

## Mechanism

### The loop

1. Fit the model to the labelled set $\Dcal_L$.
2. For each unlabelled point $\xvec_u$, compute $\hat p(y \mid \xvec_u)$ and its most probable class $\hat y_u$.
3. Add the pairs $(\xvec_u, \hat y_u)$ with $\max_y \hat p(y \mid \xvec_u) \ge \tau$ to the training set.
4. Refit and return to step 2. Pseudo-labels are usually recomputed each round, so a point can change class or drop
   out.

<SelfTrainingLoop />

The threshold controls a trade-off. A high $\tau$ adds few points, but their pseudo-labels are nearly all right. A low
$\tau$ adds many points, including wrong ones.

### Why it moves the boundary

A point far from the current boundary gets a confident prediction. Under the cluster assumption, points far from the
boundary on one side are mostly of that side's class, so the pseudo-labels are mostly correct. Adding them makes the
training set cover the clusters, and the refitted boundary moves away from the dense regions into the gap.

Training on hard pseudo-labels also minimises the uncertainty of the predictions on unlabelled data. With the
<NoteLink to="cross-entropy-and-perplexity">cross-entropy loss</NoteLink>, an unlabelled point contributes $-\log\hat p(\hat y_u \mid \xvec_u) = -\log\max_y\hat p(y \mid \xvec_u)$,
which is smallest when the model is confident about that point. The objective therefore prefers boundaries that pass
where few unlabelled points lie, since those leave fewer points near probability $1/2$.

### Worked example

Unlabelled data: 1000 points drawn from two equally likely classes, $x \mid y = 0 \sim \Gauss(-2, 1)$ and
$x \mid y = 1 \sim \Gauss(2, 1)$. The Bayes boundary is $x = 0$. Only two points are labelled, $x = -0.5$ in class 0
and $x = 2.5$ in class 1. A <NoteLink to="logistic-regression">logistic regression</NoteLink> (scikit-learn, default $L_2$ penalty) on these two points puts its
boundary at their midpoint, $x = 1.0$, and classifies the unlabelled points with accuracy $0.928$.

Self-training with $\tau = 0.9$ then gives, in one run:

| round | boundary | accuracy on unlabelled | pseudo-labelled points |
| ----- | -------- | ---------------------- | ---------------------- |
| 0     | 1.000    | 0.928                  | 261                    |
| 1     | 1.548    | 0.844                  | 568                    |
| 3     | 1.187    | 0.908                  | 814                    |
| 9     | 0.248    | 0.982                  | 939                    |
| 15    | 0.007    | 0.988                  | 947                    |

In round 1 the boundary moves the wrong way. The first model is weak (slope $0.74$), and with its boundary at 1.0,
249 points clear the threshold as class 0 but only 12 as class 1. The unbalanced pseudo-labels shift the fit towards
class 1. As more of the class-1 cluster clears the
threshold, the boundary moves into the gap and settles at $0.007$. The final accuracy, $0.988$, matches the <NoteLink to="bayes-theorem">Bayes rule</NoteLink>
on this sample ($0.987$).

### Variants

- **Yarowsky's algorithm.** For word-sense disambiguation, Yarowsky started from a few seed collocations per sense,
  labelled the contexts they matched, learnt new collocations from those contexts and repeated, using the constraint
  that a word keeps one sense per discourse to add and correct labels <Cite id="yarowsky1995" />.
- **Co-training.** When the features split into two views, each sufficient to classify and conditionally independent
  given the class, two classifiers are trained, one per view, and each labels confident examples for the other
  <Cite id="blum1998" />. The other view's errors look like random noise to each classifier rather than a systematic
  bias.
- **Noisy Student.** A teacher network labels a large unlabelled image set. A student network, as large or larger,
  trains on labelled and pseudo-labelled images with noise added: <NoteLink to="data-augmentation">data augmentation</NoteLink>, dropout and stochastic depth.
  The student becomes the next teacher. The noise stops the student from simply copying the teacher
  <Cite id="xie2020" />.
- **FixMatch.** Each unlabelled image is weakly augmented (flipped and shifted) and strongly augmented. If the model's
  prediction on the weak version exceeds $\tau$ (0.95 in the paper), its arg max becomes the pseudo-label that the
  prediction on the strong version is trained to match <Cite id="sohn2020" />. Pseudo-labels are recomputed at every
  step, inside one training run.

## Cost

Each round refits the model, so self-training costs a few times the supervised training, plus one prediction pass
over the unlabelled data per round. Online variants such as FixMatch fold pseudo-labelling into each minibatch and
cost roughly one extra forward pass per unlabelled example per step.

## Trade-offs

- **Confirmation bias.** A wrong pseudo-label is trained on as if it were true, which makes the model more confident
  in the same mistake. Errors near the boundary are self-reinforcing. A high threshold, recomputing pseudo-labels each
  round, and noise or augmentation in the student reduce the effect.
- **Calibration.** The threshold assumes the model's confidences mean something. An overconfident model, such as
  <NoteLink to="naive-bayes">naive Bayes</NoteLink> or an unregularised network, admits many wrong pseudo-labels.
- **Class balance.** Confident predictions are not balanced across classes, as the worked example shows. Capping the
  number of pseudo-labels per class keeps the enlarged training set close to the true class proportions.
- **The cluster assumption.** If classes overlap heavily or the boundary runs through a dense region, the unlabelled
  data carry little information about the boundary, and self-training can do worse than using the labels alone
  <Cite id="chapelle2006" />.
