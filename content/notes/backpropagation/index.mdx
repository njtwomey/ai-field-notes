<Definition>
The chain rule states that for $y = g(u)$ and $u = h(x)$,
$\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}$. In several variables, the Jacobian of a composition is the product of
the Jacobians. Backpropagation is reverse-mode automatic differentiation: it applies the chain rule from the output
towards the inputs <Cite id="rumelhart1986" />.
</Definition>

## Problem

A neural network's loss is a scalar that depends on millions of parameters through a long composition of functions.
Training needs the gradient of the loss with respect to every parameter. Finite differences would need one extra
evaluation of the loss per parameter. Symbolic differentiation produces expressions that grow exponentially with
depth.

## Mechanism

Break the computation into a graph of primitive operations, each with a known local derivative. For a scalar output
$f$, define the **adjoint** of each intermediate value $v$ as $\bar v = \partial f / \partial v$.

1. **Forward pass.** Evaluate every node from the inputs to $f$, storing each value.
2. **Seed.** Set $\bar f = 1$.
3. **Backward pass.** Visit the nodes in reverse order. For each node $v$, sum over the nodes $w$ that use it:
   $$
   \bar v = \sum_{w \,:\, v \to w} \bar w \,\frac{\partial w}{\partial v}.
   $$

The adjoints of the inputs are the gradient. The sum over uses is the multivariable chain rule: a value that feeds
several later computations collects a contribution from each.

## Example

Take the function of two inputs

$$
f(x, y) = \paren{xy + \sin x}^2.
$$

As a graph of primitive operations it is

$$
a = xy, \qquad b = \sin x, \qquad c = a + b, \qquad f = c^2,
$$

so $x$ feeds two nodes, $a$ and $b$, and its adjoint collects a contribution from each. The figure steps through the
forward pass and then the backward pass for chosen values of $x$ and $y$, and checks the result against finite
differences.

<Derivation title="The adjoints of the example">
Backwards from $\bar f = 1$: $\bar c = 2c$. Addition passes its adjoint unchanged, so $\bar a = \bar b = \bar c$. Then
$\bar y = \bar a\, x$, and $x$ collects two contributions, $\bar x = \bar a\, y + \bar b \cos x$. Substituting gives
$\partial f/\partial x = 2(xy + \sin x)(y + \cos x)$ and $\partial f/\partial y = 2(xy + \sin x)\,x$.
</Derivation>

## Cost

Reverse mode computes the full gradient of a scalar output in a small constant multiple of the cost of evaluating $f$,
whatever the number of inputs <Cite id="griewank2008" />. This is the cheap gradient principle, and it is why
networks with billions of parameters can be trained.

Forward mode is the alternative: it propagates derivatives from the inputs, one input direction per pass. It is
efficient when there are few inputs and many outputs. Reverse mode is efficient in the opposite case, one scalar loss
and many parameters, which is the machine-learning case <Cite id="baydin2018" />.

## Trade-offs

- **Memory.** The backward pass needs the forward values, so they must be stored. Activation memory, not arithmetic,
  often limits the batch size. Gradient checkpointing stores only some values and recomputes the rest.
- **Vector–Jacobian products.** Each backward step multiplies a row vector of adjoints by a local Jacobian. The full
  Jacobian is never formed.
- **Numerical checks.** Compare the result with central finite differences, $\paren{f(x + \epsilon) - f(x -
  \epsilon)}/(2\epsilon)$, on a few inputs when implementing a new operation.

## Pitfalls

- **Vanishing and exploding gradients.** The backward pass multiplies many local derivatives. When they are
  consistently below or above 1, gradients in early layers shrink or grow exponentially with depth.
- **Non-differentiable operations.** Rounding, sorting and sampling have zero or undefined derivatives. They need
  surrogate gradients or reparameterisation.
