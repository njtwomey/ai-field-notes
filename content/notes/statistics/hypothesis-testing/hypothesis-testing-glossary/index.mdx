<Definition>
A hypothesis test decides between two statements about a parameter $\theta$ using data $X$. It computes a test
statistic $T(X)$ and rejects the null hypothesis when $T$ falls in a rejection region chosen so that a true null is
rejected with probability at most $\alpha$ <Cite id="casella2002" />. This page defines every term involved. Each
row links to the note that develops it.
</Definition>

The definitions follow a common running example: $X_1, \dots, X_n$ are independent with mean $\mu$ and standard
deviation $\sigma$, and the test concerns $\mu$.

## The set-up

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Parameter | $\theta$ | The unknown quantity the test is about, e.g. the mean $\mu$ or a difference of means. | |
| Null hypothesis | $H_0$ | The claim the test is designed to reject, stated as $\theta \in \Theta_0$. Usually a statement of no effect, e.g. $\mu = \mu_0$. | <NoteLink to="null-and-alternative-hypotheses" /> |
| Alternative hypothesis | $H_1$ | The claim accepted when $H_0$ is rejected, $\theta \in \Theta_1$, with $\Theta_0$ and $\Theta_1$ disjoint. | <NoteLink to="null-and-alternative-hypotheses" /> |
| Simple, composite | | A hypothesis is simple if it fixes the distribution completely ($\mu = 0$, $\sigma$ known), and composite otherwise ($\mu \le 0$). | <NoteLink to="neyman-pearson-lemma" /> |
| One-sided, two-sided | | A one-sided alternative points in one direction ($\mu > \mu_0$); a two-sided alternative allows either ($\mu \ne \mu_0$). | <NoteLink to="one-and-two-sided-tests" /> |
| Test statistic | $T = T(X)$ | A function of the data whose value measures the evidence against $H_0$, e.g. $z = (\bar X - \mu_0)/(\sigma/\sqrt n)$. | <NoteLink to="z-test" /> |
| Null distribution | | The distribution of $T$ when $H_0$ holds. The test is calibrated against it. | <NoteLink to="null-and-alternative-hypotheses" /> |
| Sampling distribution | | The distribution of a statistic over repeated samples of the same size, under whatever $\theta$ is true. | <NoteLink to="standard-error" /> |
| Pivot | | A function of the data and the parameter whose distribution does not depend on the parameter, e.g. $(\bar X - \mu)/(S/\sqrt n) \sim t_{n-1}$. Tests and confidence intervals are built from pivots. | <NoteLink to="confidence-intervals" /> |
| Degrees of freedom | $\nu$ | The parameter of a $t$, $\chi^2$ or $F$ reference distribution, usually the sample size minus the number of estimated parameters. | <NoteLink to="one-sample-t-test" /> |

## The decision and its errors

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Rejection region | $R$ | The set of values of $T$ for which $H_0$ is rejected. Also called the critical region. | <NoteLink to="null-and-alternative-hypotheses" /> |
| Critical value | $c$ | The boundary of the rejection region, e.g. reject when $\abs{z} > c = 1.96$. | <NoteLink to="significance-level" /> |
| Type I error | | Rejecting $H_0$ when it is true: a false positive. | <NoteLink to="type-i-and-type-ii-errors" /> |
| Type II error | | Not rejecting $H_0$ when it is false: a false negative. | <NoteLink to="type-i-and-type-ii-errors" /> |
| Significance level | $\alpha$ | The chosen upper bound on the probability of a type I error, fixed before seeing the data. Commonly 0.05. | <NoteLink to="significance-level" /> |
| Size | | The largest actual probability of a type I error, $\sup_{\theta \in \Theta_0} P_\theta(T \in R)$. A test has level $\alpha$ when its size is at most $\alpha$. | <NoteLink to="significance-level" /> |
| Type II error rate | $\beta(\theta)$ | The probability of not rejecting $H_0$ at a particular $\theta \in \Theta_1$. It depends on the true effect. | <NoteLink to="type-i-and-type-ii-errors" /> |
| Power | $1 - \beta(\theta)$ | The probability of rejecting $H_0$ at a particular $\theta \in \Theta_1$. The power function gives it for every $\theta$; at $\theta \in \Theta_0$ it equals the type I error rate. | <NoteLink to="type-i-and-type-ii-errors" /> |
| Type S error | | Rejecting $H_0$ with an estimate of the wrong sign. | <NoteLink to="winners-curse" /> |
| Type M error | | The factor by which a statistically significant estimate exaggerates the true effect. Large when power is low. | <NoteLink to="winners-curse" /> |

## The evidence

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| p-value | $p$ | The probability under $H_0$ of a test statistic at least as extreme as the one observed, e.g. $P_{H_0}(\abs{Z} \ge \abs{z_{\text{obs}}})$ for a two-sided test. Equivalently, the smallest $\alpha$ at which the data would reject. It is not the probability that $H_0$ is true. | <NoteLink to="p-value" /> |
| Statistically significant | | $p \le \alpha$: the test rejects $H_0$ at level $\alpha$. | <NoteLink to="p-value" /> |
| Practically significant | | The effect is large enough to matter for the decision at hand. A statistically significant effect can be too small to matter, and a large effect can fail to reach significance. | <NoteLink to="a-b-test" /> |
| Likelihood ratio | $\Lambda$ | The ratio of the likelihoods of the data under two hypotheses. The most powerful test of a simple null against a simple alternative rejects when it is large. | <NoteLink to="neyman-pearson-lemma" /> |

## Design

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Effect size | $\delta$, $d$ | The size of the departure from $H_0$, often standardised, e.g. Cohen's $d = (\mu_1 - \mu_0)/\sigma$. | <NoteLink to="effect-size" /> |
| Sample size | $n$ | The number of independent observations, per group in a two-group comparison. | <NoteLink to="sample-size-planning" /> |
| Minimum detectable effect | MDE | The smallest true effect that a test with the planned $n$ and $\alpha$ detects with the chosen power, usually 80%. | <NoteLink to="sample-size-planning" /> |
| Standard error | SE | The standard deviation of an estimator's sampling distribution, e.g. $\sigma/\sqrt n$ for the sample mean. | <NoteLink to="standard-error" /> |
| Allocation ratio | $k$ | The ratio of group sizes in a two-group comparison. Equal allocation maximises power for a fixed total. | <NoteLink to="pooled-two-sample-t-test" /> |

## Estimation alongside the test

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Confidence interval | | A random interval that contains $\theta$ with probability at least $1 - \alpha$ over repeated samples. | <NoteLink to="confidence-intervals" /> |
| Confidence level | $1 - \alpha$ | The coverage probability a confidence interval is built to achieve. | <NoteLink to="confidence-intervals" /> |
| Test–interval duality | | $\theta_0$ lies in the level $1 - \alpha$ confidence interval exactly when the two-sided test of $\theta = \theta_0$ at level $\alpha$ does not reject. | <NoteLink to="confidence-intervals" /> |
| Sufficient statistic | | A statistic that carries all the information in the data about $\theta$. Good tests depend on the data only through one. | <NoteLink to="sufficient-statistic" /> |

## Properties of tests

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Exact test | | A test whose type I error rate equals its nominal level at every sample size, e.g. the binomial test. | <NoteLink to="binomial-test" /> |
| Asymptotic test | | A test whose level is correct only as $n \to \infty$, e.g. a $z$-test with an estimated $\sigma$. | <NoteLink to="z-test" /> |
| Conservative, anti-conservative | | A test is conservative when its actual size is below $\alpha$, and anti-conservative (liberal) when it is above. | <NoteLink to="significance-level" /> |
| Uniformly most powerful | UMP | A level-$\alpha$ test with the highest power at every $\theta \in \Theta_1$ among all level-$\alpha$ tests. It exists for one-sided alternatives in exponential families. | <NoteLink to="neyman-pearson-lemma" /> |

## Many tests at once

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| Family-wise error rate | FWER | The probability of at least one type I error among $m$ tests. For independent tests at level $\alpha$ it is $1 - (1 - \alpha)^m$. | <NoteLink to="multiple-testing" /> |
| False discovery rate | FDR | The expected fraction of false positives among the rejected hypotheses, $\expect[V / \max(R, 1)]$, with $V$ false rejections among $R$ rejections. | <NoteLink to="multiple-testing" /> |
| Bonferroni correction | | Test each of $m$ hypotheses at level $\alpha/m$. Controls the FWER at $\alpha$ under any dependence. | <NoteLink to="multiple-testing" /> |
| Benjamini–Hochberg procedure | BH | Reject the $k$ smallest p-values, where $k$ is the largest $i$ with $p_{(i)} \le i q / m$. Controls the FDR at $q$ for independent tests. | <NoteLink to="multiple-testing" /> |

## Experiments

| Term | Symbol | Definition | See |
| --- | --- | --- | --- |
| A/B test | | A randomised experiment comparing a control A with a variant B on a pre-chosen metric. | <NoteLink to="a-b-test" /> |
| A/A test | | An experiment with two identical arms, run to check that the pipeline produces p-values that are uniform under $H_0$. | <NoteLink to="a-a-test" /> |
| Sample ratio mismatch | SRM | Observed group sizes that differ from the designed split by more than chance allows. It signals a broken randomisation or data pipeline. | <NoteLink to="sample-ratio-mismatch" /> |
| Peeking | | Checking the p-value repeatedly and stopping at the first significant result. It raises the type I error rate far above $\alpha$. | <NoteLink to="peeking-and-optional-stopping" /> |
| Winner's curse | | The tendency of significant results from low-powered tests to overstate the true effect. | <NoteLink to="winners-curse" /> |
| Multiple comparisons | | Testing many metrics or variants at once, which inflates the chance that something appears significant. | <NoteLink to="many-metrics-and-variants" /> |

## How the pieces fit

Before the data: choose $H_0$ and $H_1$, the test statistic, the level $\alpha$, and the sample size $n$ that gives
the required power at the minimum detectable effect. After the data: compute $T$ and its p-value, reject $H_0$ when
$p \le \alpha$, and report the effect size with a confidence interval. The level controls the type I error rate, the
sample size controls the type II error rate at a given effect, and the confidence interval conveys the size of the
effect that a single p-value does not <Cite id="lehmann2005" />.
