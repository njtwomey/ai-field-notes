<Definition>
A test with <NoteLink to="null-and-alternative-hypotheses">critical region</NoteLink> $\Ccal$ has **significance level**
$\alpha$ when

$$
\sup_{P \in H_0} P(T \in \Ccal) \le \alpha,
$$

that is, when no distribution in the null hypothesis $H_0$ rejects with probability above $\alpha$. The left-hand side
is the **size** of the test. A test of size $\alpha$ is also of level $\alpha$; a test of level $\alpha$ may have a
smaller size <Cite id="lehmann2005" />.
</Definition>

## What α controls

$\alpha$ bounds the Type I error rate: the long-run fraction of true nulls that the test rejects. It says nothing
about any single decision. It does not bound the fraction of rejections that are wrong. That fraction also depends on
how many of the tested nulls are true and on the power of the test.

The rule "reject when $p \le \alpha$" has level $\alpha$, because a valid
<NoteLink to="p-value">p-value</NoteLink> satisfies $P_{H_0}(p \le \alpha) \le \alpha$ for every $\alpha$. For a
statistic $T$ whose large values count against $H_0$, the p-value is $p = G(T)$ with $G(t) = P_{H_0}(T \ge t)$, a
non-increasing function. So $p \le \alpha$ exactly when $T$ is at least the smallest value $c_\alpha$ with
$G(c_\alpha) \le \alpha$, and the rejection probability under $H_0$ is $G(c_\alpha) \le \alpha$. The same argument
shows that the p-value is the smallest level at which the observed data would be rejected.

## Choosing α

$\alpha$ is a design choice made before the data are seen.

- **Convention.** $\alpha = 0.05$ is a convention with no special justification. Fields with many tests or costly false
  claims use smaller values: genome-wide association studies use $5 \times 10^{-8}$, and particle physics requires five
  <NoteLink to="variance-and-covariance">standard deviations</NoteLink>, about $3 \times 10^{-7}$ one-sided. A group of
  statisticians proposed $\alpha = 0.005$ for claims of new discoveries <Cite id="benjamin2018" />.
- **Costs.** A lower $\alpha$ makes <Gloss name="fp">false positives</Gloss> rarer and misses more common at a fixed
  sample size. When a false positive is cheap and a miss is expensive, as in screening, a larger $\alpha$ can be right.
- **Multiplicity.** Running $m$ tests at level $\alpha$ gives about $m\alpha$ false rejections when all nulls are true.
  <NoteLink to="multiple-testing">Multiple-testing corrections</NoteLink> set a stricter per-test level.

## Discrete statistics: size below the level

When the test statistic is discrete, only a few sizes are attainable. For $n = 20$ tosses of a coin, the number of heads
is <NoteLink to="binomial-distribution">binomial</NoteLink>, a sum of 20
<NoteLink to="bernoulli-distribution">Bernoulli</NoteLink> tosses, so its tail probabilities jump in steps. For the
<NoteLink to="one-and-two-sided-tests">one-sided test</NoteLink> of $H_0: p = 1/2$ against $H_1: p > 1/2$, rejecting at
14 or more heads has size $0.058$, above $0.05$. Rejecting at 15 or more has size $0.021$. The level-0.05 test must use
15, so its size is $0.021$. The test is **conservative**: it rejects true nulls less often than $\alpha$, and it loses
power as a result.

The attained size changes irregularly with $n$. At $n = 21$ the same test rejects at 15 or more heads with size
$0.039$.

<SizeStaircase />

A **randomised test** attains size exactly $\alpha$. It rejects for 15 or more heads, and for exactly 14 heads it
rejects with probability $\gamma$, using an independent random draw. Its size is $P(S \ge 15) + \gamma\, P(S = 14)$, and
setting this equal to $\alpha$ gives
$\gamma = \paren{\alpha - P(S \ge 15)}/P(S = 14) = (0.05 - 0.0207)/0.0370 \approx 0.79$. The
<NoteLink to="neyman-pearson-lemma">Neyman–Pearson lemma</NoteLink> needs randomised tests to reach every size with
discrete data. In practice, two analysts with the same data could reach different decisions, so randomised tests are
rarely used. Reporting the exact p-value is the usual alternative <Cite id="casella2002" />.

## Pitfalls

- **Choosing α after seeing the p-value.** Moving the threshold to 0.10 because $p = 0.07$ destroys the error-rate
  guarantee.
- **Reading α as the error probability of a decision.** $\alpha$ is a rate over repeated use under $H_0$. The
  probability that a particular rejection is a false positive needs the prior share of true nulls and
  <NoteLink to="bayes-theorem">Bayes' theorem</NoteLink>.
- **Treating 0.049 and 0.051 as different evidence.** The threshold is a decision rule. The evidence changes
  continuously with the p-value.
