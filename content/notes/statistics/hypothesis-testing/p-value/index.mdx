<Definition>
Let $T$ be a <NoteLink to="null-and-alternative-hypotheses">test statistic</NoteLink> whose large values count as evidence against a null hypothesis $H_0$, and let $t$ be its
observed value. The p-value is

$$
p = P_{H_0}(T \ge t).
$$

For a <NoteLink to="one-and-two-sided-tests">two-sided test</NoteLink>, "at least as extreme" means $\abs{T} \ge \abs{t}$. The null is rejected at <NoteLink to="significance-level">significance level</NoteLink>
$\alpha$ when $p \le \alpha$ <Cite id="wasserman2004" />.
</Definition>

## Reading a p-value

A p-value answers one question: if $H_0$ were true, how often would data this extreme occur? A small p-value means
the data would be unusual under $H_0$. Either $H_0$ is false, or an unusual event occurred.

The significance level $\alpha$ is chosen before seeing the data. It fixes the long-run rate of false rejections when
$H_0$ is true. Reporting the p-value itself carries more information than reporting only whether it crossed $\alpha$.

## Uniform under the null

If $H_0$ is true and $T$ is continuous, the p-value has a $\Unif(0, 1)$ distribution. So
$P_{H_0}(p \le \alpha) = \alpha$ for every $\alpha$: the rule "reject when $p \le \alpha$" makes false rejections at
exactly rate $\alpha$.

**Proof.** Let $F$ be the cdf of $T$ under $H_0$, assumed continuous and strictly increasing on the range of $T$. The
one-sided p-value is the random variable $P = 1 - F(T)$. For $u \in (0, 1)$,

$$
P_{H_0}(F(T) \le u) = P_{H_0}\paren{T \le F^{-1}(u)} = F\paren{F^{-1}(u)} = u.
$$

The first step applies the increasing function $F^{-1}$ to both sides of the inequality. The second is the definition
of the cdf. So $F(T) \sim \Unif(0, 1)$, the <Gloss name="probability-integral-transform">probability integral transform</Gloss> used in
<NoteLink to="inverse-transform-sampling">inverse-transform sampling</NoteLink>, and $P = 1 - F(T)$ is uniform too. For
a two-sided test the same argument applies to $\abs T$, whose null cdf is also continuous.

<Derivation title="Discrete statistics: the p-value is conservative">
When $T$ is discrete, $P_{H_0}(P \le \alpha) \le \alpha$ instead. Let $G(t) = P_{H_0}(T \ge t)$, so $P = G(T)$. $G$ is
non-increasing. Let $t^*$ be the smallest attainable value with $G(t^*) \le \alpha$. Then $P \le \alpha$ exactly when
$T \ge t^*$, and $P_{H_0}(T \ge t^*) = G(t^*) \le \alpha$. Equality holds only when $\alpha$ is one of the attainable
tail probabilities.
</Derivation>

## What a p-value is not

The American Statistical Association lists these misreadings <Cite id="wasserstein2016" />:

- **Not the probability that $H_0$ is true.** $p$ is computed assuming $H_0$. The probability of $H_0$ given the data
  requires a prior and <NoteLink to="bayes-theorem">Bayes' theorem</NoteLink>.
- **Not the probability that the result is due to chance.** Chance is always involved. $p$ measures how unusual the
  data are under one specific chance model.
- **Not a measure of <NoteLink to="effect-size">effect size</NoteLink>.** A tiny effect gives a small $p$ when $n$ is large. A large effect can give a large
  $p$ when $n$ is small. Report the effect size and a <NoteLink to="confidence-intervals">confidence interval</NoteLink> alongside $p$.
- **Not a replication probability.** Suppose a <NoteLink to="z-test">z-test</NoteLink> gives $p = 0.04$, so $\abs{z} \approx 2.05$. Even if the true
  effect equals the observed one, a replication's statistic is $\Gauss(2.05, 1)$, and it exceeds 1.96 in absolute value
  with probability $\Phi(2.05 - 1.96) + \Phi(-2.05 - 1.96) \approx 0.54$. An identical replication reaches
  $p < 0.05$ only about half the time.

## Pitfalls

- **Multiple testing.** Testing 20 true nulls at $\alpha = 0.05$ yields about one false rejection. Correct for the
  number of tests or control the <Gloss name="fdr">false discovery rate</Gloss>.
- **Optional stopping.** Checking the p-value repeatedly and stopping when it drops below $\alpha$ raises the false
  rejection rate well above $\alpha$.
- **Choosing the side afterwards.** A one-sided test must be specified before seeing the data. Choosing the
  direction that looks favourable halves the p-value dishonestly.
