<Definition>
An **autoregressive generative model** fixes an order on the $d$ elements of $\xvec = (x_1, \dots, x_d)$, such as
pixels in raster order or audio samples in time order, and writes the joint distribution as

$$
p_{\thetavec}(\xvec) = \prod_{i=1}^d p_{\thetavec}(x_i \mid x_1, \dots, x_{i-1}).
$$

A neural network with parameters $\thetavec$ outputs every conditional. The network is **masked** so that the output
for element $i$ depends only on the elements before $i$. Training maximises the exact log-likelihood $\sum_i \log
p_{\thetavec}(x_i \mid x_{<i})$ <Cite id="oord2016" />.
</Definition>

## The factorisation is exact

The chain rule of probability, $p(a, b) = p(a)\,p(b \mid a)$, applied $d - 1$ times gives the product for any joint
distribution and any ordering. The factorisation itself makes no assumption. Assumptions enter only through how the
conditionals are parameterised. A <NoteLink to="hidden-markov-model">Markov model</NoteLink> would limit each
conditional to the last few elements; a neural autoregressive model lets each conditional depend on the whole prefix.

Each conditional is a distribution over one element, which is easy to normalise. For 8-bit pixels or audio quantised to
256 levels, it is a softmax over 256 values. The categorical output makes no assumption about the shape of the
distribution and can be multimodal. Van den Oord et al. found that a 256-way softmax modelled pixels better than a
continuous mixture <Cite id="oord2016" />.

## Masking: all conditionals in one pass

Computing each conditional with a separate network would be expensive. Masked architectures compute all $d$ conditionals
in a single forward pass while respecting the ordering:

- **MADE** multiplies the weight matrices of a fully connected autoencoder by binary masks. Each hidden unit is
  assigned a number $m$, and connections are kept only if they respect the ordering, so output $i$ depends only on
  inputs $1, \dots, i - 1$ <Cite id="germain2015" />.
- **PixelCNN** uses masked convolutions over images. The kernel's weights at the current pixel and at all later
  positions in raster order are set to zero. The first layer excludes the current pixel (mask A); later layers may
  include it (mask B), since their input at that position already depends only on earlier pixels
  <Cite id="oord2016" />. Stacked masked convolutions leave a blind spot of earlier pixels that are never seen. Gated
  PixelCNN removes it with separate vertical and horizontal stacks <Cite id="oord2016b" />.
- **WaveNet** applies causal convolutions to audio: the output at time $i$ uses inputs at times up to $i - 1$ only.
  Dilated convolutions skip inputs with a gap that doubles each layer. With kernel size 2 and dilations $1, 2, 4,
  \dots, 512$, ten layers have a receptive field of $1 + (1 + 2 + \dots + 512) = 1024$ samples <Cite id="oord2016c" />.
  WaveNet quantises 16-bit audio to 256 levels with $\mu$-law companding before the softmax <Cite id="oord2016c" />.
- **Transformers** with a causal attention mask are autoregressive models over token sequences. Language models are
  the most widely used case.

## Training and sampling

**Training** is parallel. The whole observed $\xvec$ is fed in, the mask guarantees that each prediction sees only
its prefix, and the loss is the sum of $d$ cross-entropies. Feeding the true prefix, rather than the model's own
samples, is called teacher forcing.

**Sampling** is sequential. Draw $x_1$, feed it back, draw $x_2$, and so on. A $64 \times 64$ RGB image with one
conditional per colour channel needs $12{,}288$ network evaluations. For transformers, the
<NoteLink to="kv-cache">KV cache</NoteLink> reuses the computation for the prefix. Autoregressive priors are also used
on small latent grids, as in the <NoteLink to="vq-vae">VQ-VAE</NoteLink>, where sequential sampling is affordable.

## Worked example

Two binary pixels are modelled with $p(x_1 = 1) = 0.6$, $p(x_2 = 1 \mid x_1 = 1) = 0.8$ and $p(x_2 = 1 \mid x_1 = 0) =
0.3$. The joint distribution is

| $(x_1, x_2)$ | probability             |
| ------------ | ----------------------- |
| $(0, 0)$     | $0.4 \times 0.7 = 0.28$ |
| $(0, 1)$     | $0.4 \times 0.3 = 0.12$ |
| $(1, 0)$     | $0.6 \times 0.2 = 0.12$ |
| $(1, 1)$     | $0.6 \times 0.8 = 0.48$ |

The probabilities sum to 1 by construction, with no normalising constant to compute. The log-likelihood of the
observation $(1, 1)$ is $\log 0.6 + \log 0.8 = \log 0.48 = -0.734$ nats. Sampling draws $x_1$ from $\Bern(0.6)$ and then
$x_2$ from the conditional that $x_1$ selects.

## Assumptions

- **An ordering.** The model is exact for any ordering, but some orderings are easier to learn than others. Raster
  order is arbitrary for images.
- **Discretised values.** A softmax needs a finite alphabet. Continuous data are quantised, or the softmax is replaced
  by a mixture density.

## Pitfalls

- **Slow sampling.** Generation takes $d$ sequential steps and cannot be parallelised across elements.
- **Errors compound.** Sampling conditions on the model's own earlier outputs, which may be unlike the training data.
  Teacher forcing never exposes the model to its own mistakes.
- **Likelihood is not sample quality.** Autoregressive image models achieved the best log-likelihoods of their time
  while their samples lacked global coherence, since most of the likelihood comes from local detail.
- **Receptive field.** An element can depend only on the prefix inside the receptive field. Convolutional models need
  depth or dilation to see far back.
