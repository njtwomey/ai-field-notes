<Definition>
Let $f : \reals^d \to \reals$ be a model's output for one class, such as a logit or a probability, and $\xvec \in \reals^d$
an input. A **feature attribution** is a vector $\phivec(\xvec) \in \reals^d$ whose entry $\phi_j$ measures how much
feature $j$ contributed to $f(\xvec)$. Many methods measure the contribution relative to a **baseline** input
$\xvec^\prime$, which represents the absence of signal, and aim for **completeness**:
$\sum_{j=1}^d \phi_j = f(\xvec) - f(\xvec^\prime)$.
</Definition>

## Intuition

A model has refused a loan, or labelled an image "dog". The attribution answers which inputs pushed the output where it
went. For a linear model $f(\xvec) = \wvec^\top\xvec + b$ the answer is unambiguous: feature $j$ contributes
$w_j(x_j - x^\prime_j)$, and these contributions add up to $f(\xvec) - f(\xvec^\prime)$. Every method below is a way of
extending this answer to a nonlinear $f$. They differ in which property of the linear case they keep.

## Gradient saliency

The simplest attribution is the gradient, $\phi_j = \partial f / \partial x_j$ evaluated at $\xvec$, or its absolute value
<Cite id="simonyan2014" />. It follows from the first-order Taylor expansion
$f(\xvec + \deltavec) \approx f(\xvec) + \nabla f(\xvec)^\top\deltavec$: the gradient says how the output would change under
an infinitesimal change of each feature. One backward pass of <NoteLink to="backpropagation">backpropagation</NoteLink>
computes it for all features at once.

**Gradient × input**, $\phi_j = x_j\,\partial f / \partial x_j$, multiplies the local sensitivity by the size of the
feature <Cite id="shrikumar2017" />. For a linear model with zero baseline and zero bias it equals $w_j x_j$ and is
complete.

Both fail when $f$ saturates. Take $f(x) = 1 - \max(0, 1 - x)$, a ReLU network that rises from $0$ at $x = 0$ to $1$ at
$x = 1$ and then stays flat. At $x = 2$ the gradient is $0$, so saliency and gradient × input both give $\phi = 0$,
although the input moved the output from $f(0) = 0$ to $f(2) = 1$ <Cite id="sundararajan2017" />. A local derivative
cannot see change that happened before the function flattened. Gradients of deep networks are also visually noisy;
SmoothGrad averages the gradient over copies of $\xvec$ with added Gaussian noise to reduce the noise
<Cite id="smilkov2017" />.

## Integrated gradients

Integrated gradients accumulates the gradient along the straight path $\gammavec(\alpha) = \xvec^\prime + \alpha(\xvec - \xvec^\prime)$,
$\alpha \in [0, 1]$, from the baseline to the input <Cite id="sundararajan2017" />:

$$
\mathrm{IG}_j(\xvec) = (x_j - x^\prime_j)\int_0^1 \frac{\partial f}{\partial x_j}\big(\xvec^\prime + \alpha(\xvec - \xvec^\prime)\big)\,d\alpha.
$$

**Completeness.** Along the path, $f(\gammavec(\alpha))$ is a function of the scalar $\alpha$. By the
<NoteLink to="multivariable-chain-rule">chain rule</NoteLink>, its derivative is

$$
\frac{d}{d\alpha} f(\gammavec(\alpha)) = \sum_{j=1}^d \frac{\partial f}{\partial x_j}(\gammavec(\alpha))\,\frac{d\gamma_j}{d\alpha}
= \sum_{j=1}^d \frac{\partial f}{\partial x_j}(\gammavec(\alpha))\,(x_j - x^\prime_j).
$$

Integrating from $\alpha = 0$ to $\alpha = 1$ and applying the fundamental theorem of calculus to the left-hand side gives

$$
f(\xvec) - f(\xvec^\prime) = \sum_{j=1}^d (x_j - x^\prime_j)\int_0^1 \frac{\partial f}{\partial x_j}(\gammavec(\alpha))\,d\alpha = \sum_{j=1}^d \mathrm{IG}_j(\xvec).
$$

The attributions account exactly for the difference between the prediction and the baseline prediction. The argument
needs $f$ to be differentiable almost everywhere along the path, which holds for ReLU networks. For the saturating
example, $\mathrm{IG}(2) = 2\int_0^1 f^\prime(2\alpha)\,d\alpha = 2 \cdot \tfrac12 = 1 = f(2) - f(0)$.

**Other axioms.** Sundararajan et al. state two further requirements. **Sensitivity**: if $\xvec$ and $\xvec^\prime$
differ in one feature and $f(\xvec) \ne f(\xvec^\prime)$, that feature gets a nonzero attribution. Completeness implies
it. **Implementation invariance**: two networks that compute the same function get the same attributions. Integrated
gradients depends on $f$ only through its gradients, which are properties of the function, so it has this property.
Methods that backpropagate modified signals layer by layer, such as DeepLIFT, need not. Any path from $\xvec^\prime$ to
$\xvec$ gives a complete attribution by the same chain-rule argument. The straight line is the only path method that
gives equal attributions to two features that enter $f$ symmetrically when the input and baseline treat them equally
<Cite id="sundararajan2017" />.

**Computation.** The integral is approximated by a Riemann sum with $m$ points,
$\mathrm{IG}_j \approx (x_j - x^\prime_j)\frac{1}{m}\sum_{k=1}^m \partial_j f\big(\xvec^\prime + \tfrac{k - 1/2}{m}(\xvec - \xvec^\prime)\big)$,
at the cost of $m$ gradient evaluations. The authors report that 20 to 300 steps bring the sum within 5% of
$f(\xvec) - f(\xvec^\prime)$ <Cite id="sundararajan2017" />. The gap between the two is a check on $m$.

## LIME

LIME (local interpretable model-agnostic explanations) fits an interpretable model $g$ that imitates $f$ near $\xvec$
<Cite id="ribeiro2016" />. It samples perturbed inputs $\zvec$ around $\xvec$, for example by switching off random subsets
of words or superpixels, and represents each by a binary vector $\zvec^\prime \in \set{0, 1}^{d^\prime}$ of which
interpretable components are present. It then solves

$$
\xi(\xvec) = \argmin_{g \in \Gcal}\ \sum_{\zvec} \pi_{\xvec}(\zvec)\big(f(\zvec) - g(\zvec^\prime)\big)^2 + \Omega(g),
\qquad \pi_{\xvec}(\zvec) = \exp\!\big(-D(\xvec, \zvec)^2/\sigma^2\big),
$$

where $\Gcal$ is the class of linear models $g(\zvec^\prime) = \wvec_g^\top\zvec^\prime$, $\pi_{\xvec}$ weights samples by
their distance $D$ from $\xvec$ with kernel width $\sigma$, and $\Omega(g)$ restricts $g$ to at most $K$ nonzero weights.
The weights $\wvec_g$ are the attribution. LIME needs only queries of $f$, so it works for any model. Its explanation
depends on the sampling distribution, the kernel width $\sigma$ and the random seed.

## SHAP and KernelSHAP

SHAP defines $\phi_j$ as the Shapley value of feature $j$ in a cooperative game whose payoff for a coalition $S$ of
features is the model's expected output when only the features in $S$ are known <Cite id="lundberg2017" />. The Shapley
value averages the change in payoff from adding feature $j$ over all orders in which features could be revealed, and is
the unique attribution with completeness, symmetry, a dummy property and additivity. The derivation and the exact
algorithm for trees are in <NoteLink to="shap-values-for-trees">SHAP values for trees</NoteLink>.

For a general model, Lundberg and Lee showed that LIME's objective recovers Shapley values for one particular choice of
its ingredients: squared loss, no regulariser, and the kernel

$$
\pi(\zvec^\prime) = \frac{M - 1}{\binom{M}{\abs{\zvec^\prime}}\,\abs{\zvec^\prime}\,(M - \abs{\zvec^\prime})},
$$

where $M$ is the number of features and $\abs{\zvec^\prime}$ the number present <Cite id="lundberg2017" />. This
**KernelSHAP** estimator solves a weighted linear regression over sampled coalitions. The kernel is infinite for the
empty and the full coalition, which enforces $g(\zeros) = \expect[f]$ and completeness as constraints.

## Worked example

Take $f(x_1, x_2) = x_1 x_2$, the input $\xvec = (2, 3)$ and the baseline $\xvec^\prime = (0, 0)$, so
$f(\xvec) - f(\xvec^\prime) = 6$.

- **Gradient.** $\nabla f(\xvec) = (x_2, x_1) = (3, 2)$. Feature 1 looks more important although the function is
  symmetric in its arguments.
- **Gradient × input.** $(2 \cdot 3,\ 3 \cdot 2) = (6, 6)$, which sums to $12$, twice the change in output.
- **Integrated gradients.** On the path, $\partial f / \partial x_1 = x_2(\alpha) = 3\alpha$, so
  $\mathrm{IG}_1 = 2\int_0^1 3\alpha\,d\alpha = 3$. Likewise $\mathrm{IG}_2 = 3\int_0^1 2\alpha\,d\alpha = 3$. The sum is $6$.
- **Shapley values** with payoff $v(S)$ equal to $f$ evaluated with features outside $S$ set to the baseline:
  $v(\emptyset) = v(\set{1}) = v(\set{2}) = 0$ and $v(\set{1, 2}) = 6$. Each feature adds $0$ when revealed first and
  $6$ when revealed second, so each gets $\tfrac12(0 + 6) = 3$.

Integrated gradients and Shapley values agree here and split the interaction equally. They need not agree in general:
Shapley values average over orders of revelation, integrated gradients over a continuous path.

## Assumptions

- The baseline $\xvec^\prime$ represents "no information". A black image is a common choice for images and a zero
  embedding for text. The attributions are statements relative to that baseline, and change when it changes.
- Gradient methods require $f$ to be differentiable almost everywhere. LIME and KernelSHAP require only queries.
- Perturbation methods such as LIME and KernelSHAP evaluate $f$ on inputs with features removed or replaced. These
  inputs can lie far from the training data, where $f$ is unconstrained.

## Pitfalls

- **Attributions explain the model, not the data.** A feature with a large attribution is used by the model. The
  feature need not cause the outcome.
- **Visual appeal is not faithfulness.** Some attribution maps look like edge detectors and change little when the
  network's weights are randomised <Cite id="adebayo2018" />. Test a method before trusting it.
- **Correlated features.** When two features carry the same information, the model can use either, and methods split
  or assign the credit in different ways. Low attribution does not mean a feature is uninformative.
- **Sign conventions.** Saliency maps often show $\abs{\partial f / \partial x_j}$, which discards whether a feature
  pushed the output up or down.
